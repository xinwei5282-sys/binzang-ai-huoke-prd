# 页面 PRD：设置 / 成员与权限

> 页面 ID：`member`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_设置与治理]]

## 问题

企业多人协作涉及知识、内容、发布和账号等敏感能力，需要明确角色、数据范围和审批边界，避免越权或跨租户访问。

## 目标

支持成员邀请、角色配置、数据范围、停用和审计；保证最小权限、租户隔离和最后管理员保护。

## 目标用户

企业管理员管理成员；企业负责人审批高权限；部门负责人查看本部门；成员查看自身权限。

## 用户流程

进入成员列表 → 搜索/筛选 → 邀请成员 → 设置角色和数据范围 → 发送邀请 → 成员接受 → 管理员调整或停用 → 查看审计。

## 功能规则

- 系统角色为企业管理员、负责人、运营、审核员、只读成员；可叠加数据范围。
- 权限按租户、功能、动作、数据范围共同判断，默认拒绝。
- 不能删除或降级最后一名active企业管理员。
- 发布、账号凭证、受限知识等高权限需负责人确认。

## 异常与边界

重复邀请返回原邀请；邀请过期可重发；已离职成员立即停用会话和令牌；最后管理员操作阻止；跨租户成员身份隔离；批量修改逐条返回结果。

## 字段交互 / 取值

### 成员搜索
搜索框。字段键：`keyword`。按姓名/手机号/邮箱，2–50字，300ms防抖。

### 成员状态
筛选。字段键：`member_status`。取值invited/active/suspended/left；默认active与invited。

### 姓名
文本输入。字段键：`name`。2–40字，邀请时必填。

### 手机号
文本输入。字段键：`phone`。手机号格式，可与邮箱至少填一个；显示脱敏。

### 邮箱
邮箱输入。字段键：`email`。标准邮箱，可与手机号至少填一个；租户内不可重复active身份。

### 企业角色
单选。字段键：`role`。取值enterprise_admin/owner/operator/reviewer/readonly；必填；默认readonly。

### 数据范围
单选。字段键：`data_scope`。取值all_enterprise/department/specified_domains/owned_only；默认owned_only。

### 可访问知识域
多选。字段键：`knowledge_domains`。数据范围为specified_domains时必选；取值为企业七个知识域。

### 专项权限
复选。字段键：`special_permissions`。取值review/publish/export/manage_accounts/manage_agents；高风险项需负责人确认。

### 邀请成员
主按钮。字段键：`invite_member`。校验联系方式、角色和范围后发送；记录邀请人和有效期72小时。

### 编辑权限
列表按钮。字段键：`edit_member_permissions`。打开当前权限快照；保存携带version并显示新增/移除权限差异。

### 停用成员
危险按钮。字段键：`suspend_member`。必须填写原因并二次确认；立即吊销会话，历史归属保留。

### 查看审计
按钮。字段键：`view_member_audit`。显示邀请、登录、授权、停用和敏感操作；仅管理员/负责人可见。

## 状态与权限

成员：`invited → active → suspended | left`。企业管理员管理；负责人批准高权限；成员仅查看自己的角色和范围。

## 数据与接口

对象：`tenant_member`、`member_invitation`、`role_binding`、`permission_grant`、`audit_log`。接口：`GET/POST /settings/members`、`PATCH /members/{id}/permissions`、`POST /members/{id}/suspend|reactivate`。错误码：`CONTACT_REQUIRED`、`MEMBER_DUPLICATE`、`LAST_ADMIN_GUARD`、`HIGH_RISK_APPROVAL_REQUIRED`、`VERSION_CONFLICT`。

## Skill / Prompt

权限由确定性策略引擎判断，不交给大模型。AI只可将自然语言权限需求转换为待确认建议：

```text
输出 suggested_role、suggested_scope、suggested_permissions、risk_notes。不得直接授权；高风险权限必须标记 requires_owner_approval=true。
```

## 埋点事件

`member_list_viewed`、`member_invited`、`member_invitation_accepted`、`member_permission_changed`、`member_suspended`、`last_admin_guard_triggered`；属性含role、scope、permission_count。

## 验收标准

1. 最后一名管理员无法被删除、停用或降级。
2. 成员无法访问范围外知识和其他租户数据。
3. 高风险权限必须经过负责人确认。
4. 停用后现有会话立即失效且历史记录保留。

## 核心指标

跨租户访问事件0；高风险授权审批覆盖率100%；最后管理员保护率100%；停用会话吊销成功率100%。
