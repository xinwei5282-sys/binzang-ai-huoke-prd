## 页面概述

用量管理展示租户共享额度、周期消耗、剩余额度、活跃子账号、成员用量上限和平台调整记录，帮助管理员做资源控制。

- 目标用户：租户管理员、用量管理员、观察员。
- 页面入口：系统管理 → 用量管理。
- 权限：`usage.view`、`usage.manage`、`usage.export`。
- 核心结果：额度透明、成员上限可控、调整可追溯。

## 页面级业务规则

1. 租户使用共享额度池，成员消耗从同一周期额度聚合。
2. `剩余额度 = 共享总额度 - 已确认记账用量`，不使用前端估算值扣费。
3. 活跃子账号指周期内至少产生一条有效用量事件的成员。
4. 管理员可设置成员月度上限，观察员只读。
5. 成员上限不得低于其当前周期已用量，也不得违反租户额度策略。
6. 平台增加额度、月度重置和平台纠错记录只读，租户不可修改。
7. 导出统计不包含 Prompt 正文、知识正文、附件、输入原文或密钥。
8. 用量事件按幂等键记账，任务重试不能重复扣量。

## 页面字段级定义

| 字段 | 字段键 | 类型 | 必填 | 口径 | 展示 |
|---|---|---|:---:|---|---|
| 周期 | `period` | year-month | 是 | 租户计量周期 | 默认当前月 |
| 共享总额度 | `total_quota` | integer | 是 | 周期可用总量 | KPI 1 |
| 已用量 | `used_quota` | integer | 是 | 已确认记账汇总 | KPI 2 |
| 剩余额度 | `remaining_quota` | integer | 是 | 总量减已用 | KPI 3 |
| 活跃子账号 | `active_members` | integer | 是 | 有有效事件成员数 | KPI 4 |
| 成员 | `member_id/name` | ref/string | 是 | 当前租户成员 | 用量表 |
| 成员消耗 | `member_used` | integer | 是 | 周期聚合 | 用量表 |
| 成员上限 | `member_cap` | integer | 是 | 大于等于已用量 | 管理员可编辑 |
| 使用率 | `usage_rate` | percent | 是 | used/cap | 进度条 |
| 调整类型 | `event_type` | enum | 是 | add/reset/correction | 调整表 |
| 调整额度 | `quota_delta` | integer | 是 | 增减值或重置总量 | 只读 |
| 调整说明 | `reason` | string | 是 | 来源与原因 | 只读 |

## 页面级操作定义

| 操作 | 权限 | 前置条件 | 结果 | 审计 |
|---|---|---|---|---|
| 查看用量 | `usage.view` | 周期有效 | 加载 KPI 与成员聚合 | 可采样 |
| 设置成员上限 | `usage.manage` | 新上限 ≥ 当前已用 | 保存上限 | `member_quota_cap_updated` |

## 产品边界

本页不提供充值、套餐购买、账单开票或平台额度修改，不定义模型供应商成本结算。真实计量、原子扣量、退款与财务账单由后端服务负责；原型仅演示数据结构和上限交互。

## 页面级流程

```text
进入页面 → 加载当前周期 quota_snapshot → 聚合成员 usage_events
→ 展示 KPI、成员上限与调整记录

设置上限 → 输入新值 → 校验不低于已用量 → 服务端版本校验
→ 保存上限 → 写审计 → 刷新成员行
```

导出：选择周期/范围 → 创建异步导出任务 → 写导出记录 → 完成后下载。

## 通知与日志

- 成员上限调整写操作日志，包含旧值、新值和操作者。
- 额度达到 70%、90%、100% 时按规则通知管理员。
- 平台额度调整写不可变额度事件与操作日志。
- 导出统计写导出记录，包含周期、范围和文件摘要。
- 记账失败写系统告警，不把失败任务计入已用量。

## 异常与空状态

| 场景 | 页面表现 | 恢复动作 |
|---|---|---|
| 当前周期无消耗 | KPI 显示 0，成员表保留字段说明 | 切换周期 |
| 无成员 | 显示成员管理入口 | 添加成员 |
| 上限低于已用量 | 阻止保存并提示最小值 | 调高上限 |
| 额度耗尽 | KPI 标红，创建高消耗任务时阻断 | 联系平台调整 |
| 聚合延迟 | 标记“数据更新中”和快照时间 | 稍后刷新 |
| 导出失败 | 保留周期和范围 | 重试导出 |

## 页面验收标准

1. 共享总额度、已用量、剩余额度和活跃子账号四个 KPI 同屏展示。
2. 成员表展示消耗、上限、使用率和设置入口。
3. 上限低于已用量时不能保存。
4. 观察员没有可用的设置上限动作。
5. 平台增加额度与月度重置记录只读。
6. 导出统计会生成导出审计且不含敏感正文。
7. 任务重试不会产生重复用量事件。
8. 页面 PRD 抽屉展示 `usage` 与本文合同。

## 技术实现提示

- 对象：`quota_snapshot`、`member_quota_cap`、`usage_event`、`quota_adjustment`。
- `usage_event` 唯一约束建议 `tenant_id + idempotency_key + meter_key`。
- KPI 由已确认事件聚合，页面展示聚合时间与快照版本。
- 上限更新使用版本锁，扣量使用服务端原子检查。
- 导出异步、限流并做字段白名单。
- 自动化测试覆盖无用量、上限边界、并发、幂等、导出和移动端表格。
