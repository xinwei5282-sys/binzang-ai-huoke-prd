# 页面 PRD：设置 / 帮助与服务

> 页面 ID：`setting-help`｜版本：v1.0｜优先级：P1｜上位：[[../PRD_设置与治理]]

## 问题

用户遇到操作、授权或生成失败时需要快速定位帮助和提交服务请求；静态原型不能伪装成真实在线客服或已受理工单。

## 目标

提供帮助文档、常见问题、服务状态和工单入口；明确演示与真实服务边界，并让已提交请求可追踪。

## 目标用户

所有企业成员查帮助；管理员提交技术/账号问题；负责人提交商务与套餐咨询；服务人员处理工单。

## 用户流程

进入帮助与服务 → 搜索文档/选择问题分类 → 查看答案 → 未解决则填写工单 → 提交并获得编号 → 查看进度和回复 → 确认解决或重新打开。

## 功能规则

- 帮助内容按入门、企业大脑、品牌经营、营销物料、AI获客、账号权限、用量计费分类。
- 服务状态仅显示监控接口返回数据；未接入时标注“暂未接入”，不能显示假正常。
- 工单提交成功必须由后端返回ticket_id；本地toast不代表已受理。
- 敏感凭证、密码和个人隐私不得写入描述或附件。

## 异常与边界

搜索无结果推荐提交工单；附件失败可移除重传；离线时保存本地草稿但不显示已提交；服务接口不可用显示状态未知；已关闭工单在时限内可重开。

## 字段交互 / 取值

### 帮助搜索
搜索框。字段键：`help_keyword`。2–100字，300ms防抖；匹配标题、关键词和正文摘要。

### 帮助分类
单选/导航。字段键：`help_category`。取值getting_started/brain/brand/marketing/acquisition/accounts/billing；默认getting_started。

### 帮助文章
列表。字段键：`help_articles[]`。显示标题、摘要、更新时间、适用版本；点击打开正文并保留搜索上下文。

### 服务状态
状态卡。字段键：`service_status[]`。显示服务名、operational/degraded/outage/unknown、更新时间和说明；unknown不显示绿色正常。

### 问题类型
下拉。字段键：`ticket_type`。取值product_issue/account_auth/generation_failure/billing/security/business_other；必填。

### 紧急程度
单选。字段键：`priority`。取值low/normal/high/urgent；默认normal；urgent需说明业务影响，不承诺固定响应时间除非套餐包含SLA。

### 问题标题
文本输入。字段键：`subject`。5–100字，必填。

### 问题描述
多行输入。字段键：`description`。20–5000字，必填；提示提供页面、时间、任务ID和复现步骤，禁止凭证。

### 关联对象
选择器。字段键：`related_object`。可选任务/报告/内容/平台账号/账单；只可选择当前用户有权查看对象。

### 附件
上传。字段键：`attachments[]`。PNG/JPG/PDF/TXT/日志，单个≤20MB，最多5个；上传前安全扫描并提示脱敏。

### 联系方式
文本输入。字段键：`contact`。邮箱或手机号，必填；默认当前成员信息，展示脱敏。

### 提交工单
主按钮。字段键：`submit_ticket`。在线且校验通过时可用；成功必须展示服务端ticket_id和创建时间。

### 我的工单
列表。字段键：`tickets[]`。显示编号、标题、状态、优先级、更新时间、负责人和未读回复数。

### 追加回复
输入+按钮。字段键：`ticket_reply`。1–3000字；open/in_progress/waiting_customer状态可提交。

### 确认解决/重新打开
操作按钮。字段键：`resolve_or_reopen`。确认解决进入closed；关闭后7天内可重开并填写原因。

## 状态与权限

工单：`draft → open → in_progress → waiting_customer → resolved → closed`，可`closed → reopened`。成员查看自己工单；管理员看租户工单；服务人员按分配范围处理。

## 数据与接口

对象：`help_article`、`service_status`、`support_ticket`、`ticket_message`、`ticket_attachment`。接口：`GET /help/articles|service-status`、`GET/POST /support/tickets`、`POST /tickets/{id}/messages|close|reopen`。错误码：`OFFLINE_DRAFT_ONLY`、`ATTACHMENT_UNSAFE`、`TICKET_CREATE_FAILED`、`REOPEN_WINDOW_EXPIRED`。

## Skill / Prompt

```text
你是帮助内容检索助手。只引用已发布帮助文章和当前用户可见状态；输出 answer、article_refs、confidence、next_action。无法确认时建议提交工单，不得编造服务状态、工单编号、SLA或已受理结果。
```

## 埋点事件

`help_page_viewed`、`help_searched`、`help_article_opened`、`support_ticket_draft_saved/submitted`、`ticket_reply_sent`、`ticket_closed/reopened`；属性含category、result_count、ticket_type、priority、status。

## 验收标准

1. 服务未接入时显示未知/暂未接入，不显示假正常。
2. 只有收到后端ticket_id才显示提交成功。
3. 离线草稿不被标记为已受理。
4. 用户只能查看授权范围内工单和关联对象。
5. 附件和描述明确阻止敏感凭证上传。

## 核心指标

虚假受理数0；帮助搜索解决率上线后建立基线；工单创建可确认率100%；未授权工单访问数0。
