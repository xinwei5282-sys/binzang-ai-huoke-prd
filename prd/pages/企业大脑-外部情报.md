# 页面 PRD：企业大脑 / 外部情报

> 页面 ID：`intelligence`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_企业大脑]]

## 问题

企业需要从公开网站持续获取行业、政策、竞对和客户需求信息，但来源真实性、重复内容和企业相关性必须可核验。

## 目标

支持添加公开链接和采集公开网站，形成带来源、证据和置信度的情报候选；人工确认后再用于经营判断。

## 目标用户

企业负责人查看关键变化；市场/战略人员添加来源和确认情报；运营人员维护订阅；普通成员只读。

## 用户流程

进入外部情报 → 查看分类和最新候选 → 添加公开链接或创建公开网站采集 → 系统抓取、去重、摘要和相关性判断 → 人工查看原文 → 采用/忽略 → 采用项进入正式情报库并可关联经营计划。

## 功能规则

- 仅采集无需登录、合法公开访问的HTTP/HTTPS页面；遵守robots、频率限制和站点条款。
- “添加公开链接”与“采集公开网站”使用同一候选、证据、去重和确认流程。
- 情报类型为竞对、政策、行业、客户需求；每条必须保留原始URL、来源机构、采集时间和原文证据。
- 采集结果默认candidate，人工采用后才可作为诊断和计划依据。
- 本页不展示Agent授权和上传资料入口。

## 异常与边界

登录墙、验证码、付费墙和禁止抓取页面停止采集；URL无效或非公开地址拒绝；页面变更保留历史快照；重复内容合并来源；无法确认发布日期时标记未知；删除源不删除已采用历史证据。

## 字段交互 / 取值

### 情报类型
多选筛选/创建字段。字段键：`intelligence_type`。取值competitor/policy/industry/customer_demand；创建时必选。

### 适用地区
地区输入。字段键：`applicable_region`。取值全国、省市区或自定义1–50字；可为空表示未判断。

### 标题
文本输入。字段键：`title`。2–120字，必填；抓取后可用网页标题，人工可改。

### 原始链接
URL输入。字段键：`source_url`。仅http/https，必填；保存前规范化并检查内网/重复/可访问性。

### 来源机构
文本输入。字段键：`publisher`。1–100字；可由站点元数据提取，无法识别时待补充。

### 发布时间
日期时间。字段键：`published_at`。不得晚于当前时间；可为空并显示“未知”。

### 来源摘要
多行文本。字段键：`source_summary`。0–1000字；必须由原文支持，AI摘要带证据定位。

### 企业相关性
只读+人工修订。字段键：`enterprise_relevance`。含high/medium/low、原因和关联目标；AI判断仅为候选。

### 添加公开链接
主按钮。字段键：`add_public_link`。校验URL后创建单页采集任务，结果进入candidate。

### 采集公开网站
按钮。字段键：`collect_public_site`。创建站点订阅，需填写入口URL、范围和频率，不支持登录凭证。

### 采集范围
规则输入。字段键：`crawl_scope`。取值single_page/same_path/same_domain；默认single_page；same_domain需显示预计范围和上限。

### 采集频率
下拉。字段键：`schedule`。取值manual/daily/weekly/monthly；默认manual；高频受套餐和站点限制。

### 情报候选列表
列表。字段键：`candidates[]`。显示类型、标题、来源、时间、地区、相关性、状态、证据和操作。

### 查看原文
按钮。字段键：`view_source`。打开安全新页或文本快照；原站不可用时展示最后成功快照。

### 采用/忽略
操作按钮。字段键：`review_action`。采用需选择知识域/经营目标；忽略需原因，可恢复。

## 状态与权限

采集任务：`queued → fetching → parsed → candidate | failed | blocked`；情报：`candidate → adopted | ignored | expired`。市场/知识负责人采用，普通成员只读。

## 数据与接口

对象：`public_source`、`collection_job`、`intelligence_candidate`、`source_snapshot`、`intelligence_item`。接口：`POST /intelligence/public-links`、`POST /intelligence/sources`、`GET /intelligence/candidates`、`POST /candidates/{id}/adopt|ignore`。错误码：`URL_INVALID`、`PRIVATE_NETWORK_BLOCKED`、`ROBOTS_BLOCKED`、`LOGIN_REQUIRED`、`DUPLICATE_CONTENT`。

## Skill / Prompt

Skill：`collect-external-intelligence`。

```text
只采集允许公开访问的来源。对每条候选输出 source_url、publisher、published_at、collected_at、evidence_excerpt、type、region、summary、enterprise_relevance、confidence、duplicate_key。事实和推断分开；无证据不生成结论；不得绕过登录、验证码、付费墙或robots限制。
```

## 埋点事件

`intelligence_page_viewed`、`public_link_added`、`public_site_collection_created`、`collection_blocked/failed`、`intelligence_adopted/ignored`；属性含type、scope、schedule、domain、error_code。

## 验收标准

1. 两个入口均产生同结构候选并进入人工确认。
2. 每条候选可打开原文或快照。
3. 登录墙、内网地址和禁止抓取站点不会被绕过。
4. 未采用候选不进入正式诊断依据。
5. 页面无Agent授权和上传资料入口。

## 核心指标

来源可追溯率100%；公开访问合规阻断率100%；重复候选合并率≥95%；未确认情报进入正式知识数0。
