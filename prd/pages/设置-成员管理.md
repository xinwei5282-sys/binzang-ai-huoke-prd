## 页面概述

成员管理负责租户内成员账号、多个角色分配、启停和密码重置，明确“成员只挂角色、权限统一在角色页维护”。

- 目标用户：租户管理员、成员管理员、只读观察员。
- 前置条件：当前账号具备 `member.view`。
- 页面入口：系统管理 → 成员管理。
- 核心结果：成员可登录状态与角色关系可追溯。

## 页面级业务规则

1. 一个成员可分配一个或多个角色，最终权限为所有角色权限并集。
2. 本页不提供逐成员 allow/deny 覆盖，避免角色与个人权限冲突。
3. 新增成员必须填写姓名、唯一账号并至少选择一个有效角色。
4. 停用成员会阻止新登录并使有效会话失效，但不删除历史任务、产物和审计。
5. 最后一个可管理成员与权限的管理员不得被停用或移除管理员角色。
6. 密码重置生成一次性链接；明文密码和重置链接不进入页面日志。
7. 已删除角色不出现在分配选项；被成员引用的角色不能在权限页删除。

## 页面字段级定义

| 字段 | 字段键 | 类型 | 必填 | 规则 | 展示 |
|---|---|---|:---:|---|---|
| 成员姓名 | `name` | string | 是 | 2–30 字 | 列表主标题 |
| 登录账号 | `account` | phone/email | 是 | 租户内唯一；格式有效 | 按权限脱敏 |
| 角色 | `role_ids` | array | 是 | 至少 1 个有效角色 | 徽标列表 |
| 最终权限摘要 | `permission_summary` | computed | 是 | 角色权限并集 | 只读 |
| 状态 | `status` | enum | 是 | active / disabled | 启用、停用徽标 |
| 创建时间 | `created_at` | datetime | 是 | 服务端时间 | 租户时区展示 |
| 最近登录 | `last_login_at` | datetime | 否 | 无记录显示“—” | 详情展示 |
| 成员 ID | `member_id` | uuid | 是 | 稳定不可变 | 不允许编辑 |

## 页面级操作定义

| 操作 | 权限 | 前置条件 | 结果 | 审计事件 |
|---|---|---|---|---|
| 新增成员 | `member.manage` | 姓名、账号、角色有效 | 创建启用成员 | `member_created` |
| 编辑角色 | `member.manage` | 至少保留一个角色 | 更新关系并重算权限 | `member_roles_updated` |
| 停用成员 | `member.manage` | 不是最后一个管理员 | 状态停用、会话失效 | `member_disabled` |
| 启用成员 | `member.manage` | 账号仍有效 | 恢复登录能力 | `member_enabled` |
| 重置密码 | `member.manage` | 成员启用或可恢复 | 生成一次性重置任务 | `member_password_reset` |
| 查看权限摘要 | `member.view` | 成员存在 | 展示角色并集 | 可按策略采样 |

## 产品边界

本页不编辑角色内部权限、不创建跨租户账号、不管理知识密级的专项授权，也不展示明文密码。短信、邮件、MFA 与会话失效由身份服务实现；原型只展示交互合同。

## 页面级流程

```text
新增：点击新增成员 → 填姓名/账号 → 多选角色 → 校验唯一性
→ 创建成员 → 计算权限并集 → 写审计 → 列表回显

停用：选择成员 → 校验管理员保护 → 确认停用
→ 撤销有效会话 → 状态回显 → 保留历史
```

角色调整：打开成员 → 修改角色集合 → 校验至少一个角色 → 保存 → 权限缓存失效并重算。

## 通知与日志

- 新增、角色调整、启停写操作日志。
- 登录、密码重置和异常尝试写登录与安全日志。
- 停用可通知成员，但通知内容不得包含敏感权限详情。
- 审计保存角色 ID 的变更前后集合、操作者和时间。
- 重置链接与密码永不进入日志。

## 异常与空状态

| 场景 | 页面表现 | 恢复动作 |
|---|---|---|
| 无成员 | 展示成员价值说明与新增入口 | 新增首位成员 |
| 账号重复 | 字段提示已有成员，不创建 | 使用其他账号或编辑原成员 |
| 未选角色 | 阻止保存并定位角色区 | 至少选择一个角色 |
| 最后管理员保护 | 禁止停用或移除角色 | 先创建另一管理员 |
| 角色已失效 | 标记角色不可用并阻止保存 | 选择有效角色 |
| 重置服务失败 | 保留页面状态，显示重试 | 再次发起重置 |

## 页面验收标准

1. 列表展示姓名、账号、角色、权限摘要、状态和创建时间。
2. 新增成员必须通过账号唯一和至少一个角色校验。
3. 多角色成员的权限摘要按并集更新。
4. 本页不存在逐账号权限编辑器。
5. 启用、停用、密码重置都有确认与审计反馈。
6. 最后一个管理员不可被停用或移除管理员角色。
7. 停用成员历史任务与日志仍可查。
8. 页面 PRD 抽屉标题与页面键为“成员管理 / members”。

## 技术实现提示

- 对象：`member`、`role`、`member_roles`、`session`。
- 唯一约束建议 `tenant_id + normalized_account`。
- 权限摘要可由授权服务计算，角色变化使缓存和活跃会话声明失效。
- 启停与角色更新采用版本号，防止并发覆盖。
- 重置密码只返回任务状态，不向前端返回可长期复用凭据。
- 浏览器验收覆盖新增、角色多选、启停、重置、管理员保护和移动表格滚动。
