# 页面 PRD：设置 / 企业设置

> 页面 ID：`setting-company`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_设置与治理]]

## 问题

企业基础配置影响全系统显示、时区、品牌与通知，但若与知识候选混用，可能让提取内容未经确认就覆盖企业配置。

## 目标

集中维护租户级企业配置，明确哪些字段是系统配置、哪些同步为正式知识，并保证修改可审计、可校验。

## 目标用户

企业管理员维护；企业负责人查看和批准关键变更；普通成员只读有限信息。

## 用户流程

进入企业设置 → 查看当前配置 → 编辑字段 → 即时校验 → 保存 → 关键字段二次确认 → 系统记录版本并同步允许同步的正式知识。

## 功能规则

- 页面标题顶部为“设置”，内容标题为“企业设置”。
- 设置字段必须由有权限用户直接编辑，上传/OCR/网站提取只可给出候选提示，不能自动覆盖。
- 企业名称、时区等关键字段变更写审计；影响下游时展示影响清单。
- 保存按版本号并发控制，成功后刷新租户上下文。

## 异常与边界

名称重复仅在租户内允许但显示提示；Logo上传失败不影响其他字段；时区变化不自动改历史发布时间；并发修改返回差异；最后一次成功配置可恢复。

## 字段交互 / 取值

### 企业显示名称
文本输入，失焦校验。字段键：`display_name`。2–80字，必填；默认注册名称；保存后影响全局导航和产物落款。

### 企业法定名称
文本输入。字段键：`legal_name`。2–120字，可为空；仅管理员和负责人可见，不由AI自动填写。

### 企业简称
文本输入。字段键：`short_name`。2–20字，可为空；默认从显示名称建议，需人工保存。

### 所属行业
可搜索单选+自定义。字段键：`industry`。标准行业枚举或2–40字自定义，必填；同步正式企业知识。

### 所在地区
省市区选择器。字段键：`region_code`。中国行政区划代码，可为空；海外选择国家/地区和城市文本。

### 默认时区
下拉搜索。字段键：`timezone`。IANA时区，必填；默认`Asia/Shanghai`；只影响新任务与展示。

### 默认语言
下拉。字段键：`locale`。取值zh-CN/en-US；默认zh-CN；当前版本仅控制界面与生成语言偏好。

### 企业Logo
图片上传。字段键：`logo_asset_id`。PNG/JPG/SVG，≤10MB；SVG需安全扫描；预览后保存，旧版本保留。

### 官网
URL输入。字段键：`website_url`。http/https，可为空；保存仅记录，不自动采集。

### 联系人
文本输入。字段键：`contact_name`。2–40字，可为空；仅设置管理员可见。

### 联系电话
文本输入。字段键：`contact_phone`。中国大陆手机号/固话或国际格式，可为空；展示脱敏。

### 保存设置
主按钮。字段键：`save_company_settings`。字段变化且校验通过后可用；提交携带version。

## 状态与权限

配置状态：`active`，修改形成版本。企业管理员编辑全部；负责人批准关键字段；普通成员仅查看display_name、logo、industry、region。

## 数据与接口

对象：`tenant_settings`、`tenant_setting_version`、`audit_log`。接口：`GET/PATCH /settings/company`、`POST /settings/company/logo`。错误码：`FIELD_INVALID`、`ASSET_UNSAFE`、`KEY_FIELD_CONFIRMATION_REQUIRED`、`VERSION_CONFLICT`。

## Skill / Prompt

```text
如需给出行业、简称等建议，只可基于用户当前输入形成 suggestion，不得直接写入配置。输出 suggested_value、reason、source_field；最终值必须由用户保存。
```

## 埋点事件

`company_settings_viewed`、`company_setting_changed`、`company_settings_saved`、`company_logo_uploaded`、`company_settings_conflict`；属性含field_name、role、changed_field_count。

## 验收标准

1. 未经用户保存的提取候选不会覆盖设置。
2. 时区变更不修改历史任务时间。
3. 并发保存可见冲突而非静默覆盖。
4. 关键修改有完整审计。

## 核心指标

设置保存成功率≥99%；未经确认自动覆盖数0；关键字段审计覆盖率100%；版本冲突可发现率100%。
