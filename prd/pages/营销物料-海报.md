# 页面 PRD：营销物料 / 海报

> 页面 ID：`material-poster`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_营销物料]]

## 问题

企业需要按VI快速生成多尺寸海报，但图片模型可能产生错误文字、Logo或未经确认的数据；页面也不能增加不存在的发布和回收能力。

## 目标

支持新建、生成、预览、编辑、审核和按尺寸下载；确保VI、事实、素材授权和图片安全区可追溯。

## 目标用户

运营创建编辑；品牌负责人审核VI一致性；审核人检查事实和授权；只读成员预览。

## 用户流程

进入列表 → 新建并选用途/尺寸 → 生成文案与主视觉 → 预览/换图/编辑 → 审核 → 下载指定尺寸。

## 功能规则

- 无发布账号、发布时间、发布状态和结果回收。
- active VI优先；无active VI使用系统主题并提示。
- 图片Prompt不得要求模型生成正文、Logo、水印或业务数字；文字和Logo由排版层叠加。
- 各尺寸独立渲染和保存；下载冻结版本。

## 异常与边界

图片失败降级为授权素材或纯色背景；文字溢出阻止审核；Logo安全区不足提示换版式；授权未知阻止正式下载；单尺寸失败不影响其他尺寸。

## 字段交互 / 取值

### 海报用途

单选卡片。字段键：`purpose`。取值：活动推广/产品介绍/品牌展示/通知公告/自定义；必填。默认活动推广。

### 目标受众

文本输入。字段键：`audience`。取值2–100字符，必填。

### 尺寸/场景

多选卡片并显示比例预览。字段键：`size_presets`。取值：朋友圈1:1、小红书3:4、公众号封面2.35:1、A4、自定义；至少1项。自定义宽高300–6000px。

### 主标题

文本输入。字段键：`headline`。取值2–30字符，必填。实时显示溢出提示。

### 副标题

文本输入。字段键：`subheadline`。取值0–60字符，可为空。

### CTA

文本输入。字段键：`cta`。取值0–40字符，可为空；不得自动补联系方式。

### 参考图片

多文件上传。字段键：`reference_assets`。JPG/PNG/WebP，单张≤10MB，最多10张；必须确认授权来源。

### VI版本

只读链接。字段键：`vi_version_id`。取值active版本或system_default；任务创建后冻结。

### 海报名称/尺寸/状态

列表字段。字段键：`name/size_presets/status`。状态为draft/generating/pending_review/approved/downloaded/failed。

### 新建海报

主按钮，打开创建表单；校验通过后生成各尺寸任务，防重复提交。

### 替换图片/重新生成

编辑器按钮，仅影响选中尺寸和当前版本；完成后回pending_review。

### 下载

approved时显示尺寸菜单；生成带版本元数据的PNG/JPG/PDF，不创建发布任务。

## 状态与权限

`draft → generating → pending_review → approved → downloaded | failed`。运营编辑，品牌负责人/审核人批准，授权角色下载。审核、下载和素材替换写审计。

## 数据与接口

对象：`poster_task`、`poster_version`、`poster_render`、`poster_asset`、`content_review`。接口：`GET/POST /posters`、`PATCH /posters/{id}`、`POST /{id}/renders`、`POST /renders/{id}/retry`、`POST /{id}/review`、`POST /{id}/download`。

错误码：`VI_NOT_ACTIVE`、`TEXT_OVERFLOW`、`ASSET_LICENSE_UNKNOWN`、`IMAGE_GENERATION_FAILED`、`RENDER_FAILED`、`REVIEW_REQUIRED`。

## Skill / Prompt

```text
你是企业海报策划。基于 confirmed_facts、active_vi、purpose、audience 输出 headline、subheadline、cta、visual_prompt、layout_safe_zones、evidence_refs、risk_flags。visual_prompt 中禁止文字、Logo、水印、价格和业务数字；这些由排版层处理。事实不足时返回 missing_inputs。
```

## 埋点事件

`poster_created`、`poster_size_selected`、`poster_image_retried`、`poster_review_submitted`、`poster_approved`、`poster_downloaded`；属性包含size、vi_version、asset_source、error_code。

## 验收标准

1. 页面无发布和回收字段。
2. 多尺寸产物内容一致且版式适配，不简单拉伸。
3. 图片不含模型生成文字/Logo；排版文字无溢出。
4. 授权不明素材不能正式下载。

## 核心指标

各尺寸渲染成功率≥97%；正式下载成功率≥99%；VI版本追溯率100%；错误发布入口出现率0%。
