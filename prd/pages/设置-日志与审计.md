## 页面概述

日志与审计统一查询系统管理和 AI 业务的关键操作，覆盖五类固定日志，并提供脱敏详情、日志导出与统计报表导出。

- 目标用户：租户管理员、审计员、安全管理员、授权观察员。
- 页面入口：系统管理 → 日志与审计。
- 权限：`audit.view`、`audit.export`。
- 核心原则：不可篡改、租户隔离、最小披露、导出留痕。

## 页面级业务规则

1. 固定日志类型为操作日志、登录与安全日志、AI 调用日志、知识使用日志、导出记录。
2. 日志采用 append-only，不在页面提供编辑或删除。
3. 查询结果必须按 `tenant_id`、角色权限和数据范围过滤。
4. 无查看权限时不得返回记录数量、事件标题或对象摘要。
5. AI 调用日志记录 Prompt/模型/输入快照与校验摘要，不记录完整 Prompt 正文或敏感原文。
6. 知识使用日志记录知识版本与用途，不批量暴露知识正文或附件。
7. 日志导出只包含当前筛选和字段白名单；统计报表只导出聚合指标。
8. 每次导出本身必须生成一条导出记录。
9. Token、Cookie、密码、密钥和文件二进制不得进入任何日志字段。

## 页面字段级定义

| 字段 | 字段键 | 类型 | 必填 | 规则 | 展示 |
|---|---|---|:---:|---|---|
| 日志 ID | `event_id` | uuid | 是 | 全局稳定 | 详情引用 |
| 发生时间 | `occurred_at` | datetime | 是 | 服务端 UTC 存储 | 租户时区展示 |
| 日志类型 | `log_type` | enum | 是 | 五类固定枚举 | 筛选/列表 |
| 事件 | `event_name/summary` | string | 是 | 稳定事件键 + 人类摘要 | 列表主字段 |
| 对象 | `object_type/id/version` | ref | 否 | Prompt、成员、任务、知识等 | 列表/详情 |
| 操作人 | `actor_type/id/name` | ref | 是 | 用户或系统服务 | 列表 |
| 结果 | `result` | enum | 是 | success/passed/failed/blocked | 徽标 |
| 详情 | `detail` | json | 否 | 字段白名单且脱敏 | 详情弹层 |
| 请求 ID | `request_id` | string | 否 | 跨服务追踪 | 详情 |
| 数据保留期 | `retention_until` | date | 是 | 按安全政策 | 管理员详情 |

## 页面级操作定义

| 操作 | 权限 | 前置条件 | 结果 | 记录 |
|---|---|---|---|---|
| 按类型筛选 | `audit.view` | 类型有效 | 与关键词联合过滤 | 不修改日志 |
| 关键词搜索 | `audit.view` | 输入 0–100 字 | 搜事件、对象、操作人 | 脱敏结果 |
| 查看详情 | `audit.view` + 对象范围 | 事件存在 | 展示白名单详情 | 可记录查看事件 |
| 清除筛选 | `audit.view` | 有筛选 | 恢复可见范围 | 不记录 |
| 导出日志 | `audit.export` | 时间/数量满足限制 | 创建异步文件 | `audit_export_created` |
| 导出统计报表 | `audit.export` | 聚合范围有效 | 创建聚合报表 | `audit_report_exported` |

## 产品边界

本页不允许删除、修改或补写审计事件，不支持批量导出知识正文、附件、完整 Prompt、输入原文或凭据。原型只演示前端筛选、详情与反馈；生产需使用独立不可篡改存储与保留策略。

## 页面级流程

```text
进入页面 → 权限与租户过滤 → 加载最近记录
→ 选择日志类型 + 输入关键词 → 查看详情

导出：确认当前筛选 → 校验权限/数量/时间范围
→ 创建异步导出任务 → 写导出记录 → 完成后提供限时下载
```

Prompt 发布：保存草稿 → 测试写 AI 调用日志 → 发布/回滚写操作日志 → 可在本页追溯。

## 通知与日志

- 高风险登录、权限变化、发布失败和连续越权尝试触发安全通知。
- 普通查看不一定逐次通知，但导出必须记录并可通知审计负责人。
- 日志导出记录筛选条件摘要、文件哈希、创建人与过期时间。
- AI 调用记录耗时、模型、Prompt ID/版本、校验结果和输入快照 ID。
- 知识使用记录知识版本、用途和任务，不记录正文。

## 异常与空状态

| 场景 | 页面表现 | 恢复动作 |
|---|---|---|
| 当前范围无记录 | 展示五类说明与清除筛选入口 | 清除筛选或调整时间 |
| 无查看权限 | 不显示数量与摘要 | 联系管理员 |
| 对象已归档 | 详情保留对象引用并标记归档 | 查看历史版本 |
| 查询超时 | 保留筛选条件 | 缩小范围或重试 |
| 导出超量 | 阻止导出并提示限制 | 缩小时间范围 |
| 导出任务失败 | 保留任务和错误码 | 重试当前任务 |
| 脱敏规则异常 | 阻断详情与导出 | 安全管理员处理 |

## 页面验收标准

1. 五类日志均有可识别记录并可按类型筛选。
2. 关键词可搜索事件、对象和操作人。
3. 无结果状态可一键清除筛选。
4. 详情展示时间、类型、事件、对象、操作人、结果与脱敏说明。
5. 日志导出与统计报表导出为两个明确动作。
6. 每次导出生成新的导出记录。
7. 页面与导出中不出现知识正文、附件或凭据。
8. 无权限用户看不到日志总数和摘要。
9. 移动端表格局部滚动且详情可关闭。
10. 页面 PRD 抽屉显示 `logs` 与本文合同。

## 技术实现提示

- 核心对象：`audit_event`、`audit_export_task`、`security_alert`。
- `audit_event` append-only，建议按租户和月份分区并做完整性校验。
- 事件详情使用 Schema 白名单，在写入与读取两侧双重脱敏。
- 查询接口强制时间范围、分页、租户和对象权限。
- 导出异步、限流、加密存储、限时下载并记录文件哈希。
- 浏览器和结构测试覆盖五类枚举、联合筛选、空态、详情、导出与敏感词扫描。
