# 页面 PRD：AI 获客 / 总览

> 页面 ID：`acquisition`｜版本：v1.0｜优先级：P0｜日期：2026-09-01｜上位：[[../PRD_AI获客]]

## 页面概述

| 项目 | 说明 |
|---|---|
| 页面目标 | 聚合获客计划、爆款追踪、营销视频、AI 混剪和数字人的任务状态，让负责人先处理阻塞和待确认事项，再进入具体任务页。 |
| 适用角色 | 企业负责人、增长负责人、运营人员和只读观察者。 |
| 页面入口 | 左侧 `AI 获客` 一级菜单；各获客子页返回总览。 |
| 权限要求 | 有 AI 获客查看权限可访问；创建、审核、发布和重试分别受对应动作权限控制。 |

## 页面级业务规则

- 总览只聚合任务和待办，不替代各子页面的创建、编辑、审核和发布流程。
- 任务必须显示实际业务类型、知识依据、当前阶段、下一人工门和状态。
- “待确认”和“部分成功”优先进入右侧关注区；部分成功只能重试失败片段，不重做已成功片段。
- 平台发布必须在具体任务中选择已绑定账号和可用方式；总览不得默认账号或静默发布。
- 演示数据、定时器和本地状态不得表述为真实平台、模型或 RPA 已接入。

## 页面字段

| 字段 | 类型 | 必填/展示规则 | 业务口径 |
|---|---|---|---|
| 任务名称 | 文本 | 列表必显 | 使用用户命名或任务主题，不用模型生成的临时 ID 代替。 |
| 任务类型 | 枚举 | 列表必显 | `plan/tracking/marketing_video/remix/avatar`。 |
| 知识依据 | 文本+版本 | 列表必显 | 仅展示已确认企业知识、已审核脚本和授权素材版本。 |
| 当前阶段 | 枚举+说明 | 列表必显 | 与子任务状态机一致，不另造总览状态。 |
| 下一人工门 | 文本 | 存在时显示 | 价格、承诺、素材、成片和发布确认必须明确责任人。 |
| 任务状态 | 枚举 | 列表必显 | `draft/running/pending_confirmation/partial_success/succeeded/failed`。 |
| 类型筛选 | 单选 | 默认全部类型 | 只过滤当前列表，不修改任务。 |
| 状态筛选 | 单选 | 默认全部状态 | 支持执行中、待确认、部分成功、已完成和失败。 |
| 更新时间 | 时间 | 列表必显 | 使用服务端任务更新时间；演示页标明示例。 |

## 操作与结果

| 按钮/操作 | 展示条件 | 执行结果 | 权限与记录 |
|---|---|---|---|
| 新建获客任务 | 有创建权限 | 选择任务类型、平台、账号和方式后创建草稿 | 写创建人、账号能力快照和幂等键。 |
| 查看详情 | 所有任务 | 打开任务详情抽屉，不改变任务状态 | 记录查看事件，不记录正文全文。 |
| 去确认 | `pending_confirmation` | 进入对应审核上下文 | 只有审核人可确认，写审核记录。 |
| 只重试失败镜头 | `partial_success` | 仅重试失败片段并保留已成功产物 | 写失败片段、供应商版本和重试次数。 |
| 刷新 | 所有用户 | 重新读取任务和待办 | 不创建任务，不清空筛选。 |
| 清空筛选 | 已选择筛选 | 恢复全部类型和状态 | 仅更新本地视图。 |

## 产品边界

总览展示的是获客工作流状态，不是生产监控台。爆款数据、模型生成、数字人、Remotion、RPA 和平台发布只有接入真实服务并通过权限、授权、审计与人工门后才可执行；未接入时必须显示“演示”或“待接入”。

## 状态与跳转

- `AI 获客总览 → 获客计划 → 审核并启用 → 创建内容任务`
- `AI 获客总览 → 爆款追踪 → 拆解并采用 → 营销视频或 AI 混剪`
- `AI 获客总览 → 待确认任务 → 人工确认 → 生成或发布`
- `AI 获客总览 → 部分成功 → 仅重试失败片段 → 成片确认`

## 通知与日志

- 待确认、部分成功、失败和授权过期进入负责人待办；普通执行中状态不重复通知。
- 记录 `acquisition_overview_opened`、`acquisition_filter_changed`、`acquisition_task_opened`、`acquisition_partial_retry_started`。
- 审计属性包含 `tenant_id/task_id/task_type/status/operator_id/source_version`，不得记录密码、Cookie、token 或完整生成正文。

## 异常与空状态

| 场景 | 页面表现 |
|---|---|
| 无页面权限 | 隐藏入口；直接访问由服务端返回无权限。 |
| 首次无任务 | 解释五类任务的用途并提供“新建获客任务”。 |
| 筛选无结果 | 保留筛选条件，提供“清空筛选”。 |
| 列表加载失败 | 保留页面结构，展示错误摘要和重试，不回显旧租户数据。 |
| 子任务已删除或无权访问 | 关闭详情并提示任务不可用，不泄露任务内容。 |
| 外部能力未接入 | 展示待接入边界，不伪造完成状态。 |

## 页面验收标准

1. 五类任务可在总览区分，筛选不会改变任务状态。
2. 待确认和部分成功任务在关注区可到达对应处理入口。
3. 部分成功任务重试不会重新消耗已成功片段。
4. 新建或发布任务均不能绕过具体账号、发布方式和人工确认。
5. 空态、失败态和无权限状态不展示其他租户或伪造数据。
6. 1440×900 与 390×844 均无非预期横向溢出。

## 技术评估项

- 聚合查询按 `tenant_id`、任务类型、状态和更新时间分页，状态由各领域任务表投影。
- 写操作必须携带 `input_version` 和 `idempotency_key`；重试接口必须接受失败片段集合。
- 账号能力、知识版本、Prompt 版本、素材授权和发布方式在任务创建时保存快照。
- 列表刷新失败不得清空最后一次已确认视图；跨租户缓存必须物理隔离。
- 当前单文件页面仅用于原型评审，生产实现需由后端提供真实聚合接口和权限校验。
