> 原型入口：`prototype/index.html?review=prompts`｜更新日期：2026-09-01
> 注册真源：[[../PRD_提示词]]｜企业基线：[[../PRD_企业AI经营大脑_当前开发基线]]

## 页面概述

提示词管理展示 AI 获客实际使用的全部 Prompt 资产，让当前账号能看到关联功能、场景、模型、参数、稳定 ID、版本、状态、完整正文、输入输出合同和真源。

- 目标用户：Prompt 查看者、测试员、编辑者、发布者与审计员。
- 页面入口：系统管理 → 提示词管理；旧 `agent-center` 自动跳转本页。
- 核心原则：平台基线本体不可覆盖，但授权账号可从基线创建租户覆盖版本并完成测试、发布。
- 权限：`prompt.view/edit/test/publish` 独立控制。

## 页面级业务规则

1. 目录是 `PRD_提示词` 注册表、企业基线、页面 PRD、Remotion 真源与原型实际调用的并集。
2. 稳定 Prompt ID 去重；同一资产升级版本时不改变 ID。
3. 每条可见资产必须有非空完整正文、`sourceRef`、输入合同和输出合同。
4. 只返回租户已开通且当前账号有权查看的功能，不可仅靠前端隐藏越权内容。
5. 每条可见 Prompt 按权限显示修改、测试和发布；修改平台基线时创建租户覆盖草稿，不改写平台基线本体。
6. 租户覆盖或租户自建项编辑后只保存草稿，测试通过后才能发布。
7. 发布生成新版本；历史任务继续引用原版本，不静默覆盖。
8. 回滚基于历史已发布版本生成新记录，不删除历史。
9. 合规检查与质量门禁温度锁定为 0，租户修改不能放宽事实、合规、审批或发布边界。
10. 数字人训练、结构化事实查询等非 Prompt 驱动能力不进入资产表。

首版功能簇：全局与路由、企业大脑、营销物料、AI 获客、经营与发布。

## 页面字段级定义

| 字段 | 字段键 | 类型 | 必填 | 规则 | 展示位置 |

## 页面级操作定义

| 操作 | 权限 / 条件 | 执行结果 | 审计 |
|---|---|---|---|
| 功能筛选 | `prompt.view` | 与搜索词联合过滤 | 不记录正文 |
| 搜索 | `prompt.view` | 搜索 ID、名称、场景、功能、模型 | 无结果可重置 |
| 查看配置 | `prompt.view` | 展示完整正文、模型、合同和真源 | 可按策略采样 |
| 修改配置 | `prompt.edit` | 租户项保存草稿；平台项创建租户覆盖草稿 | `prompt_draft_saved` |
| 测试 Prompt | `prompt.test` | 运行 Schema、事实引用和合规校验 | AI 调用日志 |
| 发布版本 | `prompt.publish` 且租户草稿测试通过 | 创建租户新发布版本 | `prompt_published` |
| 回滚版本 | `prompt.publish` 且租户项 | 创建新的回滚版本 | `prompt_rolled_back` |
| 清除筛选 | `prompt.view` | 恢复全部可见资产 | 不记录 |

## 产品边界

本期不接真实模型、Prompt 服务或版本后端，不做 A/B 实验、Prompt 市场、跨租户共享和批量正文导出。非文本生成能力不伪造成 Prompt。完整 Prompt 允许授权账号查看，但日志与导出默认不包含正文。

## 页面级流程

```text
查看：进入页面 → 服务端按能力/权限过滤 → 搜索或筛选 → 查看完整配置

发布：可见 Prompt → 修改正文/模型/参数 → 平台项创建租户覆盖草稿（租户项直接保存草稿）
→ 填样例输入 → Schema/事实/合规测试通过 → 人工确认 → 发布新版本

回滚：选择历史发布版 → 查看差异 → 确认 → 生成新回滚版本 → 保留全部历史
```

旧链接：`?review=agent-center` → 归一化为 `prompts` → 显示一次升级提示。

## 通知与日志

- 草稿保存、发布和回滚写操作日志。
- 测试写 AI 调用日志：Prompt ID/版本、模型、输入快照、耗时、Schema/事实/合规摘要。
- 正文、密钥、Cookie、Token 与密码不进入日志。
- 发布冲突和校验失败保留草稿并记录脱敏失败维度。
- 发布成功可通知 Prompt 维护人和受影响功能负责人。

## 异常与空状态

| 场景 | 页面表现 | 恢复动作 |
|---|---|---|
| 无开通功能 | 不展示伪资产，说明联系管理员 | 开通功能 |
| 无查看权限 | 不泄露名称、数量或正文 | 申请权限 |
| 搜索无结果 | 显示当前筛选说明 | 清除筛选 |
| 正文或真源缺失 | 标记配置异常，阻断测试/发布 | 补齐配置 |
| 样例输入缺变量 | 定位缺失合同字段 | 补齐后测试 |
| 测试失败 | 保留输入与草稿，显示失败维度 | 修改后重试 |
| 发布版本冲突 | 提示当前生效版本变化 | 刷新并重新确认 |
| 未保存离开 | 提示存在草稿修改 | 保存或放弃 |

## 页面验收标准

1. 七类真源并集中的批准资产均能被检索。
2. 每条可见资产有非空完整正文、真源和输入输出合同。
3. 功能筛选与搜索同时生效，计数显示当前/可见总数。
4. 每条可见 Prompt 按权限显示修改、测试和发布；平台基线修改后标记为“租户覆盖 · 基于平台基线”。
5. 租户覆盖与租户自建项可完成编辑→草稿→测试→发布→回滚闭环，平台基线本体和历史版本不被覆盖。
6. 测试未通过时发布被阻止。
7. 合规 Prompt / 质量门禁温度为 0 且不可放宽。
8. 旧 `agent-center` 链接打开本页而非空白或旧静态表。
9. 移动端表格局部滚动，详情可完整操作。
10. 页面 PRD 抽屉显示本文字段、操作和边界。

## 技术实现提示

- 原型数据源：`AI_HUOKE_PROMPT_CATALOG` + `AI_HUOKE_PROMPT_CONTENT`。
- 正式对象：`prompt_asset`、`prompt_version`、`prompt_test_run`、`prompt_release`。
- 列表接口必须服务端执行租户、能力和权限过滤。
- 内容修改采用版本号；发布和回滚使用幂等键与事务。
- 测试流水线顺序：输入 Schema → 模型调用 → 输出 Schema → 事实引用 → 合规 → 人工门。
- 每次业务调用固化 Prompt、Skill、模型、知识、VI 与输入快照版本。
- 自动化测试覆盖唯一 ID、非空正文、权限边界、搜索、空状态、版本冲突和旧路由。
