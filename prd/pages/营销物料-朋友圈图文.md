# 页面 PRD：营销物料 / 朋友圈图文

> 页面 ID：`material-moments`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_营销物料]]

## 问题

朋友圈图文需要快速生成、编辑和导出，但系统没有朋友圈自动发布与结果回收能力，页面不能堆入无法兑现的账号、发布和数据功能。

## 目标

保留新建、列表、预览、编辑、审核和导出图文包；基于正式企业知识和 active VI 生成可信内容。

## 目标用户

- 运营：创建、编辑、导出。
- 审核人：检查事实、VI、合规和素材授权。
- 只读成员：预览已授权内容。

## 用户流程

1. 进入页面查看草稿和审核状态。
2. 新建并填写主题、受众、CTA和参考图片。
3. 系统生成封面、正文、配图和CTA草稿。
4. 用户预览/编辑，提交人工审核。
5. 审核通过后导出图文包，在系统外发布。

## 功能规则

- 不显示发布账号、自动发布时间、发布状态、阅读、曝光、线索或结果回收。
- 未确认事实和非 active VI 不进入生成。
- 编辑或重新生成创建新版本并回到待审核。
- 正式导出必须基于 approved 版本；草稿仅可导出带水印预览。

## 异常与边界

- 无正式知识：允许生成通用结构，但缺失事实留空并提示补充。
- 图片生成失败：正文继续可编辑，支持单图重试或上传替换。
- 素材授权不明：阻止正式导出。
- 导出失败：保留approved版本，可仅重试打包。

## 字段交互 / 取值

### 内容主题或活动目标

多行输入，提交创建时保存。字段键：`topic`。取值：5–500字符，必填。默认空。校验为空提示“请输入内容主题或活动目标”。运营可编辑。

### 目标受众

单行输入+历史标签建议。字段键：`audience`。取值：2–100字符，必填。默认来自任务上下文或空。

### CTA

单行输入。字段键：`cta`。取值：0–80字符，可为空。默认读取企业内容规范；无规范为空，不自动编造联系方式。

### 参考图片

多文件上传，选择后本地预览。字段键：`reference_assets`。取值：JPG/PNG/WebP，单张≤10MB，最多10张。校验格式/大小/授权声明；保存为受控素材引用。

### 企业知识版本

只读链接。字段键：`knowledge_version_id`。取值：最新formal版本，必填；任务创建后冻结。

### 企业 VI 版本

只读链接。字段键：`vi_version_id`。取值：active版本；可为空。为空时使用系统默认主题并提示未启用VI。

### 图文名称

列表主字段。字段键：`title`。取值：2–60字符。点击打开预览；过长省略。

### 内容构成

只读摘要。字段键：`deliverables`。取值：封面/正文/配图数量/CTA；生成中显示进度。

### 状态

状态标签。字段键：`status`。取值：draft/generating/pending_review/approved/exported/failed。

### 新建朋友圈图文

主按钮，有创建权限时显示。点击打开表单；提交后loading并使用幂等键，成功返回列表。

### 预览

draft及以后显示。打开当前版本图文预览并标记草稿/审核状态。

### 编辑

运营且非导出锁定态可用。编辑标题、正文、CTA、封面和配图；自动保存草稿。

### 提交审核

必填内容完整且生成结束后可用。点击进入pending_review；重复点击不重复创建审批。

### 导出图文包

approved时可用。输出图片、正文、CTA、版本和使用说明；成功写exported记录，不产生发布记录。

## 状态与权限

`draft → generating → pending_review → approved → exported`；任一生成步骤可进入failed；编辑后回pending_review。运营创建编辑，审核人批准，只有授权角色导出。

## 数据与接口

对象：`moments_task`、`moments_version`、`image_asset`、`content_review`、`export_package`。版本包含topic、audience、title、body、cta、asset_ids、knowledge_version_id、vi_version_id、risk_flags、status、version、created_by/at。

接口：`GET/POST /moments`、`GET/PATCH /moments/{id}`、`POST /{id}/generate`、`POST /{id}/submit-review`、`POST /{id}/approve|reject`、`POST /{id}/export`。错误码：`FACT_GAP`、`ASSET_LICENSE_UNKNOWN`、`IMAGE_GENERATION_FAILED`、`REVIEW_REQUIRED`、`EXPORT_FAILED`、`VERSION_CONFLICT`。

## Skill / Prompt

Skill：`content-context-builder`、`moments-content-generator`、`image-generator`、`content-compliance-checker`。

```text
你是企业朋友圈图文编辑。只使用 confirmed_facts、active_vi 和 authorized_assets。
输出 title、body、image_plans、cta、evidence_refs、risk_flags、missing_inputs。语言自然、适合熟人社交，不伪造价格、案例、地址、效果和客户评价。事实不足时留空并提示，不生成发布动作或效果指标。
```

## 埋点事件

`moments_page_viewed`、`moments_created`、`moments_generation_failed`、`moments_review_submitted`、`moments_approved`、`moments_exported`；属性包含task_id、version、image_count、error_code。

## 验收标准

1. DOM与接口模型均无发布账号、自动发布和效果数据字段。
2. 编辑后状态回待审核，旧approved版本保留。
3. 未审核或授权不明素材无法正式导出。
4. 导出包内容、图片和版本一致，不创建publish_task。

## 核心指标

- 草稿生成成功率≥95%。
- 审核通过率上线后建立基线。
- 正式导出成功率≥99%。
- 错误发布入口出现率0%。
