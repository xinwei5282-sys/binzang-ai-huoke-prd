# 页面 PRD：AI 获客 / 获客计划

> 页面 ID：`plan`｜版本：v1.1｜优先级：P0｜日期：2026-09-01｜上位：[[../PRD_AI获客]]

## 页面概述

| 项目 | 说明 |
|---|---|
| 页面目标 | 把已确认经营目标拆成可审核、可执行、可复盘的获客计划。 |
| 适用角色 | 企业负责人审核；增长/运营负责人编排；执行成员更新进度；只读成员查看。 |
| 页面入口 | `AI 获客 → 获客计划`，或从经营计划行动进入。 |
| 权限要求 | 查看、编辑、审核和启用分权；执行成员只能更新分配给自己的任务。 |

## 页面级业务规则

- 每个获客计划关联零或一个经营计划行动；无关联时必须填写目标依据。
- AI 只生成 `draft`，未确认事实、预算、指标或承诺进入信息缺口。
- 渠道只表示策略偏好，真正发布时必须重新选择具体账号和发布方式。
- 计划启用后修改产生新版本，历史版本和生成依据不可覆盖。
- 缺少目标客户、核心指标或负责人时不得提交审核。

## 页面字段

| 字段 | 类型 | 必填/展示规则 | 业务口径 |
|---|---|---|---|
| 计划名称 | 文本 | 2–80字，必填 | 默认“周期 + 获客计划”。 |
| 关联经营行动 | 选择器 | 可空 | 仅可选择同租户 `active` 行动，选择后带入目标与周期。 |
| 目标客户 | 多行文本+建议 | 5–500字，必填 | AI 建议须人工采用，不得虚构具体客户属性。 |
| 阶段目标 | 多行文本 | 5–300字，必填 | 不得填写无依据 ROI 或成交承诺。 |
| 计划周期 | 日期范围 | 必填，最长一年 | `start_at < end_at`。 |
| 渠道 | 多选 | 至少一项 | `wechat/douyin/xiaohongshu/offline/other`，不等于发布账号。 |
| 预算上限 | 金额 | 可空，CNY | 超过租户护栏时需负责人确认。 |
| 核心指标 | 指标组 | 至少一项 | 包含名称、目标、单位和真实基线或基线缺口。 |
| 负责人 | 成员选择 | 必填 | 仅同租户 `active` 成员。 |
| 任务列表 | 表格 | 计划生成后展示 | 名称、类型、负责人、截止时间、状态和关联内容。 |

## 操作与结果

| 按钮/操作 | 展示条件 | 执行结果 | 权限与记录 |
|---|---|---|---|
| 新建计划 | 有编辑权限 | 创建 `draft` | 写创建人和输入版本。 |
| AI 生成草案 | 必填字段完整 | 生成任务、指标、风险和信息缺口 | 保存 Prompt、知识和经营计划版本。 |
| 提交审核 | 草案校验通过 | `draft → pending_confirmation` | 写提交人和风险快照。 |
| 确认启用 | 审核通过且缺口关闭 | `pending_confirmation → active` | 仅负责人可用，写审核记录。 |
| 创建内容任务 | 计划已启用 | 跳转对应营销视频、AI 混剪或其他内容页 | 不创建发布任务。 |
| 归档 | 已完成或停止 | `active/completed → archived` | 保留历史版本和结果。 |

## 产品边界

获客计划负责目标、任务和衡量口径，不自动选择平台账号、不执行发布、不承诺增长结果。模型和外部数据未接入时，页面只能展示原型流程和示例数据。

## 状态与跳转

- `draft → pending_confirmation → active → completed → archived`
- `draft/pending_confirmation → 信息缺口 → 补充或修改 → 重新提交`
- `active → 创建内容任务 → 营销视频或 AI 混剪 → 人工审核 → 发布任务`

## 通知与日志

- 提交审核、退回、启用、预算护栏和计划到期通知负责人。
- 记录 `acquisition_plan_created/generated/reviewed/activated/archived` 与 `acquisition_task_created`。
- 属性包含计划版本、经营行动版本、风险数量和操作者，不记录生成正文全文。

## 异常与空状态

| 场景 | 页面表现 |
|---|---|
| 首次无计划 | 解释计划与经营行动关系，提供新建入口。 |
| 必填字段缺失 | 就地标错并聚焦第一个缺失项，不创建生成任务。 |
| 预算超护栏 | 阻止启用，展示差额和负责人确认入口。 |
| 关联行动失效 | 标记待修复，可解除或重新关联。 |
| 版本冲突 | 保留当前输入，提示刷新并对比新版本。 |
| 生成失败 | 保留输入、失败原因和重试入口。 |

## 页面验收标准

1. 缺目标客户、指标或负责人时不能提交审核。
2. AI 草案明确显示证据、缺口和风险，不直接启用。
3. 启用计划不会自动创建发布记录。
4. 内容任务发布时仍必须选择具体账号和方式。
5. 修改已启用计划会产生新版本，历史版本可追溯。

## 技术评估项

- 核心对象：`acquisition_plan/acquisition_task/plan_metric/plan_review`。
- 接口：`GET/POST /acquisition-plans`、`PATCH /{id}`、`POST /{id}/generate|review|activate|archive`。
- 写接口携带 `tenant_id/input_version/idempotency_key`；版本冲突返回 `VERSION_CONFLICT`。
- 生成任务保存企业知识、经营行动、Prompt 和用户约束快照。
- 指标基线缺失时保存 `baseline_status=missing`，不得补写虚假数值。

# 详细执行契约（保留）

## 问题

企业获客动作常与经营目标、目标客户、负责人和渠道资源脱节；计划若直接发布又会绕过账号选择和人工确认。

## 目标

把经营计划拆成可执行的获客计划、内容任务和衡量指标，但不自动选择账号、不自动外发。

## 目标用户

企业负责人审核计划；增长/运营负责人编排任务；执行成员更新进度；只读成员查看。

## 用户流程

进入列表 → 新建计划 → 选择经营目标/周期/受众/渠道 → AI生成草案 → 人工编辑审核 → 启用 → 创建内容任务 → 跟踪复盘。

## 功能规则

- 每个获客计划关联0或1个经营计划行动；无关联时必须手填目标依据。
- 渠道任务只保存平台偏好，真正发布时必须重新选择具体账号和方式。
- 未确认事实、预算和承诺进入缺口，不得形成正式任务。
- 计划启用后修改产生新版本。

## 异常与边界

无目标客户、指标或负责人不能提交审核；预算超护栏阻止启用；关联经营行动失效时标记待修复；并发修改返回版本冲突。

## 字段交互 / 取值

### 计划名称
文本输入，失焦保存。字段键：`name`。取值2–80字，必填；默认“周期+获客计划”。

### 关联经营行动
选择器。字段键：`operating_plan_action_id`。取值同租户active行动，可为空；选择后带入目标和建议周期。

### 目标客户
多行输入+企业画像建议。字段键：`target_audience`。取值5–500字，必填；AI建议需人工采用。

### 阶段目标
多行输入。字段键：`objective`。取值5–300字，必填；不得写未经确认ROI承诺。

### 计划周期
日期范围。字段键：`start_at/end_at`。开始<结束且最长1年；必填。

### 渠道
多选。字段键：`channels`。取值wechat/douyin/xiaohongshu/offline/other；至少1项；不等于发布账号。

### 预算上限
金额输入。字段键：`budget_limit`。取值≥0，币种CNY；可为空；超过租户护栏需负责人确认。

### 核心指标
指标组。字段键：`metrics[]`。每项含name/target/unit；至少1项；禁止用虚构基线。

### 负责人
成员选择器。字段键：`owner_id`。取值active成员，必填。

### 任务列表
展示任务名称、类型、负责人、截止时间、状态、关联内容。字段键：`tasks[]`；支持新增、排序、拆分和进入对应页面。

### 生成获客计划
主按钮；字段完整后调用AI生成draft，loading防重复。

### 提交审核/确认启用
分别进入pending_confirmation和active；高风险、预算、缺口未关闭时阻止启用。

## 状态与权限

`draft → pending_confirmation → active → completed | archived`。负责人审核启用；运营编辑草案和任务；执行人只更新被分配任务。

## 数据与接口

对象：`acquisition_plan`、`acquisition_task`、`plan_metric`、`plan_review`。接口：`GET/POST /acquisition-plans`、`PATCH /{id}`、`POST /{id}/generate|review|activate|archive`、`POST/PATCH /{id}/tasks`。错误码：`METRIC_REQUIRED`、`BUDGET_GUARDRAIL`、`FACT_GAP`、`OWNER_INVALID`、`VERSION_CONFLICT`。

## Skill / Prompt

```text
你是企业获客策划。仅使用 confirmed_facts、approved_operating_plan 和 user_constraints。输出目标客户、阶段目标、渠道策略、任务、负责人角色、时间、指标、预算风险、evidence_refs、missing_inputs。不得选择具体发布账号、不得执行发布、不得承诺ROI。
```

## 埋点事件

`acquisition_plan_created/generated/reviewed/activated`、`acquisition_task_created`、`budget_guardrail_triggered`；属性含plan_id、channel_count、task_type、risk_count。

## 验收标准

1. 缺目标客户、指标、负责人时不能审核。
2. 启用计划不会自动创建发布记录。
3. 任务进入发布时仍必须选择具体账号和方式。
4. 历史版本与依据可追溯。

## 核心指标

计划字段完整率100%；审核通过率和按期完成率上线后建立基线；绕过账号选择的发布任务数0。
