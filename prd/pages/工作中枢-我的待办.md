# 页面 PRD：工作台 / 我的待办

> 页面 ID：`work-tasks`｜稳定路由：`workhub`｜版本：v1.2｜状态：原型已联通｜更新日期：2026-09-07
> 关联：[[工作中枢-项目]]、[[工作中枢-客户]]、[[企业大脑-会议纪要]]

## 问题

任务来自会议纪要、客户跟进、项目冲突和 Agent 生成，平铺后难以判断每个项目的整体进度；日期只以文字展示，也不方便调整排期。首页与任务页如果各自维护数据，还会出现状态不一致。

## 目标用户

老板、员工和任务负责人。用户需要先在首页快速了解今日重点，再进入工作台处理完整任务；两处必须使用同一账号范围和同一任务数据。

## 用户流程

首页查看今日待办与项目摘要 → 在周日历拖动任务调整时间 → 进入工作台 → 按“我的、团队、客户、当前项目、执行中、失败”筛选 → 按项目汇总或切换平铺列表 → 查看会议/冲突来源 → 确认或运行任务 → 进入 PPT、报价、合同或话术交付物。

## 功能规则

1. 一级导航显示“首页 → 工作台 → 品牌与经营”，内部路由继续使用 `workhub`，避免破坏既有深链。
2. 首页和工作台共享 `WORK_HUB_TASKS`；首页是精简视图，工作台是完整视图，不复制任务记录。
3. 默认按 `projectId` 汇总，组头展示项目名、客户、任务数和未完成数；无项目任务统一进入“日常待办”。
4. 日历按本周七天和 09:00、14:00、18:00 三个时间槽展示。桌面可拖拽，触屏或键盘用户可点击“调整时间”。
5. 两种排期方式都更新 `scheduledDate`、`scheduledTime` 与展示字段 `dueAt`，并立即刷新首页和工作台。
6. Agent 生成动作必须形成可追溯子待办；PPT 继续进入营销物料 / PPT，不在任务页伪造文件。

## 异常与边界

- 无项目任务不报错，归入“日常待办”。
- 当前项目未选择时，“当前项目”筛选显示空态，不扩大到所有项目。
- 触屏浏览器不支持原生拖拽时，使用“调整时间”表单完成相同操作。
- 当前原型只在内存中模拟排期；不接真实日历、通知、自动外发或服务器持久化。

## 字段交互/取值

- `Task`：`id`、`tenantId`、`ownerAccountId`、`customerId`、`projectId`、`parentTaskId`、`status`。
- 来源：`sourceMeetingId`、`sourceConflictId`、`evidenceTimestamp`。
- 排期：`scheduledDate`（YYYY-MM-DD）、`scheduledTime`（HH:mm）、`dueAt`（中文展示值）。
- 状态：`pending | running | ready | failed`；未完成数为状态不等于 `ready` 的任务数量。
- 视图：`taskGroupMode = project | flat`；默认 `project`。

## 状态与权限

先按 `tenantId` 隔离，再按系统角色的工作台 grant、`all | team_self | self` 数据范围以及项目成员关系过滤。首页与工作台都使用同一 `canCurrentAccountSeeWorkItem` 判断。员工的私人任务仅本人可见，项目任务只对有项目访问权的成员可见。

## 数据与接口

原型以 `WORK_HUB_TASKS` 为任务真源。生产建议使用 `GET /tasks?scope=&projectId=&status=` 与 `PATCH /tasks/:id/schedule`；排期写入需要服务端重新鉴权、乐观锁版本和审计记录，避免多人同时拖动造成覆盖。

## Skill / Prompt

任务生成 Prompt 输入会议行动项、项目上下文和证据引用，输出结构化 `title`、`ownerAccountId`、`projectId`、`dueAtCandidate`、`sourceRefs` 和 `deliverableType`。AI 只给候选负责人和时间；员工确认或调整后才成为正式排期。

## 埋点事件

`home_task_overview_viewed`、`task_group_mode_changed`、`task_calendar_drag_started`、`task_schedule_changed`、`task_schedule_form_opened`、`project_task_opened`、`task_source_opened`、`task_confirmed`、`agent_task_started`。记录账号、任务、项目、原时间、新时间和入口。

## 验收标准

1. 工作中枢的用户可见名称全部改为“工作台”，并位于首页下方。
2. 首页展示“今日待办 + 项目汇总 + 本周日历”，工作台展示完整筛选和同一批任务。
3. 默认项目汇总正确，无项目任务出现在“日常待办”，可切换为平铺列表。
4. 拖动任务到 2026-09-11 14:00 后，任务显示“9月11日 14:00”，首页与工作台同步。
5. “调整时间”表单可完成与拖拽相同的变更。
6. 1440×900 下列表与日历双栏显示；390×844 下上下堆叠且日历可横向滚动。

## 核心指标

首页到工作台进入率、项目待办完成率、排期覆盖率、拖拽/表单调整成功率、逾期率、会议行动项转待办率和任务到交付物转化率；上线后建立基线。
