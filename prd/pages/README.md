## 当前页面评审结构（2026-09-01）

AI 获客页面及后续新增页面统一按浏览器页面 PRD 抽屉的阅读顺序编写：

1. 页面概述：页面目标、适用角色、页面入口、权限要求。
2. 页面级业务规则：当前页面必须保持的业务判断与人工门。
3. 页面字段：字段、类型、必填或展示规则、业务口径。
4. 操作与结果：按钮或操作、展示条件、执行结果、权限与记录。
5. 产品边界：原型、生产、外部能力和禁止事项。
6. 状态与跳转：主要状态机和跨页面路径。
7. 通知与日志：通知对象、埋点和审计属性。
8. 异常与空状态：无权限、空数据、失败、超时和降级。
9. 页面验收标准：可执行操作与预期结果。
10. 技术评估项：对象、接口、版本、幂等、性能和外部依赖。

旧模板中的问题、目标、数据接口、Skill/Prompt、核心指标等详细内容可以保留在“详细执行契约”中，但页面评审区必须先按上述十段提供完整口径。

## 页面 PRD 统一结构

每份页面 PRD 按用户确认的阅读顺序编写，缺一项视为未完成：

### 问题

说明当前用户为什么需要这个页面、现状有什么阻碍。

### 目标

说明页面本期要达成的结果，不写实现手段。

### 目标用户

逐项列出角色及其使用目的。

### 用户流程

从进入页面到完成核心任务，按真实操作顺序逐步描述。

### 功能规则

写清保留、删除、限制、人工门、版本和跨页面规则。

### 异常与边界

覆盖空数据、权限不足、处理中、失败、超时、并发、外部能力不可用和降级。

### 字段交互 / 取值

每个字段或按钮独立成项，至少写：

```text
字段/按钮中文名
控件与交互方式；选择、输入、保存和联动行为
字段键：field_key
取值：枚举 / 字符长度 / 数字范围 / 日期规则 / 可为空与否
默认：默认值或默认逻辑
校验：触发时机、错误文案和失败后行为
权限：哪些角色可见、可编辑或只读
```

展示字段、筛选、排序、分页、按钮、弹层和状态标签都按同样方式写，不能只写输入框。

### 状态与权限

写完整状态机、状态进入/退出条件、各状态允许操作、审批角色和审计要求。

### 数据与接口

列出数据对象完整字段、主外键、唯一约束、版本、软删除；接口写方法、路径、请求/响应、错误码、幂等和并发。

### Skill / Prompt

写触发条件、输入、输出 Schema、版本、人工门、失败降级及完整可复制 Prompt；不使用 AI 的页面明确写“不调用”。

### 埋点事件

逐项写事件名、触发时机和关键属性。

### 验收标准

使用可执行的操作与预期结果，不写“功能正常”。

### 核心指标

写清指标名称、统计口径和目标值；暂无基线时标记“上线后建立基线”，不得虚构。
