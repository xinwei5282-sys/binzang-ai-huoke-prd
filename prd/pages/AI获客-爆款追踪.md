# 页面 PRD：AI 获客 / 爆款追踪

> 页面 ID：`burst`｜版本：v1.1｜优先级：P0｜日期：2026-09-01｜上位：[[../PRD_爆款抓取]]

## 页面概述

| 项目 | 说明 |
|---|---|
| 页面目标 | 从公开来源持续发现、去重、转写和拆解内容模式，形成可追溯的选题候选。 |
| 适用角色 | 运营搜索和采用；负责人配置对标范围；审核人检查来源与版权。 |
| 页面入口 | `AI 获客 → 爆款追踪`，或从营销视频选择参考内容时进入。 |
| 权限要求 | 查看、采集、分析和采用分权；来源配置仅负责人可改。 |

## 页面级业务规则

- 只处理公开可访问内容，不绕过登录、验证码、付费墙或访问限制。
- 标题、发布时间、公开指标和原始链接必须保留来源；不可验证值显示“—”。
- 原文只供内部研究；采用的是结构和选题候选，不是企业硬事实。
- 空转写、重复 URL、来源失效和采集失败不得标记完成。
- 将候选带入营销视频或 AI 混剪后，仍须重新生成企业表达并完成人工审核。

## 页面字段

| 字段 | 类型 | 必填/展示规则 | 业务口径 |
|---|---|---|---|
| 采集模式 | 页签 | 默认关键词 | `keyword/account/ranking`，切换保留各模式输入。 |
| 平台 | 单选 | 必填 | 仅展示已配置公开数据能力和覆盖说明。 |
| 关键词 | 标签输入 | 关键词模式必填 | 每项2–30字，最多20项。 |
| 对标账号 | 账号或公开链接 | 账号模式必填 | 最多20个，保存 canonical 账号 ID。 |
| 时间范围 | 单选 | 默认7天 | `7/30/90` 天。 |
| 排序 | 单选 | 默认相关性 | 发布时间、互动或相关性。 |
| 候选内容 | 表格/卡片 | 采集后展示 | 封面、标题、来源账号、时间、指标、相关性、证据级别和状态。 |
| 原始来源 | 外链 | 候选必显 | 失效时展示最后快照和失效标记。 |
| 拆解结果 | 结构化内容 | 分析完成后展示 | Hook、受众、结构、论点、画面模式、CTA、风险和来源。 |

## 操作与结果

| 按钮/操作 | 展示条件 | 执行结果 | 权限与记录 |
|---|---|---|---|
| 开始采集 | 条件完整 | 创建异步采集任务 | 写模式、平台、范围和消耗预估。 |
| 查看来源 | 有原始链接或快照 | 打开公开来源或最后快照 | 记录来源查看，不复制全文。 |
| 转写/拆解 | 内容可处理 | 创建提取与分析任务 | 保存模型/ASR版本和来源快照。 |
| 采用为选题 | `pending_review` | 生成 `topic_candidate` | 需内容权限，保留 `source_ref`。 |
| 忽略 | 待审核候选 | 状态改为 `ignored` | 可填写原因，不删除候选。 |
| 重试 | `failed` | 仅重试失败阶段 | 保留原输入和失败原因。 |

## 产品边界

爆款追踪是公开内容研究与选题工具，不是爬虫绕过工具、版权复制工具或企业事实来源。未接入真实数据平台时必须显示演示数据，不得把示例互动量描述为实时结果。

## 状态与跳转

- `discovered → extracting → extracted → analyzing → pending_review → adopted | ignored`
- `extracting/analyzing → failed → retrying → pending_review`
- `adopted → 营销视频或 AI 混剪 → 企业事实替换 → 人工审核`

## 通知与日志

- 采集完成、批量失败和来源受限通知发起人；普通单条去重不单独通知。
- 记录 `trend_collection_started/failed`、`trend_source_opened`、`trend_analyzed`、`trend_adopted/ignored`。
- 审计属性包含平台、canonical URL、来源快照、证据级别和错误码，不保存登录凭据。

## 异常与空状态

| 场景 | 页面表现 |
|---|---|
| 无候选 | 说明关键词、账号和时间范围，并提供修改条件入口。 |
| 来源失效 | 展示最后采集快照与失效时间，不伪造实时指标。 |
| 无字幕或正文 | 标记提取失败，提供人工补充或忽略。 |
| 重复内容 | 合并到 canonical 候选并展示重复来源数量。 |
| QPS/配额超限 | 显示可重试时间和消耗说明，不循环重试。 |
| 受限页面 | 阻止采集并说明访问边界。 |

## 页面验收标准

1. 每条候选的来源、发布时间和采集时间可追溯。
2. 重复内容合并，空转写不进入完成态。
3. 采用候选不会写入企业硬事实或复制长段原文。
4. 受限页面不采集，无法验证的指标显示“—”。
5. 候选进入创作页后仍经过事实替换和人工审核。

## 技术评估项

- 核心对象：`trend_collection/trend_candidate/transcript/topic_candidate`。
- 唯一约束使用 `platform + external_content_id`，无外部 ID 时使用 canonical URL。
- 抽取、ASR、拆解和采用拆为可重试阶段，单阶段失败不重跑已完成阶段。
- 写接口携带 `tenant_id/input_version/idempotency_key`，外部请求遵守速率和来源条款。
- 公开指标保存采集时间和可验证状态，不把缺失值转换为零。

# 详细执行契约（保留）

## 问题

运营缺少持续、可追溯的公开趋势来源，容易把偶然热度当成企业事实或直接复制他人内容。

## 目标

从公开来源发现、去重、转写和拆解内容模式，形成选题候选；保留来源和版权边界。

## 目标用户

运营搜索和采用选题；负责人配置对标范围；审核人检查来源与版权。

## 用户流程

选择关键词/账号/榜单 → 设置平台与时间 → 发起采集 → 查看列表与证据 → 转写/拆解 → 采用为选题或忽略。

## 功能规则

只采集公开可访问内容；不绕过登录、验证码、付费墙和访问控制。原内容只供内部研究，采用结果不是企业硬事实，生成新内容仍需事实和合规审核。

## 异常与边界

页面失效、无字幕、转写空、指标不可验证、重复URL、配额/QPS超限分别显示状态；不得用AI补造原文或热度。

## 字段交互 / 取值

### 采集模式
页签。字段键：`mode`。取值keyword/account/ranking；默认keyword；切换保留各模式输入。

### 平台
单选。字段键：`platform`。取值已配置的公开数据平台；必填；显示能力和覆盖说明。

### 关键词
文本/标签输入。字段键：`keywords[]`。每项2–30字，最多20项；keyword模式至少1项。

### 对标账号
账号名称或公开链接列表。字段键：`benchmark_accounts[]`。最多20个；account模式至少1个；保存canonical账号ID。

### 时间范围/排序
下拉。字段键：`date_range/sort`。时间7/30/90天；排序按发布时间/互动/相关性；默认7天+相关性。

### 采集按钮
创建异步collection任务；loading防重复；消耗预估在提交前显示。

### 候选列表字段
封面、标题、来源账号、发布时间、采集时间、公开指标、相关性、证据级别、状态。字段键：`candidate.*`；不可验证指标显示“—”。

### 原始来源
链接按钮。字段键：`source_url`。新窗口打开；失效时显示最后采集快照和失效标记。

### 转写/拆解
按能力显示；触发ASR/正文提取和结构分析。字段键：`extract/analyze`；空结果进入failed，不进入完成。

### 采用为选题/忽略
采用生成topic_candidate并保留source_ref；忽略填写可选原因，不删除原候选。

## 状态与权限

`discovered → extracting → extracted → analyzing → pending_review → adopted | ignored | failed`。运营采集分析；负责人配置来源；采用需内容权限。

## 数据与接口

对象：`trend_collection`、`trend_candidate`、`transcript`、`topic_candidate`。接口：`POST /trend-collections`、`GET /trend-candidates`、`POST /{id}/extract|analyze|adopt|ignore|retry`。唯一约束platform+external_content_id或canonical_url。

## Skill / Prompt

Skills：公开采集、defuddle/ASR、去重、内容拆解。
```text
分析公开内容并输出hook、audience、structure、arguments、visual_pattern、cta、transferable_pattern、risk_flags、relevance、source_refs、fact_or_inference。不得复制长段原文，不得虚构指标；可迁移模式仅作为选题候选。
```

## 埋点事件

`trend_collection_started/failed`、`trend_source_opened`、`trend_analyzed`、`trend_adopted/ignored`；属性含mode、platform、result_count、error_code。

## 验收标准

来源、发布时间和采集时间可追溯；重复内容合并；空转写不标完成；采用不写企业硬事实；受限页面不采集。

## 核心指标

可追溯来源率100%；去重准确率上线后建立基线；转写空结果误完成率0%；选题采用率仅观察。
