# 页面 PRD：企业大脑 / 进化与治理

> 页面 ID：`evolution`｜版本：v1.0｜优先级：P1｜上位：[[../PRD_企业大脑]]

## 问题

经营结果和内容数据可以推动企业知识优化，但若系统自动学习并覆盖规则，会把偶然数据、错误归因或未经审核建议放大。

## 目标

汇总学习候选、规则版本、采用记录和效果复盘；所有进化建议经人工审核后生效，并支持回滚和审计。

## 目标用户

企业负责人批准高影响调整；知识管理员审核候选；业务负责人评估专业建议；审计人员查看变更链路。

## 用户流程

进入进化与治理 → 查看候选和风险 → 打开候选证据、影响范围与建议变更 → 编辑/采用/驳回 → 创建新规则或知识版本 → 观察效果 → 保留或回滚。

## 功能规则

- 候选可来自文章阅读/分享、获客转化、经营计划结果、人工反馈和知识冲突。
- 数据只用于生成建议，不自动修改企业事实、Prompt、发布规则或权限。
- 每次采用必须记录证据、决策人、影响对象、旧值、新值和回滚点。
- 高风险调整（价格、承诺、权限、自动发布）必须负责人二次确认。
- 本页不展示Agent授权和上传资料入口。

## 异常与边界

样本不足时标记不可采用；数据归因不清时仅展示观察；来源被删除仍保留审计快照；版本冲突需重新评估；回滚不删除后续审计；敏感数据按角色脱敏。

## 字段交互 / 取值

### 候选类型
筛选。字段键：`candidate_type`。取值knowledge_update/prompt_update/rule_update/strategy_update；可多选。

### 风险等级
筛选与标签。字段键：`risk_level`。取值low/medium/high/critical；high以上需负责人批准。

### 学习候选
列表。字段键：`evolution_candidates[]`。显示标题、类型、来源指标、样本范围、置信度、风险、状态、创建时间。

### 证据与样本
只读详情。字段键：`evidence_refs[]`。包含指标定义、时间窗、样本数、分母、来源对象和异常说明。

### 当前规则
只读对比左栏。字段键：`current_value`。显示对象ID、版本、现有内容和引用范围。

### 建议调整
可编辑对比右栏。字段键：`proposed_value`。必须标注改动、理由、预期影响和验证周期。

### 影响范围
多选只读/确认。字段键：`impact_scope`。取值knowledge/prompt/plan/content/publishing；由系统计算，审核人确认。

### 采用
主按钮。字段键：`adopt_evolution`。证据充分、验证计划完整时可用；创建新版本，不覆盖旧版本。

### 驳回
次按钮。字段键：`reject_evolution`。原因必选：样本不足/归因不清/不符合策略/风险过高/重复/其他。

### 观察
按钮。字段键：`defer_evolution`。设置复查日期和触发条件，状态进入observing。

### 回滚版本
危险操作。字段键：`rollback_version`。仅管理员可用；需选择目标版本、填写原因并二次确认。

### 效果复盘
结果卡。字段键：`evaluation`。显示验证周期、基线、实际值、变化、置信度和结论；无分母不显示百分比。

## 状态与权限

候选：`candidate → reviewing → adopted | rejected | observing`；版本：`active → superseded | rolled_back`。知识负责人审核，负责人批准高风险，审计只读。

## 数据与接口

对象：`evolution_candidate`、`evolution_evidence`、`governed_version`、`approval_record`、`evaluation_result`。接口：`GET /governance/candidates`、`POST /{id}/adopt|reject|defer`、`POST /governed-versions/{id}/rollback`。错误码：`SAMPLE_INSUFFICIENT`、`ATTRIBUTION_UNCLEAR`、`HIGH_RISK_APPROVAL_REQUIRED`、`VERSION_CONFLICT`。

## Skill / Prompt

```text
你是企业经营学习分析器。基于经过定义的 metrics 和 evidence_refs 生成候选，不得把相关性写成因果。输出现状、建议、样本范围、置信度、风险、影响范围、验证计划和回滚条件。禁止自动应用任何调整。
```

## 埋点事件

`governance_page_viewed`、`evolution_candidate_opened`、`evolution_adopted/rejected/deferred`、`version_rolled_back`、`evaluation_completed`；属性含type、risk_level、sample_size、decision_role。

## 验收标准

1. 所有候选都显示证据、样本和风险。
2. 采用只创建新版本，不覆盖旧版本。
3. 高风险变更无法绕过负责人确认。
4. 可从当前版本回溯决策和回滚点。
5. 页面无Agent授权和上传资料入口。

## 核心指标

自动生效变更数0；版本可回滚率100%；高风险审批覆盖率100%；无证据候选采用数0。
