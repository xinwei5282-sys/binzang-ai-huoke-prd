# 页面 PRD：设置 / 用量与套餐

> 页面 ID：`usage`｜版本：v1.0｜优先级：P1｜上位：[[../PRD_设置与治理]]

## 问题

企业需要知道各能力消耗、额度和费用，但若只展示模糊总量或把模型成本与服务费混为一谈，无法预算和核对。

## 目标

展示套餐权益、能力用量、剩余额度、成本拆分和明细；支持阈值提醒与超额护栏，不虚构实时计费。

## 目标用户

企业负责人查看预算；管理员配置提醒；财务核对账单；成员查看本人或授权范围用量。

## 用户流程

进入用量与套餐 → 选择账期和能力 → 查看套餐、额度、趋势和明细 → 下载账单 → 设置告警 → 需要升级时提交联系/变更申请。

## 功能规则

- 用量按能力计量：AI生成、诊断、PPT导出、图片/视频、公开采集、RPA执行、存储等。
- 模型/供应商成本、平台服务费、增值服务费分开显示。
- 每条用量记录有幂等键和来源任务，失败且未产生资源的任务不计费。
- 原型或未接计费接口时明确标注演示数据，不显示为真实账单。

## 异常与边界

供应商账单延迟时标记预计值；退款/冲正用反向记录不改原记录；跨账期任务按实际发生时间归属；额度耗尽时按策略阻止或申请批准；下载失败可重试。

## 字段交互 / 取值

### 当前套餐
只读卡。字段键：`plan`。显示套餐名、生效期、计费周期、状态和主要权益；状态trial/active/past_due/cancelled。

### 账期
月份选择。字段键：`billing_period`。最多查询近24个月；默认当前账期。

### 能力类型
多选筛选。字段键：`capability_type`。取值text/image/video/diagnosis/ppt_export/public_collection/rpa/storage等。

### 用量卡
统计卡。字段键：`usage_summary[]`。每项含used、quota、unit、remaining、estimated_cost、updated_at；无额度上限显示“按量”。

### 用量趋势
图表。字段键：`usage_series`。按日/周展示实际记录；缺数据不补零以外的虚构值，支持悬停查看分母。

### 用量明细
表格。字段键：`usage_records[]`。显示时间、能力、任务、成员、数量、单位、供应商成本、服务费、状态和幂等键。

### 费用拆分
只读汇总。字段键：`cost_breakdown`。分provider_cost/service_fee/add_on_fee/tax/adjustment；币种和含税口径明确。

### 告警阈值
多值输入。字段键：`alert_thresholds`。取值50/80/90/100或自定义1–100%，递增且不可重复；默认80、100。

### 告警接收人
成员多选。字段键：`alert_recipients`。至少1名active管理员；默认企业管理员。

### 超额策略
单选。字段键：`overage_policy`。取值block/owner_approval/allow_if_plan_supports；默认block。

### 下载明细
按钮。字段键：`download_usage_statement`。格式CSV/XLSX/PDF；生成异步文件并记录审计。

### 套餐变更
按钮。字段键：`change_plan`。仅管理员/负责人可用；首版提交申请，不伪装为即时支付成功。

## 状态与权限

用量记录：`estimated → settled | reversed`；套餐：`trial → active → past_due | cancelled`。负责人/管理员看费用，成员仅看本人非费用用量，财务看账单。

## 数据与接口

对象：`subscription`、`plan_entitlement`、`usage_record`、`billing_statement`、`usage_alert_rule`。接口：`GET /settings/usage/summary|records|statements`、`PATCH /usage/alerts`、`POST /statements/export`。错误码：`QUOTA_EXCEEDED`、`USAGE_NOT_SETTLED`、`STATEMENT_GENERATION_FAILED`、`PERMISSION_DENIED`。

## Skill / Prompt

计量和计费必须由确定性记录计算，不使用大模型。AI仅可解释账单：

```text
仅根据 usage_records 和 billing_rules 解释变动，列出计算公式、时间范围和来源记录；不得预测或编造费用，不得把estimated写成settled。
```

## 埋点事件

`usage_page_viewed`、`usage_filter_changed`、`usage_alert_saved`、`usage_statement_requested/downloaded`、`quota_guardrail_triggered`、`plan_change_requested`；属性含period、capability、threshold、policy。

## 验收标准

1. 每条用量可追溯来源任务和幂等键。
2. 供应商成本与服务费分开。
3. 失败未产出任务不计费。
4. 演示数据显著标识，不冒充真实账单。
5. 额度耗尽按已配置策略执行。

## 核心指标

重复计量数0；账单记录可追溯率100%；费用拆分完整率100%；额度护栏执行准确率100%。
