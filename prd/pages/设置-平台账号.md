# 页面 PRD：设置 / 平台账号

> 页面 ID：`bind`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_设置与治理]]

## 问题

企业可能同时运营多个公众号、抖音和小红书账号；若任务不选择具体账号或凭证缺乏隔离，会导致误发、越权和数据归属错误。

## 目标

支持多平台多账号绑定、能力检测、重新授权和停用；所有发布任务明确选择对应账号和发布方式。

## 目标用户

企业管理员绑定账号；渠道运营使用授权账号；负责人审批高风险发布；审计人员查看连接记录。

## 用户流程

进入平台账号 → 按平台筛选 → 新增绑定 → 选择API授权或RPA → 完成授权与能力检测 → 设置可用范围 → 创建任务时选择具体账号 → 定期检测/重新授权/停用。

## 功能规则

- 支持同一租户绑定多个微信公众号、抖音、小红书账号。
- 账号能力动态展示：发布、定时、草稿、数据回收等，以实际授权结果为准。
- API与RPA均可配置；RPA凭证和会话保存在客户专属执行节点，不回传明文。
- 每个发布任务必须显式保存account_id和publish_method，不能只保存平台。
- 凭证永不在前端回显，日志必须脱敏。

## 异常与边界

授权取消或过期时阻止新发布；账号同平台重复绑定提示转移/恢复；RPA节点离线不创建假成功；账号停用前检查待执行任务；数据回收能力不存在时不展示虚假指标。

## 字段交互 / 取值

### 平台筛选
标签筛选。字段键：`platform`。取值wechat/douyin/xiaohongshu；默认全部。

### 账号名称
文本输入/只读回填。字段键：`account_name`。2–80字；OAuth/API成功后以平台名称为准，RPA可人工填写并校验。

### 平台账号ID
只读脱敏。字段键：`external_account_id`。平台唯一ID，必填；前端仅显示尾4位。

### 发布方式
单选。字段键：`publish_method`。取值api/rpa/manual_export；默认优先api，按平台能力显示可选项。

### 执行节点
选择器。字段键：`connector_id`。RPA时必选同租户online节点；显示最近心跳和版本，不展示机器敏感信息。

### 授权能力
只读能力列表。字段键：`capabilities`。取值draft/publish/schedule/metrics/read/share等；由检测接口返回，不允许手填。

### 可用成员
成员多选。字段键：`allowed_member_ids`。默认仅绑定人和管理员；发布权限仍需角色校验。

### 可用内容类型
多选。字段键：`allowed_content_types`。取值article/video/poster/moments等；按平台能力裁剪。

### 新增账号
主按钮。字段键：`add_platform_account`。选择平台和方式后进入授权；创建pending连接记录。

### 检测连接
按钮。字段键：`test_connection`。检测凭证有效性、能力和节点状态；不产生发布。

### 重新授权
按钮。字段键：`reauthorize_account`。expired/error时显示；成功生成新凭证版本，旧凭证立即撤销。

### 停用账号
危险按钮。字段键：`disable_account`。显示待发布任务数量；确认后阻止新任务，未执行任务转blocked等待改绑。

### 账号状态
状态标签。字段键：`status`。取值pending/active/expired/error/disabled；显示最近检测时间与错误摘要。

## 状态与权限

账号：`pending → active → expired | error | disabled`。管理员绑定/停用；授权运营使用；只有凭证服务和专属节点可解密凭证。

## 数据与接口

对象：`platform_account`、`credential_ref`、`account_capability`、`connector_node`、`account_member_scope`。接口：`GET/POST /settings/platform-accounts`、`POST /{id}/authorize|test|reauthorize|disable`。错误码：`ACCOUNT_DUPLICATE`、`AUTH_EXPIRED`、`CAPABILITY_MISSING`、`CONNECTOR_OFFLINE`、`PENDING_TASKS_EXIST`。

## Skill / Prompt

平台能力和凭证处理不用大模型。任务路由Prompt仅输出候选：

```text
根据 platform、content_type 和 required_capabilities 返回可用 account_ids 及缺失能力说明；不得自行选择最终账号、读取凭证或执行发布，最终账号由用户确认。
```

## 埋点事件

`platform_account_add_started/completed/failed`、`platform_account_tested`、`platform_account_reauthorized`、`platform_account_disabled`、`connector_offline_detected`；属性含platform、method、capability_count、error_code。

## 验收标准

1. 一个平台可绑定多个账号且列表可区分。
2. 创建发布任务必须选择具体账号。
3. 前端、接口响应和日志不出现明文凭证。
4. 节点离线或授权过期时发布被阻止。
5. 无回收能力的账号不显示虚假数据入口。

## 核心指标

明文凭证泄露数0；发布账号归属准确率100%；失效授权阻断率100%；连接检测结果可追溯率100%。
