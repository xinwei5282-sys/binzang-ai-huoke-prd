## 页面概述

平台账号统一展示渠道账号授权状态、到期时间和可用发布方式，为内容审核后的交付建立真实能力边界。

- 目标用户：租户管理员、渠道运营、审计员。
- 页面入口：系统管理 → 平台账号。
- 权限：`account.view`、`account.manage`。
- 当前原型：能力演示，不代表账号已真实连接。

## 页面级业务规则

1. 只有官方 API 完成真实授权、回调验签和端到端验证后才能开放自动发布。
2. 无开放接口的平台保持导出后手动发布，不显示可用的自动发布开关。
3. RPA 必须在人工确认后操作已登录平台，不能绕过平台限制或风控。
4. 凭据由密钥服务托管，不以明文进入页面、Prompt、日志或导出文件。
5. 解绑或授权失效阻止新发布任务，但保留历史发布、结果与审计。
6. 同一租户可绑定多个平台账号；发布任务必须固化具体 `account_id` 与方式。
7. 到期前通知负责人；刷新失败不自动降级为另一账号发布。

## 页面字段级定义

| 字段 | 字段键 | 类型 | 必填 | 规则 | 展示 |
|---|---|---|:---:|---|---|
| 平台 | `platform` | enum | 是 | wechat/douyin/xhs/video_account | 卡片标识 |
| 账号名称 | `account_name` | string | 授权后 | 平台返回显示名 | 可脱敏 |
| 平台账号 ID | `external_account_id` | string | 授权后 | 租户 + 平台内唯一 | 详情展示 |
| 授权状态 | `auth_status` | enum | 是 | pending/authorized/expired/revoked | 徽标 |
| 到期时间 | `expires_at` | datetime | 否 | 平台返回 | 过期前预警 |
| 发布方式 | `publish_methods` | array | 是 | api/rpa/manual | 只显示探测可用项 |
| 自动发布 | `auto_publish` | boolean | 否 | 仅 API 验证通过可开 | 受权限控制 |
| 最近验证 | `verified_at` | datetime | 否 | 能力探测时间 | 详情只读 |

## 页面级操作定义

| 操作 | 权限 | 前置条件 | 结果 | 审计 |
|---|---|---|---|---|
| 绑定新账号 | `account.manage` | 平台可选择 | 创建授权会话 | `account_binding_started` |
| 授权 | `account.manage` | 平台授权页可用 | 回调验签后进入验证 | 不记录 Token |
| 刷新授权 | `account.manage` | 已授权或将到期 | 更新凭据引用与状态 | `account_refreshed` |
| 解绑 | `account.manage` | 无不可中断发布任务 | 阻止新任务、保留历史 | `account_revoked` |
| 开启自动发布 | `publish.manage` | API 端到端验证通过 | 允许审核后创建发布任务 | 高风险操作日志 |
| 手动发布 | `content.export` | 内容审核通过 | 导出内容包 | 导出记录 |

## 产品边界

本页不存储或展示明文 Token、Cookie、密码，不承诺任何平台均支持自动发布，也不负责内容审核。原型不执行真实 OAuth、RPA 或发布；正式能力以平台开放政策和端到端验证结果为准。

## 页面级流程

```text
选择平台 → 创建授权会话 → 跳转平台授权 → 回调验签
→ 保存 credential_id → 能力探测 → 展示账号、状态与发布方式

已授权 → 到期预警 → 刷新授权 → 验签与探测 → 更新状态
```

解绑：确认影响 → 阻止新发布 → 撤销凭据 → 状态改为已失效 → 保留历史。

## 通知与日志

- 授权开始、成功、失败、刷新、过期与解绑写安全/操作日志。
- 到期前 7 天和 1 天通知账号负责人。
- 发布任务只记录 `credential_id`，不记录任何凭据内容。
- 自动发布开关变化记录操作者、账号与旧/新状态。
- 手动导出写导出记录并关联内容版本。

## 异常与空状态

| 场景 | 页面表现 | 恢复动作 |
|---|---|---|
| 未绑定账号 | 展示平台能力和绑定入口 | 发起授权 |
| 平台无 API | 明确“仅手动”，禁用自动发布 | 导出后人工发布 |
| 回调验签失败 | 保持未授权并显示脱敏错误码 | 重新授权 |
| 授权过期 | 标红并阻止新任务 | 刷新授权 |
| 能力探测失败 | 状态为待验证，不宣称已连接 | 重试探测 |
| 解绑时有运行任务 | 提示影响并阻止直接解绑 | 等待或取消任务 |

## 页面验收标准

1. 平台、账号、授权状态、到期时间和发布方式清晰可见。
2. 未授权与待验证状态不得展示“已连接”。
3. 无开放 API 的平台没有可用自动发布开关。
4. 只有官方 API 验证通过后才能开启自动发布。
5. 解绑阻止新任务但不删除历史。
6. 页面、日志和导出中不出现明文凭据。
7. 移动端卡片可完整操作且无页面横向溢出。
8. 页面 PRD 抽屉显示 `bind` 与本文一致。

## 技术实现提示

- 对象：`platform_account`、`credential_ref`、`capability_probe`、`publish_task`。
- OAuth state 与回调签名必须校验；凭据写入密钥服务。
- 平台账号唯一约束建议 `tenant_id + platform + external_account_id`。
- 能力探测结果需带版本与时间，过期后重新验证。
- 发布前仍必须执行 P-060、人工审核和幂等校验。
- 自动化测试覆盖无 API、验签失败、到期、解绑、能力探测和凭据泄露扫描。
