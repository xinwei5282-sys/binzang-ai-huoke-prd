# 页面 PRD：AI 获客 / AI 混剪

> 页面 ID：`remix`｜版本：v2.1｜优先级：P0｜日期：2026-09-01｜上位：[[../PRD_AI获客]]
> 当前原型真源：`prototype/index.html`｜Remotion Prompt 真源：`remotion/beauty-shoulder-relaxation/src/prompts.ts`
> 本文替代旧「AI 视频」页面口径；[[../PRD_视频模板化生成与换人换产品]]仅作历史模板能力参考，冲突时以本文为准。

## 页面概述

| 项目 | 说明 |
|---|---|
| 页面目标 | 用口播、授权素材、数字人、字幕和音频组成可逐镜检查、局部替换并经人工确认的 Remotion 混剪任务。 |
| 适用角色 | 运营创建和替换素材；审核人确认脚本与分镜；视频人员处理失败；负责人控制预算。 |
| 页面入口 | `AI 获客 → AI 混剪`，或从爆款候选和获客计划创建任务。 |
| 权限要求 | 查看、编辑、素材替换、确认和正式渲染分权；授权审核不可由创建人自批。 |

## 页面级业务规则

- 先展示任务列表，点击“创建 AI 混剪”后进入两步设置；详情复用创建页并可在两步间跳转。
- 第一步确定口播来源、CTA、数字人和声音；第二步统一确认封面、主素材、分镜、对应口播、时长、来源、授权和质量问题。
- 不提供手动裁剪；素材不足时替换、补齐、删除或重新生成，系统重算时长和关键帧。
- 后台质量门禁完成后才允许人工确认；存在 blocker、未处理 warning 或未确认素材时不得正式渲染。
- Remotion 只编排已确认轨道和素材版本；局部失败只重试失败片段。

## 页面字段

| 字段 | 类型 | 必填/展示规则 | 业务口径 |
|---|---|---|---|
| 任务标题 | 文本 | 2–80字，必填 | 用于列表和成片文件名。 |
| 口播来源 | 分段控件 | 必填 | 手动输入或参考链接；参考内容只借鉴结构。 |
| 最终口播稿 | 多行文本 | 必填且人工确认 | 修改后创建新脚本版本并使下游确认失效。 |
| CTA | 开关+文本 | 默认关闭 | 关闭时自然收尾；开启时1–80字。 |
| 数字人形象/声音 | 选择器 | 使用数字人轨道时必填 | 仅可选授权有效且 `available` 的资源。 |
| 分镜素材 | 分镜卡列表 | 第二步必显 | 画面、口播、目标/可用时长、来源、授权、首尾帧和问题。 |
| 合成预览 | 视频/内容视图 | 第二步可切换 | 低清代理预览不创建正式 Remotion 渲染。 |
| 质量状态 | 枚举 | 第二步必显 | `checking/blocked/warning/passed`，问题定位到分镜。 |

## 操作与结果

| 按钮/操作 | 展示条件 | 执行结果 | 权限与记录 |
|---|---|---|---|
| 创建 AI 混剪 | 有创建权限 | 新建草稿并进入第一步 | 写企业知识和用户输入版本。 |
| 抓取并仿写 | 有公开参考链接 | 生成结构化口播候选 | 保留来源，不复制长段原文。 |
| 生成素材方案 | 口播已确认 | 进入第二步并启动后台质量门禁 | 保存 Prompt 和素材请求版本。 |
| 查看素材 | 素材可用 | 在页面内预览当前版本 | 不改变确认状态。 |
| 替换/删除素材 | 有编辑权限 | 更新当前分镜并使该分镜确认失效 | 保存授权和素材版本。 |
| 自动修复 | 仅可自动处理 warning | 处理安全范围内问题并重跑门禁 | blocker 不自动绕过。 |
| 确认并生成 | 质量通过且人工确认 | 创建正式 Remotion 渲染任务 | 写确认人、输入快照和预算。 |
| 只重试失败片段 | 部分成功或失败 | 仅重跑失败段 | 保留已成功轨道和产物。 |

## 产品边界

AI 混剪不负责平台发布，也不把代理预览当正式成片。真实抓取、数字人、模型、素材生成和 Remotion 渲染均需工程服务；当前原型中的图片、视频和定时状态只用于流程演示。

## 状态与跳转

- `draft → script_confirmed → material_planning → quality_checking → awaiting_human_confirmation → queued → rendering → succeeded`
- `quality_checking → blocked/warning → replace_or_fix → quality_checking`
- `rendering → partial_success/failed → retry_failed_segments → rendering`
- `succeeded → download or create_publish_task`

## 通知与日志

- 质量 blocker、素材授权到期、渲染失败和成片待确认通知任务负责人。
- 记录 `remix_created/script_confirmed/material_replaced/quality_checked/render_confirmed/render_succeeded/render_failed`。
- 审计包含脚本、素材、授权、Prompt、Remotion manifest 和确认版本，不记录密钥或原始声音文件。

## 异常与空状态

| 场景 | 页面表现 |
|---|---|
| 首次无任务 | 说明两步流程并提供创建入口。 |
| 链接不可抓取 | 保留链接和手动口播入口，不补造原文。 |
| 授权失效 | 标记对应形象、声音或素材为 blocker，禁止渲染。 |
| 时长不足/关键帧缺失 | 定位到分镜并提供补齐或替换，不提供手动裁剪。 |
| 质量门禁失败 | 展示检查项、级别和恢复动作，`render_allowed=false`。 |
| 单段渲染失败 | 保留成功片段并提供局部重试。 |

## 页面验收标准

1. 进入页面先显示任务列表，创建后可在两步间跳转。
2. 第二步同时显示画面、口播、时长、来源、授权、关键帧和质量问题。
3. blocker、未处理 warning 或未人工确认时正式渲染按钮不可用。
4. 替换或删除素材会使对应分镜确认失效并重跑门禁。
5. 单段失败可局部重试，已成功片段不重复生成或扣费。
6. 成片保存 AI 标识、素材授权链、输入版本和质检结果。

## 技术评估项

- 核心对象：`remix_task/script_version/storyboard_version/material_asset/quality_issue/remotion_manifest/render_task`。
- `remotion_manifest` 固化视频、数字人、字幕、音频、转场和 CTA 轨道及其版本。
- 所有写接口携带 `tenant_id/input_version/idempotency_key`；版本不一致返回 `VERSION_STALE`。
- 质量门禁输出 `render_allowed/checks/scene_issues/auto_fixable/human_confirmation_required`。
- Prompt 版本固定为 `remix-video-v1.0.0`；正式接入前需完成素材授权、供应商、预算和浏览器预览性能评估。

# 详细执行契约（保留）

## 1. 问题与目标

企业已有图片、视频、数字人口播和企业知识，但传统纯 API 整片生成成本高、可控性差，生成后难以返工。用户需要在正式渲染前看清口播、分镜、真实素材、时长和质量问题，人工确认后再由 Remotion 多轨合成。

目标：

1. 用两步完成「视频设置 → 素材确认」，降低操作成本。
2. 以数字人口播音轨为主时间轴，生成可编辑的 Remotion 多轨成片。
3. 优先使用已授权的企业素材，缺失时再用 AI 补齐，避免为生成而生成。
4. 质量门禁后台自动执行，问题直接标记到对应分镜，阻断问题处理前不得渲染。

## 2. 用户与成功指标

目标用户：企业老板、运营、内容人员和有审核权的成员。

| 指标 | 口径 | 目标 |
|---|---|---|
| 素材方案完整率 | 口播时间轴内无缺失素材的任务占比 | ≥95% |
| 阻断问题拦截率 | 含 blocker 但未创建正式渲染的任务占比 | 100% |
| 分镜可追溯率 | 可追溯到口播、素材、授权、Prompt 版本的分镜占比 | 100% |
| 局部重试复用率 | 失败后保留已成功片段的任务占比 | 100% |
| 首次成片可用率 | 质检后无需整片重做的成片占比 | 上线后建立基线 |

## 3. 范围

### 3.1 本期范围

- AI 混剪任务列表、创建、详情、暂存、重试、查看成片和下载。
- 企业上下文自动从企业大脑提取；用户只设置本次视频。
- 手动输入口播、爆款结构仿写、授权链接抓取后仿写。
- 目标平台、画面方向、视频时长独立设置。
- 选择数字人和声音，默认右下圆形小窗、贯穿口播。
- 封面自动生成或人工上传，同时用于发布封面和开头 1 秒。
- 真实分镜素材预览、替换和删除；不提供手动裁剪功能。
- 字幕自动转写对齐，低置信度文本支持人工校对。
- 配乐选择、人声优先、ducking、循环和结尾淡出。
- 后台质量门禁、分镜级问题展示、补齐和自动修复。
- 人工确认后创建 Remotion 正式渲染任务。

### 3.2 不在本期

- 不做专业 NLE 时间线编辑器、逐帧特效、调色和手动裁剪。
- 不在本页发布到外部平台；成片与发布任务分离。
- 不在未授权时自动下载或复制外部内容。
- 不将 AI 推断、OCR 或外部抓取结果自动升级为企业事实。
- 不返回剪映草稿；当前编辑性来自 Remotion 独立轨道和结构化配置。

## 4. 信息架构与用户流程

### 4.1 任务列表

AI 混剪先进入列表，点击「创建 AI 混剪」才进入设置页。所有状态支持「查看详情」，详情复用创建页且两步均可点击跳转。

| 状态 | 主操作 |
|---|---|
| 草稿 | 查看详情、继续编辑 |
| 素材生成中 | 查看详情 |
| 待确认 | 查看详情、立即生成（进入第 2 步） |
| 成片生成中 | 查看详情 |
| 已完成 | 查看详情、查看成片、下载 |
| 失败 | 查看详情、查看原因、重试失败片段 |

### 4.2 第 1 步：视频设置

| 字段 | 规则 |
|---|---|
| 企业上下文 | 从企业档案、产品服务、品牌规则和行业合规规则自动提取，只读展示来源 |
| 本次视频主题 | 必填；不得替代或覆盖企业事实 |
| 目标平台 | 抖音、视频号、小红书、快手；单独设置 |
| 画面方向 | 9:16、16:9、1:1；单独设置 |
| 视频时长 | 15/30/60 秒或跟随数字人口播时长；不展示「最终时长」字段 |
| 口播来源 | 手动输入或粘贴已授权参考链接 |
| 口播处理 | 直接使用、按爆款结构仿写，结果可继续手动修改 |
| CTA | 可选；配置则显示，未配置则自然收尾 |
| 数字人/声音 | 从已授权的企业资产或平台公模中选择 |
| 数字人布局 | 当前只有「右下圆形小窗·贯穿口播」 |

主操作「生成素材方案并进入下一步」只创建素材方案，不创建正式成片。

### 4.3 第 2 步：素材确认

1. 页面展示封面、数字人、字幕、配乐和「分镜素材与首尾帧」。
2. 数字人和声音可返回第 1 步替换。
3. 字幕默认根据数字人音轨自动转写和对齐；页面展示字幕总句数和低置信度数量，「查看/校对字幕」展示全部时间段文字。
4. 分镜素材和首尾帧合并展示，不设置重复的「已选素材」区。
5. 每张分镜卡必须展示：真实图片或视频预览、对应口播、使用区间、所需/可用时长、素材来源、授权状态、语义匹配、首尾帧要求和质量问题。
6. 分镜操作仅保留「查看/播放、替换、删除」；不提供手动裁剪。
7. 点击分镜卡后，右侧低成本合成预览同步切换主画面和字幕；代理素材不可用时可切换内容占位预览。
8. 提供「返回上一步、暂存、确认素材并生成成片」。

### 4.4 AI 关键帧规则

- AI 生成镜头默认生成首帧。
- 仅在动作连续、转场衔接或下一镜头复用时同时生成尾帧。
- 人工上传或企业素材库中的现成素材不重复生成首尾帧。

## 5. 后台质量门禁

质量门禁在素材方案生成后自动后台执行，不要求用户手动点击「重新检查」。页面顶部只展示汇总，有问题时直接显示在对应分镜卡。

| 维度 | 检查内容 | 展示位置 |
|---|---|---|
| content | 口播逻辑、品牌语气、CTA、企业已确认事实 | 全局汇总；涉及具体分镜时标到分镜 |
| semantic | 画面是否直接支持当前口播 | 对应分镜 |
| timeline | 口播主时间轴是否存在缺失、重叠、越界或素材时长不足 | 对应分镜 |
| visual | 清晰度、主体裁切、字幕安全区、右下数字人遮挡 | 对应分镜 |
| caption_audio | 字幕时间戳、两行上限、低置信度、人声和配乐 | 字幕/配乐卡及全局汇总 |

问题级别：

- `blocker`：事实未确认、必需素材缺失、时间轴不完整、规格不符、严重遮挡或字幕越界。存在 blocker 时必须 `render_allowed=false`。
- `warning`：语义相关度偏低、构图/节奏可优化、字幕低置信度。本期 warning 也需处理后才能生成。

允许自动修复：后台自动裁取合理使用区间、补齐转场、重新匹配已授权素材、调整安全区、音量和淡入淡出。禁止自动修改：企业事实、价格、资质、案例、功效承诺和核心口播含义。

## 6. Remotion 合成规则

1. 数字人口播音轨是主时间轴；分镜、字幕、配乐和成片结束点与之对齐。
2. 输出轨道至少分为 `cover`、`mainVisual`、`avatar`、`captions`、`music`、`cta`，不得在渲染前预合成为单轨素材。
3. 素材过长由系统自动取合理使用区间；素材过短优先增加同语义素材，其次 AI 延展。禁止极端变速、明显循环和静帧硬拖。
4. 数字人保持独立轨道，不得因调整数字人位置带动其他轨道。
5. CTA 仅在已配置时生成 CTA 轨道，未配置时自然收尾。
6. 低成本预览使用代理素材，不触发正式 Remotion 渲染和用量计费。

## 7. 状态机与异常

`draft → materials_generating → review → render_queued → rendering → completed | failed`

- 素材方案生成后自动执行质量门禁，质检过程不新增独立用户步骤。
- 任务生成中页面可查看设置和当前状态，但首版不提供供应商级实时百分比进度。
- 片段或 Remotion 合成失败时保留已成功素材，只重试失败片段。
- 替换、删除、补齐素材后自动重新计算受影响分镜的质检结果。
- 未配置 CTA、背景音乐不影响视频生成；数字人、声音、口播和必需分镜素材为必填。

## 8. 数据与接口契约

核心对象：

- `remix_task`：企业、主题、平台、画幅、目标时长、CTA、状态、Prompt 版本。
- `narration_version`：来源、原文、仿写结果、人工修改、声音资产和音轨时长。
- `remix_scene`：时间段、口播文本、画面意图、素材、来源、授权、时长、语义分、首尾帧要求。
- `quality_issue`：分镜 ID、维度、级别、证据、修复建议、是否可自动修复、处理状态。
- `remotion_manifest`：六类轨道、素材版本、字幕、音频、渲染参数和成片产物。

接口草案：

- `POST /remix-tasks`：创建或暂存任务。
- `POST /remix-tasks/{id}/build-plan`：生成素材方案并启动后台质检。
- `GET /remix-tasks/{id}`：返回设置、分镜、素材、问题和状态。
- `PATCH /remix-tasks/{id}/scenes/{sceneId}/asset`：替换或删除分镜素材，并重算受影响质检。
- `POST /remix-tasks/{id}/scenes/{sceneId}/fill`：补齐缺失素材或关键帧。
- `POST /remix-tasks/{id}/quality-issues/{issueId}/auto-fix`：仅处理允许自动修复的问题。
- `POST /remix-tasks/{id}/confirm-render`：校验无未处理问题后创建 Remotion 渲染任务。
- `GET /remix-tasks/{id}/video`：查看和下载已完成成片。

所有写接口必须带 `tenant_id`、`input_version`、`idempotency_key`；素材更换必须固化授权快照和素材版本。

## 9. Skill 与 Prompt

Skill：`remix-plan-builder`、`asset-semantic-matcher`、`caption-aligner`、`remix-quality-gate`、`remotion-render-orchestrator`。

Prompt 版本：`remix-video-v1.0.0`。策划与质量门禁共用同一版本号，每个任务必须固化 Prompt 版本和输入快照。

Prompt 上下文优先级：

`platform_rules → industry_knowledge → confirmed_enterprise_facts/brand_config → task_settings`

硬约束：

- 不得编造企业资质、案例、价格、功效或承诺；缺失返回 `needs_confirmation`。
- 策划 Prompt 只输出 JSON，包含 `promptVersion`、`summary`、`narrationDurationSeconds`、`scenes`、`tracks`、`assetRequests`、`captionCues`、`audioPlan`、`qualityRisks`、`needsConfirmation`。
- 质量 Prompt 只输出 JSON，包含 `promptVersion`、`renderAllowed`、`overallStatus`、`checks`、`blockers`、`warnings`、`autoFixes`、`needsHumanReview`。
- 自动修复后仍需人工预览复核，未点击确认前不得创建正式渲染任务。

Prompt 完整文本和输入校验以 `remotion/beauty-shoulder-relaxation/src/prompts.ts` 为真源，PRD 不重复复制，避免版本漂移。

## 10. 权限、合规与风险

- 口播、数字人、声音、素材和配乐必须有租户权限与授权记录。
- 外部链接仅用于有权使用的内容抓取和结构仿写，不复制原作者表达。
- 数字人与声音授权过期、撤回或不匹配时禁止新渲染。
- AI 生成/合成内容按当期平台和法规要求添加标识，具体规则需上线前重新核验。
- 主要风险：企业素材不足、语义匹配不准、口播与素材时长不一致、数字人遮挡、字幕误识别、供应商局部失败和渲染成本超限。
