# 页面 PRD：营销物料 / 公众号文章

> 页面 ID：`material-wechat`｜版本：v1.0｜优先级：P0｜上位：[[../PRD_营销物料]]

## 问题

文章需要绑定具体公众号和发布记录，自动发布时间必须逐文章设置，数据也必须回收到对应文章；否则多账号、多文章场景会串数据或误发布。

## 目标

打通创作、审核、选账号、独立定时、API/RPA/手动发布及逐文章阅读/分享；不展示在看和新增关注。

## 目标用户

运营创作排期；审核人批准；发布负责人确认账号/方式/RPA；负责人查看逐文章数据。

## 用户流程

进入列表 → 新建并选公众号/方式/计划节点 → 设置本篇时间 → 生成/编辑 → 审核 → 到时发布或手动执行 → 同步本篇阅读/分享 → 失败重试或人工接管。

## 功能规则

- 同租户支持多个公众号；创建时必须选择具体账号。
- 发布方式只显示账号capability支持的API/RPA/manual。
- 经营计划时间只作为推荐值，本篇`scheduled_at`独立保存和确认。
- 阅读/分享直接显示在文章行；联合键为article_id+account_id+publish_record_id。
- 编辑已审核文章产生新版本并撤销原定时确认。

## 异常与边界

账号过期/解绑、capability变化、计划时间过去、版本变化、API失败、RPA登录失效/验证码均阻止静默发布。RPA异常进入manual_takeover。无指标能力时显示“不支持同步”，不显示0。

## 字段交互 / 取值

### 文章主题或目标

多行输入。字段键：`topic`。取值5–500字符，必填。为空提示“请输入文章主题或内容目标”。

### 发布账号

公众号选择器，展示名称、认证状态和到期时间。字段键：`publishing_account_id`。取值同租户authorized公众号；必填。切换账号会刷新方式和指标能力。

### 发布方式

单选。字段键：`publish_method`。取值api/rpa/manual；必填。默认账号首选能力；不支持项不显示。RPA显示风险说明。

### 经营计划

下拉选择active计划。字段键：`operating_plan_id`。可为空；默认当前active计划。

### 经营计划节点

联动下拉。字段键：`plan_action_id`。可为空；只显示有建议发布时间的行动。

### 系统推荐发布时间

只读日期时间。字段键：`recommended_publish_at`。来源plan_action.suggested_at；无计划显示“未关联计划”。

### 本篇自动发布时间

日期时间选择器。字段键：`scheduled_at`。取值晚于当前时间且在账号授权期内；自动发布开启时必填。用户修改不回写计划。

### 自动发布开关

开关。字段键：`auto_publish_enabled`。默认false；开启要求api/rpa、scheduled_at和审核通过。RPA仍需任务启动前人工确认。

### 参考资料

多文件上传。字段键：`reference_assets`。PDF/DOCX/TXT/图片，单个≤20MB；提取结果先作为任务引用，不变成正式事实。

### CTA

文本输入。字段键：`cta`。0–80字符，可为空；不得编造联系方式。

### 文章列表字段

字段键：`title/account/plan_action/scheduled_at/publish_status/reads/shares/updated_at`。阅读、分享仅published且同步成功后显示数字；其他显示“—/同步中/不支持”。

### 审核并发布

approved前打开审核；通过后再次确认账号、方式、时间、版本。API定时进入scheduled；RPA进入awaiting_confirmation；manual生成发布包。

### 同步数据

published且账号支持metrics时可用。使用publish_record_id拉取；按钮loading防重复；失败保留旧值并显示最后成功时间。

## 状态与权限

内容：`draft → generating → pending_review → approved`。发布：`scheduled | awaiting_human_confirmation → publishing → published | failed | manual_takeover`。运营编辑，审核人批准，发布负责人确认外发；查看指标按文章权限。

## 数据与接口

对象：`wechat_article`、`article_version`、`publish_task`、`publish_record`、`article_metric`。publish_task包含account_id、method、scheduled_at、auto_publish_enabled、content_version、review_id、idempotency_key。

接口：`GET/POST /wechat/articles`、`PATCH /{id}`、`POST /{id}/generate|submit-review`、`POST /publish-tasks`、`POST /publish-tasks/{id}/confirm|retry`、`GET /articles/{id}/metrics?account_id=&publish_record_id=`。

错误码：`ACCOUNT_REQUIRED`、`ACCOUNT_AUTH_EXPIRED`、`METHOD_UNSUPPORTED`、`SCHEDULE_INVALID`、`CONTENT_VERSION_CHANGED`、`REVIEW_REQUIRED`、`RPA_MANUAL_TAKEOVER`、`METRICS_UNSUPPORTED`。

## Skill / Prompt

```text
你是企业公众号主编。只使用 confirmed_facts、active_vi、authorized_assets 和用户提供的任务资料。输出 title、summary、body_sections、image_plans、cta、evidence_refs、risk_flags、missing_inputs。不得虚构价格、资质、案例、承诺和客户评价。账号、发布方式和发布时间属于发布任务字段，不由文章生成模型决定。
```

发布前Skill校验article_id、version、account_id、method、scheduled_at、review_status、idempotency_key；缺一项返回阻断，不执行API/RPA。

## 埋点事件

`wechat_article_created`、`wechat_account_selected`、`wechat_schedule_changed`、`wechat_review_approved`、`wechat_publish_confirmed`、`wechat_publish_succeeded/failed`、`wechat_metrics_synced`；指标事件含article_id、account_id、publish_record_id。

## 验收标准

1. 新建必须选择具体公众号和受支持方式。
2. 文章时间独立修改不改变经营计划。
3. 编辑approved文章后原定时任务失效并要求重新审核。
4. 两篇文章、两个账号、两次发布的指标互不串行。
5. 页面不出现“文章数据”容器、在看和新增关注。

## 核心指标

文章生成成功率≥95%；发布成功率按方式分别统计；指标归属准确率100%；误重复发布率0%；计划推荐时间采用率仅观察。
