# PRD：品牌与经营

> 上位真源：[[PRD_企业AI经营大脑_当前开发基线]]。冲突时以上位 PRD 为准。

## 1. 目标与范围

把企业事实转化为可查看、可追溯、可迭代的品牌诊断与经营计划。用户能够区分初步诊断和深度诊断，查看完整交付物，并以经营计划驱动后续内容任务和发布时间。

### 本期范围

- 品牌报告：初步诊断、深度诊断、生成状态、失败原因、预览、下载、历史版本。
- 经营计划：年度/季度/月度目标、策略、行动、负责人、时间、关联内容任务、复盘。
- 企业信息补充：四步表单可点击切换，保留已填写内容。

### 不在本期

- AI 结论自动覆盖企业正式事实。
- 未确认资料直接进入报告依据。
- 自动承诺 ROI、成交额或经营结果。

## 2. 页面与用户流程

### BRAND-001 品牌报告列表

- 入口：`品牌与经营 / 品牌报告`。
- 列表字段：报告名称、类型、依据版本、生成时间、状态、操作。
- 报告类型：`initial_diagnosis | deep_diagnosis`。
- 状态：`draft → generating → ready | failed`。
- `ready` 支持预览、下载、重新生成；`failed` 必须打开失败原因并支持重试。

### BRAND-002 初步诊断

- 企业信息完整度达到配置阈值后允许生成。
- 输出必须包含：执行摘要、六维评分、主要问题、证据、待补资料、优先建议。
- 页面展示完整文档案例，不使用几张摘要卡代替报告预览。

### BRAND-003 深度诊断

- 仅在完整度和六维最低完整度达到配置阈值后开放。
- 输出必须明显深于初步诊断，至少包含：管理摘要、诊断方法、逐维证据、问题树、根因、机会地图、优先级、90 天行动方案、指标、风险、依据附录。
- 深度报告可以是在线文档，不强制为 PPT。
- 报告中的事实、推断、建议必须分层标识。

### PLAN-001 经营计划

- 计划层级：年度方向、季度重点、月度行动。
- 行动字段：目标、任务、负责人、开始/截止时间、状态、关联依据、关联营销内容、计划发布时间。
- 状态：`draft → pending_confirmation → active → completed | archived`。
- 计划启用前人工确认；后续变更保留版本和审计记录。
- 公众号文章等内容任务可以读取计划建议发布时间，但文章的自动发布时间必须在任务中单独确认和保存。

### ONB-002 企业信息四步补充

- 四个步骤标题均可点击切换，不要求只能点“下一步”。
- 切换步骤不清空已填写值；错误仅标记当前字段。
- 上传/OCR/网站提取只形成候选，人工确认后才计入诊断依据。

## 3. 数据与接口

核心对象：`diagnosis_report`、`report_evidence_ref`、`operating_plan`、`plan_action`、`company_profile_draft`。

- `POST /diagnosis-reports`：创建初步/深度诊断任务。
- `GET /diagnosis-reports/{id}`：读取状态、报告正文和失败原因。
- `POST /diagnosis-reports/{id}/retry`：按原依据版本重试。
- `POST /operating-plans`：创建经营计划草稿。
- `POST /operating-plans/{id}/confirm`：人工确认并启用。
- `PATCH /plan-actions/{id}`：更新行动、时间和关联内容任务。

所有写接口必须携带 `tenant_id`、操作者、依据版本和幂等键。

## 4. Skill 与 Prompt

- Skills：`enterprise-initial-diagnosis`、`enterprise-deep-diagnosis`、`company-operating-plan`、`document-render`。
- Prompts：使用总 PRD 的 `P-011`、`P-012`、`P-050`。
- 输出先做 Schema 校验，再做事实引用完整性与敏感承诺检查。

## 5. 验收标准

| ID | 操作 | 预期结果 |
|---|---|---|
| BO-AC-001 | 打开初步报告案例 | 显示完整初步诊断正文及依据，不是摘要占位 |
| BO-AC-002 | 打开深度报告案例 | 显示问题树、根因、机会、90 天方案、指标、风险和附录 |
| BO-AC-003 | 打开失败报告原因 | 原因弹层可正常打开，并可发起重试 |
| BO-AC-004 | 点击企业信息第 3 步后返回第 1 步 | 步骤可切换且已填写内容保留 |
| BO-AC-005 | 启用经营计划 | 产生版本和审计记录，关联内容任务可读取建议时间 |
| BO-AC-006 | 创建公众号文章任务 | 自动发布时间单独确认，不因计划时间直接发布 |

## 6. 风险与依赖

- 依赖企业大脑正式事实、报告生成服务、文档预览/下载服务和任务调度器。
- 深度报告浅化风险：用固定章节 Schema、最低证据数量和验收样例约束。
- 计划误发布风险：经营计划只提供建议时间，渠道任务仍保留账号选择和人工确认。
