# 企业 AI 经营大脑原型

面向通用企业的 AI 获客与经营大脑产品原型，包含企业建档、诊断、企业知识、品牌 VI、经营计划、营销物料和 AI 获客工作台。

## 本地预览

```bash
python3 -m http.server 8010 --directory prototype
```

打开 `http://127.0.0.1:8010/index.html`。

## 测试

```bash
node --test prototype/tests/*.test.mjs
```

当前仓库是静态交互原型。异步生成、第三方采集、公众号发布、文件下载和数据回收等能力均为产品交互演示，不代表生产服务已经接通。

未经人工确认的 OCR、资料解析、网站或公众号采集结果，不会自动成为企业正式事实。
