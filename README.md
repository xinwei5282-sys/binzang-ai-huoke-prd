# 殡葬 AI 获客产品

> 🔒 **私有仓库** · 含报价 / 客户尽调 / 商业策略，**勿改公开、勿外传**。

一套面向殡葬商家的 **AI 营销内容 / 视频生产平台**（知识库底座驱动，可分销）。本仓库存放该产品的 **PRD / 高保真原型 / 方案与策略** 全部设计资产。

---

## 一、分期定调（先看这个）

**这是分期，不是转向**——承接转化仍是核心护城河，只是排二期。

| 期 | 重心 | 说明 |
|---|---|---|
| **一期** | 内容 / 视频生产工具 + 多模态知识库底座 + 分销赋能 | 核心动机＝**降低客户使用难度与成本**（模板化出片、提示词收后台、i2v 替文生视频降本）；留存靠**数据沉淀**（知识库/素材/赢家内容换走清零） |
| **二期** | **承接转化**（真护城河） | 承接智能体 + 话术 SOP + 跟进机器人；**硬触发 gate**：第一单续费 / 付费 N 家留存 X% / 一期上线 ≤6 个月无条件启动 |

详见 `产品规划-殡葬V1.md` 与 `AI 获客产品方案 Index`（vault 根目录）§十九。

## 三、怎么看原型

浏览器直接打开 `prototype/index.html`（商家端）或 `prototype-boss/index.html`（后台），登录页点「登录」即进。纯静态、无需构建。

> **demo 视频未入库**（43MB，体积原因 gitignore）。要让原型里的案例/成片视频可播放，按 `prototype/assets/demo/README.md` 把 mp4 放回该目录即可。

**商家端模块**：工作台 · 内容创作（拆解→仿写→按模板生成，含出片确认门）· 爆款抓取 · 知识库（多模态底座）· 数字人 · 作品库（含公式形态）· 用量 · 成员 · 平台绑定
**后台模块（精简）**：账号开通 · 套餐配置 · 合规词库

## 六、关键约束与红线

- **硬事实精确召回不幻觉**：价格/规格走结构化精确查询、未命中留空不编造（见技术方案）。

- **视频换人**：仅授权本人/数字人形象，禁任意换脸；成片加 AI 生成标识；供应商须算法备案。
- **第三方全 TBD**：蝉镜 / 蝉妈妈 / 阿里百炼 / Seedance 等接口与报价**签约前不写死**，经 Provider 适配层隔离。
