# AI 获客方案 — 殡葬寿衣商家定制版

> 性质：通用版产品蓝图，针对殡葬/寿衣行业现状与卡点的**定制调整**。  
> 定位更新（2026-06-22）：**双主线** —— ① 帮客户自己扩 2C 获客（通用版定位）；② 把同一套内容/视频生成能力**打包赋能给下游小 B**（客户主动诉求）。两条线共用一套引擎，自用验证 → 对外输出。

## 一、战略锚

- **双主战场**：

  - **主线 A · 2C 获客**：用 AI 内容链 + 承接 + GEO 帮客户自己把个人消费者做起来（与通用版一致）
  - **主线 B · 2B 赋能**：把同一套视频/内容生成 + 合规预审能力，打包成工具赋能下游小 B（一条龙/区域商家），收渠道月费、绑定供货关系
- **一句话目标**：用同一套内容/视频生成引擎，4–6 周内 ① 让客户自己的 2C 内容产能/转化率提升，② 跑通 3–5 个种子小 B 的赋能试点；再用「老人记忆私域」+「2B SaaS 渠道网」建双护城河
- **关键洞察**：**两条线是同一套能力的两个出口**——客户自己做 2C 时打磨出的选题/文案/数字人/剪辑/合规模板，直接复用打包给小 B。不是两个项目，是一套引擎两个客户群。
- **两个前提（老板必须先拍板）**：① 2C + 2B 赋能的投入决心与预算（决定 1.0/2.0 节奏）② 数据（诊断 1 周拿到核心数字，否则一切无基线）

## 二、客户三大卡点 + 两条横切病（尽调诊断）

客户**有产品力、有信任、有口碑裂变苗头**，但获客链卡在：

1. **内容生产**——靠人、偏行业内、C 端进不来
2. **承接转化 / 渠道粘性**——小 B 接不住线索、全压老板一人、不可复制；且下游小 B "比价就走"、粘性弱
3. **留存裂变**——口碑只自然发生、老客资产沉睡

横切：**合规风控**（敏感被限流/下架）+ **数据缺失**（全程无数据）

> **卡点二的重构（本次方向调整的核心）**：原方案把"小 B 接不住承接"当纯问题处理；客户提出赋能小 B 后，这个问题**翻转成产品机会**——与其抱怨小 B 承接差，不如把内容/视频生成工具赋能给他们，让小 B 自己能做获客内容。客户从"只供货"升级为"供货 + 供工具 + 供流量方法"，**用工具绑定渠道**，直接解掉"比价就走"的粘性问题，还多一条渠道收入。

> 根本矛盾：**"有产品力但不会卖、渠道不牢"**。AI 补内容和承接，2B 赋能补渠道粘性；方案要往"把信任、口碑、渠道关系系统化放大"这个根上打。

## 三、通用版 → 定制版的关键调整

**调整 1 · 定位升级为双主线（本次最大变化）**  
通用版只做"帮 B 端商家获 C 端"；本客户在此之上要"把获客能力再赋能给自己的下游 B"。→ 方案新增 **2B 赋能主线**，与 2C 获客并列。客户既是产品的使用者（自用 2C），又是产品的分销渠道（赋能小 B）。

**调整 2 · 新增「2B 赋能」产品线 —— 代做切入、工具沉淀（核心新增）**

> ⚠️客户回填校正（6/23）：小 B**最缺的是"做内容的人"和"做内容能赚钱的意识"**，客户倾向\*\*"帮他们代做"**。所以一期**不走"给工具自助"，走"我方代做"\*\*——用 AI 把代做成本压下来，跑出效果和 SOP，同时把重复动作工具化，为日后自助打底。

把给客户自用的 2C 内容链，做成"代做产能"，能力同源：

| 能力 | 一期怎么用（代做） | 沉淀什么（为自助打底） |
|-|-|-|
| 视频生成 | 我方用数字人口播 + 图生视频(i2v) 给小 B 批量出片 | 模板库 + 一键出片流程 |
| 内容产出 | 行业选题库 + AI 文案 + 分版剪辑，我方代产 | 选题库 + 文案/剪辑模板 |
| 合规预审 | 发布前敏感词/违禁过滤（殡葬刚需，小 B 不懂） | 行业敏感词库（可复用） |
| 素材/品牌 | 客户统一供素材，我方代做时统一品牌口径 | 素材库 + 话术 SOP |

> **🎯 一期范围**：**① 给小 B 开子账号（用于交付/管理素材与成品）② 内容生成功能（我方代做为主）**。代做中沉淀模板/SOP/流程，逐步把重复动作工具化。**是否分销、计费分成暂不处理**——先用代做跑出效果，验证"做内容真能给小 B 带来获客"，再定商业模式与自助化节奏。

**调整 3 · GEO：1.0 做基础，2.0 重估为 2C 核心入口（被低估的机会）**  
现状 GEO 弱（GU 刚上、关键词不准、官网没做、只放电话漏客）→ 1.0 先补基础（关键词+官网承接）。  
**反转洞察**：殡葬 2C 是 GEO 最可能成立的消费场景——消费者**羞于问人(隐私敏感) + 信息差极大("300 和 3000 看起来一样") + 决策急(时间紧)**，三点叠加 = 极强的"私下问 AI"动机（"寿衣怎么选""骨灰盒什么价""有什么讲究"）。普通人不问 AI 推荐美容院，但很可能问 AI 殡葬怎么办。**对手几乎没人做 GEO** → 2.0 重估为 2C 核心入口。

**调整 4 · 新增「行业敏感合规预审」模块（通用版没有，本客户命脉，且是 2B 赋能的核心卖点）**  
获客天花板就是敏感被限流/下架（灵堂/光电池/经文/包裹布全被下过、投流不让投、价值材质不能讲）。  
→ 发布前 LLM 敏感合规预审：自动过滤违禁表达 + 给"国标俗称→合规说法"改写建议。**自用是内容链标配前置；对外是 2B 赋能里小 B 最缺、最值钱的能力**（小 B 自己根本不会合规）。

**调整 5 · 承接转化优先级从 V3 提到「1.0 第一梯队」**  
最痛卡点是承接：小 B 接不住、全压老板一人、团队不会卖、无 SOP。  
→ **销售话术助理 + 承接智能体 + SOP 沉淀（L5-04/05/07）提到 1.0 核心**，和内容链并列。目标转化率 5%→10–20%。内容做出来但转化还压老板一人 = 白做。

**调整 6 · 截流「红线刹车」（纠偏客户原想法）**  
客户原想做"评论区/点赞用户私信截流，成百上千数字人偷别人客户"——**正中红线**（抓别人数据 + 批量自动化 + 封号）。  
→ 截流**降级为：人工、小量、自有账号**；**禁止数字人批量评论区截流**。主动给客户讲清：封的是他辛苦养的 10 个号。

**调整 7 · 新增两个通用版没有的能力**

| 新能力 | 是什么 | 定位 |
|-|-|-|
| 数字人直播（合规路径） | 抖音封号高风险 → 改 AI 直播（真实场景+AI 回复），或只在淘宝/京东/快手做 | 1.0/2.0 可选 |
| **老人记忆/回忆录获客** | AI 陪伴+回忆录做长周期 2C 入口，"产品即钩子"，绕开"抢客"冲突沉淀私域 | **2.0 护城河，本客户独有** |

> 「老人记忆」把"殡葬=低频一次性"变成"陪伴=长周期触达"，是 2C 护城河；「2B 赋能 SaaS」把"一次性供货"变成"持续工具绑定"，是渠道护城河。**两条护城河，对应两条主线。**

## 四、阶段化方案（诊断 → 1.0 → 2.0）

> 时序逻辑：2B 赋能依赖先有打磨好的引擎，所以双主线落地节奏是"先自用验证 → 同步种子试点 → 再规模输出"，不是先后取舍。

| 阶段 | 主线 A（2C 自用） | 主线 B（2B 赋能） | 对应 Backlog + 新增 |
|-|-|-|-|
| **阶段 0 · 诊断（1 周）** | 拿数据：漏斗各层转化、GEO 关键词排名、电商数据 → 漏斗诊断 + 卡点定位 | 摸底下游小 B：数量、画像、付费意愿、最缺什么能力 | 前提（数据全缺是硬约束） |
| **1.0（4–6 周见效）** | ① 内容链(对标→爆款拆解→生成→分版剪辑) ② **敏感合规预审** ③ **私域承接智能体 + 话术 SOP** ④ GEO 基础 + 官网承接 | **2B 赋能一期 = 代做切入**：选 3–5 个种子小 B，**我方用 AI 代做内容**跑出效果，同时沉淀模板/SOP、把重复动作工具化（子账号用于交付/管素材）。**分销/计费暂不做** | L3A/L4 + L5-04/05/07 + L3B/L2-01 + 新增合规预审 + **L0-08 子账号 + L0-10 能力配额** |
| **2.0（几月起效）** | ① **老人记忆/回忆录**(独有) ② 老客裂变转介绍 ③ **GEO 重估为 2C 入口** | **2B 赋能商业化**：一期跑通后再定是否分销、怎么计费分成，铺开渠道网 | 新增 + L5-06 + **L0-09 分销计费(暂缓)** |

## 五、合规特别篇（本客户头等约束）

1. 🔴 **数字人批量评论区截流 = 红线刹车**：抓别人数据 + 批量自动化，会封客户号。只人工、小量、自有账号。
2. ⚠️ **数字人直播**：抖音封号高风险；要做就 AI 直播（真实场景+AI 回复），或只在淘宝/京东/快手。
3. ⚠️ **自动发布易封号**：内容 AI 批产，发布尽量手工点；已在用"一枚"一键发且未封再议。
4. 🔴 **行业敏感预审**：所有对外内容发布前过 LLM 合规预审，降低限流/下架（这是获客天花板）。
5. ⚠️ **2B 赋能的连带合规责任**：工具输出给小 B 的内容若违规，可能连累客户品牌/账号。→ 赋能工具必须**内置强制合规预审**，不给小 B 关闭选项。

## 六、商业模式与报价锚（按价值不按工具）

- **主线 A · 2C 自用**：诊断 + 内容链 + 承接助理，锚"转化率提升 / 内容产能翻倍"，一次性方案费 + 月度工具费
- **主线 B · 2B 赋能（一期不收费，远期主营收线）**：一期只做子账号 + 内容生成，**先不谈分销和计费**，目标是验证小 B 真用得起来；远期理想形态是月费/账号 × 下游商家数 = 可规模化渠道收入，但是否分销、怎么分成等跑通后再定。
- **2.0 · 双护城河**：老人私域（2C 资产）+ 2B 渠道网（渠道资产），锚"别人比不了的长期资产"

> **报价结构建议**：1.0 用"自用见效"立信任（低风险、快）；2B 赋能一期先免费/低价让小 B 用起来验证价值，**商业模式（分销/分成）等用量和留存数据出来再设计**——别在没验证前就把收费模型定死。

## 七、必须提醒（对齐用）

1. **双主线但有时序**：2B 赋能必须先有自用打磨好的引擎才输出，别让客户以为两条线第一天就齐头并进；1.0 自用为主 + 2B 种子试点，2.0 才规模化。
2. **2C + 2B 决心与预算是前提，不是细节**：建议 1.0 先做（低风险见效），用结果倒逼决心。
3. **数据全缺是 1.0 盲区**：诊断 1 周必须拿到数据 + 下游小 B 摸底，否则"内容提质""转化 5%→20%""小 B 付费意愿"都没基线。
4. **2B 赋能一期=代做切入，验"做内容真能带来获客"**：客户回填证实小 B 缺人缺意识、要代做（不是要工具）。所以一期我方代做、跑效果、沉淀 SOP/工具，**验证"内容→获客"对小 B 成立**；自助化与收费是后话。⚠️注意张力：代做偏服务/人力，要靠"AI 压成本 + 沉淀可复用工具"守住技术公司定位，别滑成纯人力外包。
5. **根本矛盾是"不会卖 + 渠道不牢"**：方案别做成纯获客工具，要往"把口碑系统化放大 + 用工具绑死渠道"打。
