# 营业执照原图与字段回显设计

## 目标

在“3 分钟了解企业”单页引导中，用户上传营业执照后，当前页立即回显执照原图和识别字段，便于对照核验，不新增页面或独立确认步骤。

## 页面布局

- 初始状态保留当前营业执照上传区。
- 上传后，上传区转为回显区，不再同时保留一块等高的空上传框。
- 桌面端使用左右布局：左侧为执照预览，右侧为可编辑字段。
- 手机端使用上下布局：原图在上，字段在下。
- 预览区显示文件名、文件类型和“更换执照”操作；图片文件显示可点击放大的缩略图。
- PDF 在静态原型中显示 PDF 占位预览和文件名，不伪造已渲染的执照图像。

## 回显字段

识别完成后直接展示并允许修改：

1. 企业名称（必填）
2. 统一社会信用代码（必填）
3. 法定代表人
4. 成立日期
5. 注册地址
6. 经营范围

每个字段保留来源提示。低置信度字段用橙色“请核对”标记，不使用无真实数据支持的准确率。

## 交互与状态

1. 选择 JPG、JPEG 或 PNG 后，使用浏览器本地对象 URL 立即回显图片，不等待 OCR 状态完成。
2. 识别中保留图片预览，字段区显示处理状态。
3. 识别完成后，字段自动填入原型演示值并可编辑。
4. 点击缩略图打开大图预览；按 Escape 或点击遮罩关闭。
5. 点击“更换执照”重新打开文件选择器。新文件会替换当前预览并重新识别，不保留上一份执照的字段值。
6. 手动填写模式不显示伪造的执照图，只展示字段。

## 异常与资源处理

- 格式不支持时不创建预览，保留可操作的错误状态。
- 重新上传时释放上一个对象 URL，避免页面长时打开后累积无效资源。
- 页面卸载时释放当前对象 URL。
- 静态原型不上传或持久化用户文件，预览仅存在于当前浏览器页面。

## 能力边界

- 执照原图回显是真实的本地文件预览。
- 执照字段仍为静态原型的 OCR 演示值，页面必须继续显示“原型演示 · OCR 待接入”。
- 不增加真实 OCR、文件上传、后端存储或企业数据校验。

## 验收标准

1. 上传图片执照后，当前页显示该图片的真实缩略图和六个可编辑字段。
2. 桌面端为左图右字段，390 × 844 窄屏为上图下字段，无水平滚动。
3. 点击缩略图可放大，点击“更换执照”可选择新文件。
4. PDF 显示真实文件名与 PDF 占位预览，不显示伪造的执照缩略图。
5. 更换文件后旧预览对象 URL 被释放，不沿用旧字段值。
6. 页面存在明确的 OCR 原型边界说明。
7. 相关自动测试和原型全量测试通过。
8. 1440 × 900 与 390 × 844 真实浏览器渲染中，原图、字段和操作入口清晰可用。
