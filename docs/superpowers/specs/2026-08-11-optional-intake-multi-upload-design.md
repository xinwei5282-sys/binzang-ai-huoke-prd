# 初步设置全部可选与多文件上传设计

## 目标

将“3 分钟了解企业”中的企业身份、补充资料、官网与公众号三部分统一设为可选。用户可以不上传任何内容直接完成初步设置，后续再补充资料。

## 页面口径

- `01 企业身份` 标记为“可选”，营业执照不再是进入系统的前置条件。
- `02 补充资料` 标记为“可选 · 多文件”，明确说明可一次选择多个文件。
- `03 官网与公众号` 标记为“可选”，不添加链接也能完成。
- 页面删除会被理解为必填门槛的“建议先传”、“核心”和必填星号。
- 保留资料类型分组，但分组只用于帮助用户理解用途，不代表上传优先级或必填等级。

## 补充资料上传

`02 补充资料` 使用同一个支持 `multiple` 的文件选择器，接受：

- Word：`.doc`、`.docx`
- 纯文本：`.txt`
- PDF：`.pdf`
- PowerPoint：`.ppt`、`.pptx`

用户可以从任一资料分组点击“选择文件”。一次选择多个文件后，每个文件创建一条独立的异步任务，分别显示文件名、资料分组、处理状态和后续操作。

选择器不接受图片、音频、视频、Excel 或 CSV。营业执照仍使用 `01 企业身份` 内的独立图片/PDF 入口。

## 完成初步设置

- 主按钮固定为“完成初步设置”，初始状态即可点击。
- 按钮旁明确说明“所有资料均可稍后补充”。
- 用户未上传执照时，不校验企业名称和统一社会信用代码。
- 用户已上传执照时，已回显字段仍可修改，但留空不阻止完成初步设置。
- 未填写的字段保持“待补充”状态，不写入伪造的企业事实。
- 完成后仍进入现有六维诊断页；已提交的异步资料继续处理，不阻塞跳转。

## 状态与能力边界

- 无任何资料时，完成操作只记录“初步设置已跳过，资料待补充”，不将企业画像标记为已确认事实。
- 有执照回显字段时，静态原型仍明确标记 OCR 待接入，不把演示值宣称为真实识别结果。
- 补充资料仍只生成知识候选，异步任务不自动变成企业正式事实。

## 验收标准

1. 三个区域均显示“可选”，不再显示“建议先传”或必填星号。
2. 用户不选择任何文件、不填写任何字段、不添加任何链接时，也可以完成初步设置并进入六维诊断。
3. 主按钮初始可用，文案为“完成初步设置”。
4. `onboardingMaterialFile` 含有 `multiple`，`accept` 仅包含 `.doc,.docx,.txt,.pdf,.ppt,.pptx` 及对应 MIME 类型。
5. 一次选择至少两个支持文件后，页面产生两条独立的异步任务。
6. 营业执照图片回显与字段编辑仍正常工作。
7. 原型全量自动测试通过。
8. 1440 × 900 和 390 × 844 真实浏览器验收中，无水平溢出、操作遮挡或控制台异常。
