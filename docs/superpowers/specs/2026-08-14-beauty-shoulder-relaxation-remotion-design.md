# 美业肩颈放松 Remotion 混剪设计

## 目标

把现有「肩颈放松」素材制作成一条可直接预览和导出的 9:16 竖屏短视频，在高级疗愈感与获客转化之间取得平衡。成片约 20.7 秒，适用于抖音等短视频渠道；静态素材、数字人和演示文案不得表述为已上线生产能力或真实疗效承诺。

## 素材范围

- `digital-human-square.mp4`：20.736 秒，1080×1080，25fps，含单声道人声。
- `digital-human.mp4`：20.720 秒，1080×1920，25fps，备用竖屏数字人源。
- `scene-01.png` 至 `scene-04.png`：办公室、到店、护理、放松四个 941×1672 场景。
- `cover-base.png`：暖色封面底图。
- `captions-editable.srt`、`captions.srt`、`script.txt`：字幕和口播文本。

素材只读使用。Remotion 工程中通过项目 `public` 目录的副本引用，避免修改剪映草稿和原始素材。

## 成片规格

- 画布：1080×1920。
- 帧率：25fps。
- 时长：以数字人主音轨的真实时长为准，目标约 518 帧。
- 输出：H.264 MP4，AAC 音频，像素格式 `yuv420p`。
- 音频：保留数字人原声为唯一主线；不默认加入来源和授权不明确的网络音乐。

## 叙事与时间线

1. **0–2.2 秒｜痛点钩子**
   - 数字人或肩颈动作近景开场。
   - 主标题「上班肩颈紧，别硬扛」快速浮入。
   - 「肩颈紧」「别硬扛」作为高对比重点词。
2. **2.2–7.2 秒｜共鸣建立**
   - 办公室场景轻推镜。
   - 字幕跟随原声，说明久坐后的肩颈紧绷感。
3. **7.2–15.8 秒｜体验展示**
   - 到店、护理、舒缓场景依次切换。
   - 每个静态场景做轻微缩放和平移，避免静帧感。
   - 转场以 6–10 帧短叠化和克制柔光为主。
4. **15.8–20.7 秒｜转化收口**
   - 夜间放松场景回到数字人或人物松弛状态。
   - CTA「私信回复『肩颈』」以暖杏色胶囊出现。
   - 末帧停留约 1.2 秒，确保行动指令可读。

## 视觉与字幕

- 主色：奶油白、暖杏、浅木色、深咖；不使用高饱和促销红。
- 字体：优先系统可用的中文无衬线粗体，保留跨机器渲染的回退字体。
- 标题位于安全区上方，字幕位于画面下部但避开平台底部操作区。
- 常规字幕采用深咖半透明底板和白字；每屏最多两行。
- 重点词用暖杏色或字号变化强调，不做逐字乱跳。
- CTA 为清晰胶囊按钮，但不伪装成真实可点击控件。

## Remotion 结构

- 根入口注册单一主合成 `BeautyShoulderRelaxation`。
- 时间线由数据配置驱动：镜头起止帧、素材、裁切位置、字幕和重点词分离维护。
- 组件边界：`SceneMedia` 处理图片/视频裁切与轻运动，`CaptionOverlay` 处理字幕，`HookTitle` 处理首屏标题，`CtaOverlay` 处理末屏转化信息。
- 所有动画均由 `useCurrentFrame()`、`interpolate()`、`spring()` 等帧确定性 API 驱动；不依赖 CSS transition 或运行时随机数。

## 异常处理

- 素材缺失时构建前检查并明确报出缺失路径，不渲染空白视频。
- 字幕时间超出合成时长时裁切到最后一帧。
- 原视频比例不一致时使用 `object-fit: cover` 和可配置焦点，优先保护人脸与肩颈区域。
- 若主音轨时长与元数据有轻微差异，以媒体解析出的真实时长决定合成帧数。

## 验收

- Remotion 能列出并渲染 `BeautyShoulderRelaxation` 合成。
- 输出分辨率、帧率、时长和音视频编码符合规格。
- 抽查开头、共鸣、护理、CTA 四个关键时间点，无黑帧、错裁、字幕溢出或遮挡人脸。
- 完整播放确认人声连续、镜头切换与字幕语义同步。
- 末屏 CTA 至少稳定可读 1.2 秒。

## 明确不做

- 不修改原剪映草稿。
- 不下载或加入版权状态不明的音乐、字体和网络素材。
- 不加入疗效保证、医疗诊断或夸大承诺。
- 不在本次范围内制作横屏、多语言或批量模板系统。
