# 企业 AI 经营大脑通用产品升级设计

> 日期：2026-08-04
> 状态：已确认设计稿，待用户复核
> 适用范围：`AI获客产品` 项目的通用化升级、1.0 收口、格优大客户定制与现有资产迁移
> 会议依据：2026-08-04《企业 AI 经营大脑产品规划讨论》

## 1. 升级结论

现有“殡葬 AI 获客产品”升级为面向中小企业的通用产品“企业 AI 经营大脑”。

产品只维护一套通用底座：

- “AI 获客经营代理”是企业 AI 经营大脑的核心业务模块，不再代表整个产品。
- 殡葬是第一个行业配置包，不再是通用产品的默认行业。
- 格优是第一个大客户，通过行业知识、合规、组织、模板、指标和服务配置实现定制，不分叉一套独立产品。
- 产品 1.0 先交付企业老板能直接使用的专业成果，再进入持续获客运营。

升级后的核心价值是：

> 企业完成基础建档后，AI 基于经确认的企业知识生成品牌、经营和营销成果，并持续推进获客计划与结果复盘。

## 2. 现状与能力边界

### 2.1 已有设计资产

当前项目已有：

- 企业知识库、多模态素材、知识来源、版本、权限和审核设计。
- 内容创作、爆款拆解、数字人、作品库、平台绑定和用量设计。
- 企业 Agent、运营计划、任务审批、AI 销售、PPT / 朋友圈和结果复盘原型。
- 老板、运营与 AI 的职责边界，以及测试型、潜力型、重点精制三层内容生产漏斗。
- 15 份模块 PRD 草稿和一份静态高保真商家端原型。

### 2.2 当前真实实现状态

当前资产主要是方案、PRD 和可交互静态原型，不是已接通的产品。

| 能力 | 真实状态 |
|---|---|
| 页面与交互 | 已有静态高保真原型 |
| 企业知识库 | 仅有原型和 PRD，未接后端 |
| 企业公开信息补全 | 未实现 |
| 文案、计划与复盘生成 | 前端定时器模拟 |
| PPT / DOCX 生成 | 未实现 |
| 图片生成 | 使用随机占位图，未接生成服务 |
| 本地 Codex | 仅界面演示，未接真实任务 |
| 云端任务中心 | 未实现 |
| 数字人与视频生成 | 仅有预置 MP4 样片 |
| 平台发布与 CRM | 未接入 |
| 计费 | 仅有设计与用量演示，未扣费 |
| 小程序 | 未实现 |

后续所有对内、对外文案都必须区分“已设计”“原型可演示”“已接入”“已验收”四种状态。

## 3. 产品定位与用户

### 3.1 一句话定位

企业 AI 经营大脑是一套面向中小企业的经营知识与内容执行平台，通过企业建档、专业报告、营销物料和获客运营，帮助企业将经营信息和个人经验转化为可持续使用的组织能力。

### 3.2 核心用户

- 购买者：缺乏专业品牌、经营策划和内容运营团队的中小企业主。
- 方向用户：老板或经营负责人，确认企业信息、经营目标和对外发布。
- 执行用户：运营、市场、销售或门店人员，补充素材、质检、发布和回填结果。
- 平台用户：我方项目、内容、运营与技术人员，维护模板、配置、执行和审计。

### 3.3 产品原则

1. 首次使用先交付明确成果，不让用户先学习复杂 Agent 和模型概念。
2. 企业事实必须经用户确认，公开数据不得直接升级为对外正式口径。
3. 品牌、价格、承诺、法规、客户外发和正式发布必须保留人工确认。
4. 通用能力不硬编码行业或客户逻辑，差异通过行业包、客户配置和模板实现。
5. 对外不暴露 Codex、提示词、RPA 和底层模型等实现细节。
6. 不在缺少基线和真实结果的情况下承诺增长比例。
7. 1.0 以简单、可理解、可交付为优先，不以模块数量衡量产品完整度。

## 5. 1.0 核心链路与功能范围

### 5.1 首次使用链路

```text
输入企业名称
  → 获取公开基础信息
  → 用户确认、纠错和补充
  → 形成企业基础档案与品牌规范
  → 生成企业品牌报告
  → 生成企业经营计划书
  → 生成 PPT、海报或图文
  → 进入获客运营和结果复盘
```

企业经营计划书不默认写死为 90 天。通用产品支持月度、季度、年度和自定义周期；格优客户配置可将“90 天试点实施计划”作为默认模板。

### 5.2 1.0 必须交付

1. 企业建档与最小必要信息引导。
2. 企业公开信息候选补全、人工确认和来源记录。
3. 企业品牌报告。
4. 企业经营计划书。
5. 品牌 / 经营 PPT。
6. 宣传海报。
7. 公众号与朋友圈图文内容包。
8. 企业品牌视觉规范与模板选择。
9. 成果预览、人工审核、下载、版本和重新生成。
10. 基础用量记录和套餐配额。
11. 授权数据源的爆款搜索、对标账号追踪、相对基线判定和内容拆解。
12. AI 视频的选题、脚本、分镜、首帧确认、生成、混剪、质检和成片交付。
13. 内容与视频的人工发布 / 导出、结果回收和周期复盘。
14. H5 客户端；小程序作为后续适配目标。

### 5.3 1.0 获客与视频工作台

以下能力属于 1.0 的运营工作台，不阻塞企业建档和首次报告成果，但必须在 1.0 完成真实实现：

- 获客周计划和方向调整建议。
- 爆款搜索、追踪、相对基线判定、八维拆解和可迁移内容公式。
- 脚本、分镜、企业素材召回、生成镜头、数字人、混剪和成片。
- 三层内容生产漏斗。
- 人工导出 / 发布、已授权平台发布、结果回收和周期复盘。

爆款与 AI 视频的实现边界：

- 爆款数据优先使用已授权的第三方数据服务或官方接口，不使用未授权自爬作为正式产品链路。
- 爆款判定基于账号或类目相对基线，不仅使用绝对播放量。
- 拆解复用的是钩子、结构、情绪、视觉和转化等可迁移模式，不复制原文或原片。
- AI 视频严格执行“确认脚本 → 生成 / 匹配分镜首帧 → 确认分镜 → 生成视频镜头 → 混剪与质检”，避免在方向未确认时消耗高成本算力。
- 优先使用已授权企业真实素材和模板，只对缺失或高价值镜头调用生成模型。
- 数字人仅使用授权形象和声音，成片按适用规则标识 AI 生成或合成内容。

### 5.4 二期能力

- AI 销售助手、线索标签和跟进话术。
- CRM 和授权消息渠道接入。
- 客户消息初筛、人工接管和成交材料生成。
- 销转数据复盘和话术 SOP 迭代。

### 5.5 暂缓或不进入产品主线

- 本地 Codex 客户端一级入口。
- 硬件捆绑销售。
- 面向普通用户的模型、提示词和完整 Agent 配置。
- 个微自动托管、多账号群控和反检测对抗。
- 未经人工确认的批量发布、客户外发和自动报价。

## 7. 行业包与大客户定制机制

### 7.1 四层能力边界

| 层级 | 内容 | 可定制性 |
|---|---|---|
| 通用底座 | 租户、权限、知识、任务、产物、版本、计费、审计 | 不允许客户分叉 |
| 标准模块 | 建档、品牌报告、经营计划、营销物料、获客、复盘 | 可按套餐开启 |
| 行业配置包 | 行业字段、知识、合规、模板、指标 | 平台统一维护 |
| 大客户配置 | 组织、品牌、专属模板、系统对接、服务和验收 | 按客户配置或扩展 |

### 7.2 可定制与不可分叉项

大客户可定制：

- 企业建档字段。
- 报告目录、文案规则和品牌视觉模板。
- 行业知识、话术、合规词和审核规则。
- 总部、区域、门店或业务单元组织结构。
- 专属经营指标、数据看板和试点验收。
- 经确认的第三方系统对接。
- 陪跑、响应、培训、验收和商务服务。

大客户不单独分叉：

- 企业知识库底层。
- 任务、产物和版本数据模型。
- 权限、审计、计费和通用成果中心。
- PPT、DOCX 和图片生成的通用执行协议。

## 8. 格优大客户配置包

格优作为首个大客户，使用通用产品和殡葬行业配置包。

### 8.1 客户专属配置

- 殡葬行业企业建档字段。
- 殡葬行业知识、敏感词、风险等级和强制发布前审核。
- 格优总部、区域和门店的组织与知识权限。
- 寿衣、殡仪服务和门店场景内容模板。
- 总部统一品牌素材与门店本地化信息的组合规则。
- 格优专属品牌报告、经营计划和汇报模板。
- 90 天试点实施计划模板。
- 3–5 家种子门店的人机共营、内容发布、线索记录和复制复盘。

### 8.2 格优试点验收

试点验收不以“平台页面已搭建”为准，至少覆盖：

1. 总部与种子门店基础资料的真实建档与确认。
2. 关键企业事实、素材、品牌口径和合规规则的覆盖。
3. 已确认模板生成真实可用的 DOCX、PPTX、PDF 或图片成果。
4. 3–5 家门店完成小范围发布与人工审核。
5. 咨询、有效线索、成交或无法回收的结果有明确来源记录。
6. 形成一次模板、SOP、单位成本和复制条件复盘。

## 9. 云端调度与本地文件生成

### 9.1 已确认架构

采用“云端任务调度 + 本地文件生成”：

```text
通用产品前端
  → 云端任务中心
      ├── 用户、企业与权限校验
      ├── 企业知识检索
      ├── 内容结构与生成要求
      ├── 任务状态、额度、版本和审计
      ├── 爆款数据服务与视频 Provider 异步任务
      └── 分配给已绑定的本地执行器
            → 本地生成执行器
                ├── Codex 任务编排
                ├── PPTX / DOCX 生成
                ├── 图片生成或企业素材排版
                ├── 视频分镜与本地素材编排
                ├── 视频片段下载、混剪、字幕与成片
                ├── PDF / PNG 渲染
                └── 文件质量检查
                      → 云端成果中心
                          └── 预览、审核、下载和重新生成
```

### 9.2 云端职责

- 保存企业档案、知识和品牌规范。
- 判断用户是否有权使用相关资料。
- 生成结构化任务，只下发当前任务的最小必要信息。
- 管理排队、取消、超时、重试、额度和费用。
- 统一管理爆款数据服务、图片模型、数字人、图生视频和文生视频 Provider 的异步任务与回调。
- 保存预览、最终文件、生成依据和版本历史。
- 本地执行器离线时保留任务，不将离线伪装为执行中。

### 9.3 本地执行器职责

- 接收经授权的最小任务数据。
- 调用本机 Codex 完成内容编排和工具调用。
- 生成真正可编辑的 PPTX 和 DOCX。
- 调用图片模型，或使用企业素材完成海报排版。
- 根据已确认脚本生成分镜任务，优先匹配企业素材，对缺失镜头提交生成任务。
- 下载云端 Provider 返回的视频片段，完成混剪、字幕、配音、转场、音乐与 AI 标识。
- 检查成片分辨率、时长、音画同步、黑帧、缺失片段、字幕溢出和文件可播放性。
- 将 PPTX / DOCX 渲染为 PDF / PNG 预览。
- 执行溢出、缺图、空页、格式损坏和文件可打开检查。
- 上传源文件、预览文件、检查报告和失败原因。
- 任务结束后按保留策略清理临时材料。

### 9.4 首期真实产物

| 产物 | 源文件 | 预览 / 交付 |
|---|---|---|
| 企业品牌报告 | DOCX | PDF |
| 企业经营计划书 | DOCX | PDF |
| 品牌 / 经营汇报 | PPTX | PDF + 逐页 PNG |
| 宣传海报 | 可编辑配置记录 | PNG / JPG |
| 公众号 / 朋友圈 | 结构化内容包 | 标题、正文、配图和发布建议 |
| AI 视频 | 脚本、分镜、素材与生成配置 | MP4 + 封面 + 字幕 + 发布文案 |
| 爆款拆解 | 数据来源、原内容标识与拆解结果 | 八维拆解 + 可迁移公式 + 生成任务入口 |

### 9.5 任务协议最小字段

- 企业 ID、用户 ID、任务类型、任务版本。
- 使用的知识条目及版本。
- 品牌模板和视觉规范版本。
- 输出格式、页数、尺寸、语言和用途。
- 截止时间、优先级、费用上限和审核要求。
- 产物列表、检查结果、失败阶段和失败原因。

知识或模板变更不得静默覆盖已生成文件；重新生成必须建立新版本并保留旧版依据。

### 9.6 异常处理

- 本地执行器离线：云端显示“等待执行器”。
- Codex 或生成工具失败：保留日志与中间结果，允许从失败阶段重试。
- 文件渲染失败：任务不得进入“已完成”，转人工处理。
- 图片模型失败：可回退到企业素材或模板排版，但必须标明降级方式。
- 爆款数据服务不可用：保留历史数据和人工导入入口，不伪造实时热度。
- 视频 Provider 失败：只重试失败镜头；连续失败后转企业素材、静态画面或人工处理，不重做已通过镜头。
- 知识依据不足：暂停任务并请求补充或确认，不得编造企业事实。
- 敏感信息：只下发当前任务的必要内容，并记录读取范围。

## 10. 商业化与服务边界

### 10.1 体验和计费

- 支持免费体验额度，会议提出的“海报赠送 10 次”作为待成本测算的候选规则，不直接写成已上线政策。
- 套餐可按月或按年订阅，并对文件、图片、页数或模型用量设置配额。
- 数字人、视频、第三方数据和高成本图片模型应单独核算。
- 定价前必须完成单份产物、单企业和单客户服务成本测算。

### 10.2 陪跑服务

产品可配套新手课程、案例、操作指导和项目陪跑，但必须明确：

- 响应时间、指导次数和服务期限。
- 客户必须提供的资料、负责人和审核责任。
- 我方产品、运营、定制开发和第三方服务的边界。
- 修改次数、交付格式和验收标准。

- 通用企业首用链路可完整演示。
- 格优大客户定制通过配置表达，不破坏通用主体。
- 原型不再将未接入的 Codex、生成模型、平台发布和业务数据显示为真实在线。
- 关键页完成桌面端与移动端真实渲染，无溢出、遮挡和浏览器错误。

### 13.3 真实生成收口

- 云端真实创建任务，绑定本地执行器能真实领取。
- 本地执行器生成可编辑源文件，不仅改变页面状态。
- 云端能区分排队、等待执行器、执行、审核、完成和失败。
- PPTX 和 DOCX 可打开，并完成全页渲染检查。
- 图片可预览、下载，并能追溯使用的企业素材或生成配置。
- 爆款结果可追溯数据源、采集时间、原内容标识、基线口径和拆解版本。
- AI 视频完成脚本与分镜两道确认，失败镜头可单独重做，成片 MP4 通过可播放、音画同步、字幕和缺失片段检查。
- 本地执行器断开后任务不丢失，恢复后可继续。
- 未授权知识无法进入生成任务。
