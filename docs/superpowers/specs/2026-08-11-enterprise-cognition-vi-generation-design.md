# 企业认知与 VI 生成设计

> 日期：2026-08-11  
> 状态：已完成产品方案确认，待实施  
> 范围：`prototype/index.html` 中企业大脑的“企业认知”二级页面

## 1. 目标

将“企业认知”从企业档案的重复展示，调整为企业的品牌偏好与基础 VI 管理页。系统根据企业在引导页中提交的表单、品牌资料和历史内容，归纳企业偏好，生成三套 VI 方向，再由企业选择一套生成完整的基础 VI 草案。

VI 草案必须经过人工确认才能启用，未确认内容不得被 PPT、海报、朋友圈图文、公众号文章等模块当作正式企业 VI 调用。

## 2. 信息架构

企业认知页采用“阶段式决策”结构，页面自上而下分为三个连续阶段。

### 2.1 企业偏好

展示 AI 根据企业已提交内容归纳的：

- 品牌语气；
- 希望客户感受；
- 视觉关键词；
- 图片风格；
- 版式倾向；
- 禁用表达与禁止承诺。

每个偏好项显示信息来源和状态。AI 识别的结果标记为“AI 推断”，企业修改后标记为“企业确认”。

### 2.2 三套 VI 方向

系统基于已提交内容和企业偏好异步生成三套有明显区分的 VI 方向。每套方向展示：

- 方向名称与设计说明；
- 标准色和辅助色预览；
- 字体倾向；
- 图片风格；
- 适用场景；
- 一张应用效果预览。

企业只能选择一套方向继续，也可以点击“重新生成三套方向”。未选择方向前，不能生成完整 VI。

### 2.3 完整 VI 草案

选择方向后，系统异步生成基础 VI 草案，范围包括：

- Logo 使用规范；
- 标准色与辅助色；
- 品牌字体；
- 图片风格；
- 版式规则；
- 品牌语气；
- PPT、海报、朋友圈图文和公众号封面等基础应用示例。

草案默认状态为“待确认”。企业点击“确认并启用”后，该版本才成为正式企业 VI。

## 3. 生成流程

1. 企业完成引导页并提交内容。
2. 系统异步归纳企业偏好并生成三套 VI 方向，不阻塞基础诊断。
3. 企业可检查和修改偏好，也可重新生成方向。
4. 企业选择一套方向。
5. 系统异步生成完整基础 VI 草案。
6. 企业检查草案，确认后启用。
7. 营销内容模块读取当前已启用的 VI 版本。

## 4. Logo 与来源边界

- 企业已上传 Logo 时，始终优先保留企业原 Logo，AI 不得擅自替换。
- 企业未上传 Logo 时，VI 草案只生成 Logo 方向建议和使用占位，不宣称已生成正式商标。
- 偏好和 VI 方向需标明来源：企业填写、上传资料、历史内容或 AI 推断。
- 未确认的 AI 推断不得反向覆盖企业已确认偏好。

## 5. 状态设计

页面顶部统一显示当前状态：

- `analyzing_preferences`：分析企业偏好中；
- `directions_ready`：请选择 VI 方向；
- `generating_vi`：正在生成完整 VI；
- `draft_review`：VI 草案待确认；
- `active`：企业 VI 已启用；
- `generation_failed`：生成失败，可重试。

已启用状态默认展示正式 VI，同时保留“修改偏好”“重新生成”和“查看历史版本”入口。

## 6. 版本与治理

- 新生成的 VI 始终作为新草案，不直接覆盖已启用版本。
- 企业确认新草案后，再将它切换为当前启用版本。
- 旧版本保留生成来源、确认人、确认时间、使用记录和版本差异。
- 未启用草案可直接删除。已启用 VI 需先停用，并保留历史版本和审计记录。

## 7. 交互和响应式

- 桌面端按“企业偏好 → 三套方向 → VI 草案”自上而下展开。
- 当前阶段保持明显主操作，未到达的阶段显示锁定原因，不同时堆叠多个主按钮。
- 手机端按三个阶段纵向排列，三套 VI 方向支持横向滑动。
- 完整 VI 不缩放为难以阅读的整页小图，而是按 Logo、色彩、字体、图片、版式和应用示例分区展示。

## 8. 失败与恢复

- 偏好分析、VI 方向生成和完整 VI 生成均为独立异步任务。
- 单个任务失败时保留上一个已完成阶段，不清空企业偏好、方向选择或已启用 VI。
- 页面提供“重试本阶段”，同时说明失败原因和当前仍然可用的版本。
- 没有已启用 VI 时，营销模块回退到系统默认视觉，并明确标记“未启用企业 VI”。

## 9. 原型实施边界

- 原型使用本地状态演示异步生成、方向选择、草案确认和版本切换。
- 真实文档理解、视觉模型、Logo 设计、品牌版权检查和商标注册不在静态原型的实现范围内，必须标记为“原型演示 · 待接入”。
- 引导页信息结构保持不变；本次只调整企业大脑下的“企业认知”页面及其原型状态。

## 10. 验收标准

1. 企业提交引导内容后，企业认知能进入偏好分析和三方向生成状态。
2. 页面正确展示偏好来源、AI 推断和企业确认状态。
3. 三套方向在配色、字体、图片风格、适用场景和应用预览上具有可识别差异。
4. 未选择方向时，不能生成完整 VI。
5. 未确认 VI 草案不会被营销内容模块当作正式 VI 调用。
6. 确认后，PPT、海报、朋友圈图文和公众号读取同一已启用 VI 版本。
7. 修改偏好、重新生成、生成失败、重试、新版本确认和历史版本查看均有可见状态反馈。
8. 在 1440×900 和 390×844 下无页面级横向溢出，手机端的方向选择和 VI 分区可阅读。
