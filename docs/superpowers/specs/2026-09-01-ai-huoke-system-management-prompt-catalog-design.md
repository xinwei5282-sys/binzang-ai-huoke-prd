# AI 获客系统管理与 Prompt 资产目录设计

> 日期：2026-09-01  
> 状态：已确认  
> 参考原型：`http://127.0.0.1:8010/index.html?review=prompts`（杭小消后台）  
> 目标原型：`prototype/index.html`（AI 获客）

## 1. 背景与目标

AI 获客当前“设置”区域使用“企业设置、成员与权限、平台账号、Agent 权限、用量与套餐、帮助与服务”的旧结构。“Agent 权限”只展示知识、数据、动作和结果四项静态边界，无法回答系统实际使用了哪些 Prompt、由哪个模型执行、当前版本是什么以及谁可以修改。

本次将系统管理区对齐杭小消已确认的 SaaS 管理结构，并将“Agent 权限”替换为可审计的“提示词管理”。目标是：

1. 系统管理信息架构与杭小消保持一致。
2. 展示 AI 获客当前实际使用的全部 Prompt，而不是示例清单。
3. 每条 Prompt 可追溯到功能、场景、完整正文、模型、参数、版本、状态和维护边界。
4. 平台基线只读，租户可配置 Prompt 具备编辑、测试、发布和回滚闭环。
5. 不改变 AI 获客业务工作台、品牌表达和现有页面级 PRD 抽屉。

## 2. 已确认方案

采用“完整对齐系统管理七项，数据适配 AI 获客”的方案：复用杭小消的信息架构和交互合同，但不引入杭小消租户文案或消费知识数据。

未采用的方案：

- 只替换 Agent 权限：改动小，但无法满足其他系统管理能力与杭小消一致。
- 抽取两项目共享运行时组件：长期复用更强，但会同时重构两个项目，超出本次范围。

## 3. 范围

### 3.1 本期范围

- 将系统管理导航统一为七项：系统设置、成员管理、权限管理、平台账号、提示词管理、用量管理、日志与审计。
- 移除可见的“Agent 权限”入口；旧 `agent-center` 路由兼容跳转到 `prompts`。
- 成员管理与权限管理拆分：成员只分配角色，角色统一维护模块、数据和按钮权限。
- 新增 AI 获客 Prompt 资产目录、完整正文查看、搜索筛选、模型参数、版本操作。
- 用量与日志页面对齐杭小消的字段和操作结构，并换成 AI 获客数据。
- 为七项系统管理页面分别补齐字段级 PRD，并在当前页面右侧“页面 PRD”抽屉中展示。
- 桌面端与移动端保留 AI 获客现有适配能力。

### 3.2 非本期范围

- 不修改 AI 获客首页、企业大脑、品牌经营、营销物料和获客业务流程。
- 不重构杭小消项目。
- 不接入真实 Prompt API、模型调用、权限服务、额度服务或日志后端。
- 不实现 Prompt A/B 实验、Prompt 市场或跨租户共享。
- 不为数字人训练、结构化查询等非文本生成能力伪造 Prompt。

## 4. 信息架构

系统管理导航固定顺序如下：

1. 系统设置 `system`
2. 成员管理 `members`
3. 权限管理 `permissions`
4. 平台账号 `bind`
5. 提示词管理 `prompts`
6. 用量管理 `usage`
7. 日志与审计 `logs`

旧路由映射：

- `settings` → `system`
- `member` → `members`
- `agent-center` → `prompts`
- `usage` 保持兼容，但标题改为“用量管理”

菜单、页面标题、面包屑和路由状态必须同步，浏览器刷新或带 `?review=<route>` 打开时应进入正确页面。

七项路由都必须注册页面级 PRD。切换页面时，右侧“页面 PRD”入口同步更新标题、页面键、版本和正文；不得继续显示上一业务页面 PRD。

## 5. 七项页面设计

### 5.1 系统设置

仅维护当前租户的企业基础信息：企业名称、企业简称、统一社会信用代码、注册地址、联系人、联系手机。能力开通、通知规则、模型参数不混放在此页。

### 5.2 成员管理

管理成员账号与生命周期：新增成员、分配一个或多个角色、启用、停用、重置密码。成员页只展示角色与最终权限摘要，不提供逐账号权限覆盖。

### 5.3 权限管理

使用 SaaS RBAC：

- 角色列表展示角色、权限摘要、创建人、创建时间和操作。
- 编辑角色时配置模块权限、数据范围和按钮权限。
- 提示词管理按钮权限固定包含：查看、编辑、测试、发布。
- 父级模块与子按钮支持全选、半选和取消联动。
- 成员最终权限为所分配角色权限并集。

### 5.4 平台账号

沿用 AI 获客既有账号授权和发布边界。只在官方 API 完成真实授权与端到端验证后开放自动发布；无开放接口的平台保持导出后手动发布。

### 5.5 提示词管理

页面结构与杭小消保持一致：

- 顶部说明：只展示租户已开通且当前账号有权访问的功能 Prompt。
- 工具栏：按已开通功能筛选、按名称/场景/模型搜索、当前结果数。
- 表格列：Prompt/使用场景、关联功能、关联模型/参数、Prompt ID/版本、状态、操作。
- 操作：测试 Prompt、查看或编辑配置、发布版本、回滚版本。
- 配置抽屉或弹层必须展示完整 Prompt 正文，不得只展示摘要。

维护边界：

- 平台基线：只读，可查看完整内容和执行测试，不显示编辑、发布或回滚。
- 租户可配置：可编辑完整正文、模型和参数；保存为草稿后才能测试，测试通过后发布新版本；可回滚到历史已发布版本。
- 合规检查温度锁定为 0，不允许租户放宽事实、合规、审批或发布边界。

### 5.6 用量管理

展示共享总额度、已用量、剩余额度、活跃子账号、子账号消耗和额度调整记录。平台增加额度只读展示；租户管理员可设置子账号用量上限，观察员只读。

### 5.7 日志与审计

统一展示并筛选五类记录：操作日志、登录与安全日志、AI 调用日志、知识使用日志、导出记录。支持查看详情、导出日志和导出统计报表；不支持批量导出知识正文或附件。

## 6. Prompt 资产真源与目录

Prompt 清单取以下真源的并集，并按稳定 ID 去重：

1. `prd/PRD_提示词.md` §12 注册表。
2. `prd/PRD_企业AI经营大脑_当前开发基线.md` §7 完整 Prompt。
3. `prd/pages/**` 各页面“Skill / Prompt”章节。
4. `remotion/beauty-shoulder-relaxation/src/prompts.ts` 的 AI 混剪策划与质量门禁。
5. 原型中实际执行的租户微调、内容生成和合规 Prompt。

首版必须覆盖以下功能簇：

| 功能簇 | 必须展示的 Prompt |
|---|---|
| 全局与路由 | P-000 全局安全与事实边界、P-001 用户意图路由 |
| 企业资料与诊断 | P-010 企业资料提取、P-011 初步诊断、P-012 深度诊断 |
| 企业 VI 与情报 | P-020 VI 三方向、P-021 VI 场景单图、P-030 外部情报标准化 |
| 企业知识治理 | 分类建议、标签生成、知识自动分组、适用范围识别、知识冲突识别、结构化提取、优化建议识别 |
| 营销物料 | P-040 内容工厂、P-041 公众号文章、朋友圈图文、海报内容、海报视觉、PPT 大纲、PPT 页面内容、PPT 背景、内容合规检查 |
| AI 获客 | 获客计划、爆款结构分析、P-042 营销视频方向、P-043 营销视频方案、P-044 视频质量门禁、AI 混剪策划、AI 混剪质量门禁 |
| 经营与发布 | P-050 公司经营计划、P-060 RPA 发布前检查 |

数字人形象/声音训练、结构化事实查询等非 Prompt 驱动能力不进入 Prompt 表，但在功能筛选说明中显示“非 Prompt 驱动”。

## 7. Prompt 数据合同

原型内使用数据驱动目录，每条记录至少包含：

```text
id, name, featureKey, feature, scene,
model, parameters, version, status,
scope, visibleToCurrentAccount, sourceRef,
content, inputContract, outputContract
```

约束：

- `id` 唯一且稳定；同一 Prompt 的版本变化不改变 ID。
- 所有可见目录项必须存在非空完整正文。
- `sourceRef` 指向 PRD、页面 PRD 或代码真源，便于人工复核。
- 列表按已开通功能和当前账号权限过滤，不能仅靠前端隐藏越权数据。
- 测试、发布和回滚均写入操作日志与 AI 调用日志示例。

## 8. 核心交互与状态

### 8.1 搜索与筛选

- 功能筛选和搜索词同时生效。
- 搜索范围包含名称、场景、功能、模型、Prompt ID。
- 无结果时显示可恢复的空状态和“清除筛选”。
- 结果计数显示“当前结果 / 当前账号可见总数”。

### 8.2 查看与编辑

- 点击“查看配置”展示完整正文、输入输出合同、模型参数、版本和真源。
- 租户可配置项点击“编辑配置”进入可编辑状态。
- 未保存离开时提示存在未保存更改。
- 保存只产生草稿，不直接覆盖已发布版本。

### 8.3 测试、发布与回滚

- 测试需要样例输入；缺少必填变量时明确提示。
- 测试结果展示 Schema、事实引用和合规校验结果。
- 校验失败不得发布。
- 发布生成新版本并更新状态；历史任务继续保留原版本。
- 回滚选择历史已发布版本，确认后生成新的回滚版本记录，不删除历史。

### 8.4 旧路由兼容

访问 `?review=agent-center` 时自动进入 `prompts`，显示一次轻提示“Agent 权限已升级为提示词管理”；不能出现空白页或旧静态治理表。

## 9. 视觉与响应式

- 继承 AI 获客现有品牌色、字体、侧栏和页面级 PRD 抽屉。
- 七项系统管理页的布局、表格密度、筛选器、徽标和操作层级与杭小消保持一致。
- PC 端为主要使用场景；移动端保留关键功能，表格使用局部横向滚动，筛选器纵向排列，详情弹层改为全宽抽屉。
- 必须保留键盘焦点、Escape 关闭、焦点返回和 `prefers-reduced-motion` 支持。

## 10. 异常与空状态

- 无开通功能：提示联系管理员开通，不展示伪 Prompt。
- 无查看权限：展示权限说明，不泄露 Prompt 名称或正文。
- Prompt 正文缺失：该项标记“配置异常”，阻断测试和发布。
- 测试失败：保留输入与草稿，展示失败维度和可重试入口。
- 发布冲突：提示当前生效版本已变化，要求刷新后重新确认。
- 日志或用量为空：提供字段说明和筛选重置，不伪造成功记录。

## 11. 实现边界

- `prototype/index.html` 继续作为 AI 获客原型真源。
- 可复用杭小消的结构、字段和交互模式，但不建立对杭小消运行时代码的依赖。
- Prompt 目录使用独立常量与渲染函数，避免将完整正文重复散落在静态 HTML 中。
- 不改动现有业务页面的数据结构和交互逻辑。

### 11.1 页面级 PRD

七项系统管理分别维护独立 PRD 文档，并使用与现有 AI 获客页面一致的十段式评审结构：页面概述、页面级业务规则、页面字段级定义、页面级操作定义、产品边界、页面级流程、通知与日志、异常与空状态、页面验收标准、技术实现提示。

原型中的 `PAGE_PRD_CONTENT` 为浏览器展示数据；`prd/pages/` 文档为书面评审真源。两者的页面名称、路由、版本、关键字段、操作和边界必须一致。

## 12. 验证策略

### 12.1 结构测试

- 七项导航存在且顺序正确。
- 不再出现可见的 Agent 权限入口。
- `agent-center` 兼容跳转到 `prompts`。
- 成员与权限为两个独立页面。
- Prompt 必备清单全部注册，每条都有非空完整正文和真源引用。
- 平台基线与租户可配置操作边界正确。
- 权限管理包含提示词查看、编辑、测试、发布按钮权限。
- 日志包含五个分类，用量包含共享额度与子账号上限。
- 七项系统管理路由均存在十段式页面 PRD，抽屉内容与当前路由匹配。

### 12.2 浏览器验收

- 依次打开七项系统管理页面并截图。
- 提示词筛选、搜索、无结果重置可用。
- 查看平台基线完整 Prompt；确认不可编辑。
- 编辑租户 Prompt、保存草稿、测试、发布与回滚演示闭环可用。
- 旧 `agent-center` 路由正确跳转。
- 桌面端无页面溢出；移动端表格仅局部滚动，抽屉可完整操作。
- 页面无控制台错误，页面级 PRD 抽屉仍随路由正确更新。
- 依次打开七项系统管理页的 PRD 抽屉，标题、页面键和正文均与当前页面一致。

## 13. 验收标准

1. 系统管理导航与杭小消七项结构、命名和顺序一致。
2. AI 获客所有实际使用 Prompt 均可在目录中检索并查看完整正文。
3. Prompt 与功能、模型、参数、版本、状态和真源可追溯。
4. 平台基线只读，租户 Prompt 的编辑、测试、发布、回滚边界清晰。
5. 成员、角色权限、平台账号、用量和日志页面达到杭小消相同的产品闭环。
6. 旧 Agent 权限入口和静态治理表不再对用户可见，旧链接不会失效。
7. 七项系统管理页面均可在页面内打开对应的完整字段级 PRD。
8. 全量结构测试和桌面/移动端浏览器验收通过。
