# 营业执照单页上传与即时识别设计

## 目标

将“3 分钟了解企业”从四步分页流程收口为一个页面内的连续任务：用户上传营业执照后，在原位立即看到识别进度和可编辑的企业基础信息，无需跳转到独立的“AI 识别”页。

## 范围

- 修改当前活跃原型 `prototype/index.html` 中的首次企业了解引导。
- 将营业执照上传、识别、修改和确认收口在同一弹窗页面内。
- 在同一页提供公司 / 产品、客户 / 成交、品牌 / 内容、经营 / 渠道资料上传，以及官网 / 公众号内容源入口。
- 营业执照使用即时反馈流程；其他文件与链接统一进入异步任务队列。
- 保留“确认后才成为企业事实”的知识治理边界。
- 本次不接入真实 OCR、文档解析、网页采集或公众号抓取接口，不改造后端、鉴权或文件存储。

## 页面结构

引导弹窗仅保留一个主任务区，不再展示四步分页导航。

1. 标题：“3 分钟了解企业”。
2. 说明：“上传营业执照，立即核对企业基础信息”。
3. 主上传区：支持点击选择营业执照图片或 PDF。
4. 识别结果区：上传后在主上传区下方原地展开。
5. 补充资料区：以四组可展开卡片呈现，可一次提交多份文件。
6. 异步内容源区：支持粘贴官网、公众号文章链接，或绑定授权的公众号账号。
7. 任务状态区：在当前页面展示各来源的排队、采集、解析、待确认或失败状态。
8. 主操作：“确认执照信息，其他资料后台处理”。
9. 次要操作：“重新上传”“暂时没有执照，手动填写”和“稍后处理”。

## 初步设置资料清单

资料清单用于降低用户判断成本，不是全部必传的阻断门槛。页面必须区分“建议先传”“核心”“推荐”和“可选”。

### 1. 企业身份·建议先传

- 营业执照。
- 资质证书、许可证或荣誉证明。
- 门店、工厂、团队或服务场所照片。

营业执照在当前页即时返回可编辑的识别字段；其他资质和图片进入异步解析。

### 2. 企业与产品·核心

- 公司介绍、企业宣传册或现有企业 PPT。
- 产品手册、产品清单、规格与适用场景。
- 报价表、服务套餐、价格有效期与优惠规则。
- 服务流程、交付范围、售后政策与禁止承诺。

### 3. 客户与成交·推荐

- 目标客户画像、常见需求和关键购买场景。
- 成功案例、客户评价、成果证据与对外使用授权。
- 销售话术、常见异议处理、跟进 SOP 与报价审批规则。
- 售后、复购、转介绍和客户关系维护规则。

### 4. 品牌与内容·推荐

- Logo、标准色、字体、品牌手册和禁用表达。
- 历史 PPT、海报、公众号文章、图片和视频原素材。
- 效果较好和较差的内容样本，保留对应渠道与结果说明。
- 品牌语气、内容审核规则与合规词库。

### 5. 经营与渠道·可选

- 近 3–6 个月的营收、客单价、毛利和主要品类占比。
- 线索、建联、跟进、成交和复购漏斗数据。
- 新媒体、电商和搜索后台导出或截图。
- 账号清单、爆款链接、竞品和对标账号。

### 6. 官网与公众号·异步内容源

- 官网地址：异步发现并解析授权范围内的页面。
- 公众号单篇文章链接：异步抓取当前文章并提取内容候选。
- 公众号账号或历史内容：作为授权内容源绑定，用户明确选择历史范围和增量同步范围后才开始采集。
- 未授权、页面限制访问或公众号平台无可用接口时，状态必须是“等待授权”或“采集受限”，不得显示为采集成功。

## 交互与数据流

### 初始态

- 显示单一、高优先级的营业执照上传区。
- 接受 JPG、JPEG、PNG 和 PDF。
- 点击上传区必须打开真实文件选择器，不得只显示提示消息。

### 识别中

- 选择合法文件后，上传区原地显示“正在识别营业执照……”。
- 保留用户选择的文件名，让用户知道正在处理哪份资料。
- 静态原型使用短暂延时模拟处理，并明确标记“原型演示 · OCR 待接入”。

### 识别完成

- 在同一页原地展开以下可编辑字段：
  - 企业名称
  - 统一社会信用代码
  - 法定代表人
  - 成立日期
  - 注册地址
  - 经营范围
- 企业名称和统一社会信用代码为确认前必填项。
- 演示中的低置信度字段使用黄色提示，要求用户核对；高置信度也不自动成为正式企业事实。
- 点击主操作后，当前字段进入“已确认”状态，再在同一引导中继续补充主营业务、核心客户和经营目标。

### 其他资料与链接的异步处理

- 上传文件、粘贴链接或绑定内容源后，每个来源创建独立的异步任务行。
- 统一状态为：等待授权、已排队、采集中、解析中、待确认、部分成功、失败和已取消。
- 每行显示来源名称、提交或开始时间、当前阶段、已处理数量、预计下一步、失败原因和当前可执行操作。
- 异步任务不阻塞用户确认营业执照或继续初步设置。
- 任务完成只产生“知识候选”，负责人确认来源、适用范围、有效期和权限后才进入正式知识。

## 异常和降级

- 文件格式不支持：原地显示可操作错误，不进入识别态。
- 文件未选择：不改变当前页面状态。
- 识别失败：保留文件名，显示“重试识别”和“手动填写”。
- 字段缺失：使用“未识别，请补充”占位，不编造值。
- 用户重新上传：替换当前文件并重新生成演示识别结果，不保留上一份执照的字段值。
- 异步任务部分成功：保留已处理结果，只对失败项提供局部重试。
- 官网或文章链接无法访问：显示 HTTP 或权限原因，允许更换链接或改为手动上传。
- 公众号历史内容无授权：停留在“等待授权”，提供“去授权”或“改为粘贴文章链接”，不自动绕过限制。

## 能力边界

- 原型的“即时识别”是用于验证流程的模拟状态，不代表 OCR、文件上传服务或数据存储已接入。
- 模拟结果必须在页面内显示能力标识，不得使用“识别准确率”等无证据口径。
- 真实产品接入 OCR 后，保持相同的界面状态和字段结构，只替换识别数据来源。
- 公众号采集能力在授权、可用接口和端到端验证关闭前只展示流程与状态，不宣称可稳定抓取公众号历史内容。

## 验收标准

1. 首次引导不再显示“01 提供资料 / 02 确认识别 / 03 补充缺口 / 04 查看成果”分页步骤条。
2. 点击上传区可打开系统文件选择器。
3. 选择 JPG、JPEG、PNG 或 PDF 后，页面按顺序显示识别中和识别完成状态，全程不跳页。
4. 六个企业基础字段可直接编辑，必填项未填时不能确认。
5. 页面明确显示“原型演示 · OCR 待接入”。
6. 原有“上传按钮只弹提示、不打开文件选择器”的回归测试必须失败，修改后通过。
7. 现有企业诊断、知识待确认和登录引导相关测试全部通过。
8. 在 1440 × 900 桌面视口和 390 × 844 手机视口完成真实渲染检查，无内容溢出、操作遮挡或水平滚动。
9. 补充资料按企业 / 产品、客户 / 成交、品牌 / 内容、经营 / 渠道分组，每组显示具体资料示例和优先级。
10. 提交非执照文件或官网 / 公众号链接后，当前页面显示独立异步任务行，且不阻塞继续操作。
11. 异步任务行覆盖排队、采集、解析、待确认、部分成功、失败和等待授权状态，并提供可用的局部恢复动作。
12. 公众号单篇链接与账号级历史内容的入口、授权要求和状态口径明确分开。
