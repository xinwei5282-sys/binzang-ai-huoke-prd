# 企业 AI 经营大脑后台内容层级优化设计

> 日期：2026-08-06
> 状态：已确认，待实施
> 目标文件：`prototype/index.html`
> 视觉方向：A「决策工作台型」
> 参考方案：`validation/content-hierarchy-options.html`

## 1. 背景与问题

当前原型已经具备完整的业务导航、页面骨架和主要工作流，但内容区域存在以下共同问题：

- 页面标题、区块标题和卡片标题的字号、留白与边界接近，第一眼难以判断阅读顺序。
- 页面摘要、状态提示和内容面板多次表达相同信息，造成顶部拥挤、正文分组不清。
- 不同模块同时使用卡片、列表、步骤条和统计块，但缺少统一的层级语法。
- 业务重点、待处理事项、主要工作区和最近结果经常并列出现，重要性没有通过位置体现。
- 部分流程页使用横向小卡片表达连续步骤，削弱了任务前后关系。

本次优化允许调整板块顺序、合并重复内容，但不改变已确认的一级菜单、业务对象、权限边界、能力接入状态和人工确认门。

## 2. 设计目标

1. 用户进入任一页面后 2 秒内能识别页面目的、当前重点和主要操作。
2. 全项目形成可复用的四级内容层级：页面标题、区块标题、内容面板、行级信息。
3. 页面阅读顺序统一为“当前重点 → 待处理 → 主要工作区 → 最近结果或运行状态”。
4. 减少重复摘要和无必要卡片，让高密度后台保持紧凑但不拥挤。
5. 桌面、平板和手机使用同一内容语义，窄屏通过重排而不是缩小桌面结构。

## 3. 非目标

- 不修改侧栏菜单名称、分组和路由。
- 不改变品牌色、字体、圆角、状态词和控件高度 Token。
- 不新增业务模块、指标或未接入能力。
- 不为每个页面制造独立的视觉风格。
- 不把所有页面改造成经营数据看板。

## 4. 统一层级模型

### 4.1 一级：页面标题区

每个页面顶部只保留一个页面标题区，包含：

- 页面名称，20px / 600。
- 一句用途说明，12–13px，直接说明用户在这里完成什么。
- 页面级状态或范围信息，可选。
- 唯一实心主操作，可选。

规则：

- 标题区不使用卡片背景。
- 页面名称与顶栏名称允许形成上下文关系，但正文不再重复同义标题。
- 工具栏、筛选器和批量操作不得混入标题区。
- 状态标签与主操作不能同时争夺视觉主位；主操作优先。

### 4.2 二级：区块标题

区块标题负责说明一组内容的对象与口径，包含：

- 区块名称，14–16px / 600。
- 可选的一句口径说明、时间范围或数量。
- 可选的文字操作，例如“查看全部”。

规则：

- 区块标题位于面板外部，标题与面板之间保持 8px，前一区块与新区块之间保持 20–24px。
- 区块标题不使用图标、彩色竖线或独立卡片。
- 同一页面一屏内控制在 3–5 个主要区块。

### 4.3 三级：内容面板

内容面板承载同一业务对象或同一工作任务，使用白色表面、1px 边界和 6px 圆角。

规则：

- 指标组、连续列表和同一流程使用共用面板与内部隔线，不拆成多个悬浮卡片。
- 独立对象、独立任务、需要比较的方案才使用卡片。
- 面板头只在内容需要固定列名、状态或上下文操作时出现。
- 禁止卡片嵌套卡片；内部层级使用留白、字体、浅底区域和分隔线表达。

### 4.4 四级：行级信息

列表行、任务项、审批项和来源项保持紧凑，统一包含：

- 主对象名称。
- 一行来源、时间、负责人或影响范围。
- 文字状态。
- 就近操作，最多两个。

行级状态不能只用颜色表达。包含两行信息时行高为 56–64px，单行表格保持 44px。

## 5. 页面阅读顺序

### 5.1 标准顺序

适用于首页、企业大脑、AI 获客、营销物料、品牌与经营和结果复盘：

1. 页面标题区。
2. 当前重点：最多一个主要任务或结论。
3. 待处理事项：按风险与影响排序。
4. 主要工作区：列表、编辑器、生成器或详情。
5. 最近结果或运行状态：数据、成果、同步和异常。

如果页面没有真实的当前重点，不添加空的重点卡，直接进入主要工作区。

### 5.2 简化顺序

适用于设置、成员与权限、平台账号和用量页：

1. 页面标题区。
2. 分组导航或筛选。
3. 当前设置组或标准列表。
4. 危险设置、权限边界或审计信息。

这些页面不使用经营重点区，也不展示与任务无关的指标。

### 5.3 流程顺序

适用于企业建档、六维诊断、知识初始化、内容生成和视频制作：

1. 页面标题区与当前阶段摘要。
2. 紧凑步骤条或纵向任务阶段。
3. 当前步骤工作区。
4. 证据、素材、风险或预览侧栏。
5. 保存状态、确认门和恢复路径。

超过五步时只展示阶段摘要，详细过程进入纵向时间线。

## 6. 关键页面调整

### 6.1 首页

- 保留“当前最重要”作为唯一强视觉区块。
- 将下一步与待确认合并为“需要处理”，按优先级排列。
- 最近成果与用量、异常任务分为两个次级区块。
- 删除与重点任务重复的指标、说明和入口。

### 6.2 企业档案

- 标题区说明“确认企业事实，为诊断和生成提供依据”。
- 快速画像、六维诊断、品牌视觉和企业资料继续作为并列子视图。
- 子视图内部统一使用“当前状态 → 当前任务 → 证据或资料 → 最近版本”。
- 表单说明只保留在首次出现的位置，不在卡片和字段下重复。

### 6.3 品牌与经营

- 品牌报告与经营计划继续分开管理。
- 将创建入口、当前草稿和历史版本整合为一个工作区。
- 报告状态、来源与下载动作放在对象所在行，不另建成果卡。

### 6.4 营销物料

- 页面先展示发布准备状态，再进入 PPT、海报或公众号文章工作区。
- 将能力边界与发布确认合并为工作区状态栏。
- 历史物料使用统一列表，不为每件产物重复创建摘要卡。

### 6.5 AI 获客

- 当前重点展示最需要处理的获客任务或风险。
- 待确认、执行中、部分成功和失败任务进入同一任务列表。
- 知识依据、当前阶段、人工确认和结果保持在任务详情或抽屉中。
- 爆款追踪、内容创作、AI 视频和数字人继续作为子能力，不提升为一级页面重点。

### 6.6 企业大脑

- 页面顺序调整为“当前知识缺口 → 待处理事项 → 正式知识与来源 → Agent 授权与运行状态”。
- 知识健康、来源可追溯、待确认和授权 Agent 合并为一组连续指标。
- 数据源与处理状态保留在知识总览中，不重复出现在知识库标签页顶部。
- 维护中心集中处理版本冲突、过期、版权和知识缺口。

### 6.7 设置与管理

- 使用分组列表或二级导航，不使用功能入口卡片宫格。
- 每个设置组只有一个保存动作。
- 权限、数据范围、知识范围和高风险动作规则在同一上下文中呈现。

## 7. 布局与节奏

- 页面左右间距：桌面 28px、平板 20px、手机 14–16px。
- 页面标题区底部间距：20px。
- 区块之间：20–24px。
- 区块标题与面板：8px。
- 面板内部常规间距：12–16px。
- 紧密文字关系：3–6px。
- 桌面工作台主次两栏约为 2:1，侧栏 320–360px。
- 同一页面避免同时出现三种以上面板宽度和多套圆角。

## 8. 响应式

### 8.1 桌面 ≥1366px

- 保留 228px 主导航和 56px 顶栏。
- 页面工作区可使用主次双栏、固定详情侧栏和横向指标组。
- 标题区操作保持右对齐。

### 8.2 1024–1365px

- 保留侧栏，页面间距降为 20px。
- 次级侧栏缩小或改为抽屉。
- 指标组允许两行重排，但不拆成独立卡片。

### 8.3 768–1023px

- 侧栏改为抽屉，多栏内容转为单栏。
- 详情、证据和预览使用抽屉或置于主工作区之后。
- 页面标题区允许状态和操作换行。

### 8.4 <768px

- 内容使用单列任务流。
- 当前重点、主要操作和当前步骤优先显示。
- 触控目标至少 44px，表格横向滚动只发生在表格容器内。
- 次级指标、历史记录和运行状态后置，不隐藏关键功能。

## 9. 交互与状态

- 每个核心列表覆盖有数据、加载、筛选无结果、错误、无权限和部分成功状态。
- 当前重点卡中的操作直接进入对应对象或抽屉，不跳转到重复中心。
- 高风险操作继续使用人工确认，说明对象、依据、影响和确认结果。
- 异步任务显示开始时间、当前阶段、预计下一步、失败原因和局部重试动作。
- 弹窗与抽屉管理焦点，关闭后返回触发元素。

## 10. 实施边界

本次改造以公共层级系统和页面重排为主，禁止整文件重写：

1. 先补充公共层级类与回归测试。
2. 再迁移首页、企业档案、AI 获客和企业大脑。
3. 随后迁移品牌与经营、营销物料和设置。
4. 最后补齐响应式、状态和全量验收。

现有业务文案、事件处理、路由和本地演示数据默认保留；只有重复表达或影响层级的内容可以合并。

## 11. 验收标准

### 11.1 结构

- 每个路由页面只有一个页面标题区。
- 每个主要内容组都有明确区块标题或由上下文直接说明。
- 标题、面板和行级信息四级可通过自动化测试定位。
- 页面内不存在同义标题、摘要或主操作重复出现。

### 11.2 视觉

- 模糊观察时仍能识别页面标题、当前重点和主要工作区。
- 区块间距明显大于区块内部间距。
- 共用面板内部用隔线组织，不出现无意义卡片嵌套。
- 每个页面最多一个实心主操作。

### 11.3 响应式与可访问性

- 1920、1440、1366、1024、820 和 390px 宽度无整页横向滚动。
- 表格溢出只发生在表格容器中。
- 标题和操作不重叠，长文案不裁切。
- 所有交互元素具备键盘焦点状态和可读名称。

### 11.4 业务边界

- AI 结论继续显示依据或信息缺口。
- 高风险动作保留人工确认门。
- 原型演示与待接入状态不被包装成真实接入。
- 行业差异继续通过配置和知识蓝图表达，不复制页面。

## 12. 验证方式

交付时分别报告：

1. 规范与源码静态检查。
2. 自动化测试结果。
3. 真实渲染与布局审计。
4. 尚未接入的生产能力和人工验收项。

候选页面、结构测试或截图通过不代表后端能力已经交付。
