# “获客与经营”动态表单设计

## 1. 背景与目标

当前第 3 步“获客与经营”统一要求企业选择主要获客渠道、月均有效线索、转化率和收入模式。普通企业往往没有统计口径，也难以把线上零售、线下门店、项目销售等不同业务放进同一组指标，因此容易停顿或随意填写。

本次改造目标：

- 根据第 2 步已选择的经营模式，动态展示对应的获客与经营问题。
- 先用日常语言判断经营状态，不要求企业先统计精确数据。
- 知道数据的企业可展开填写数字，数字始终非必填。
- 第 3 步只描述当前现状，并补充一个“最想改善的环节”；年度目标仍留在第 4 步。
- 经营资料、官网和公众号继续作为辅助证据异步处理，不阻塞填写。

## 2. 已确认方案

采用“共同现状 + 按经营模式动态展开 + 可选数字 + 单一改善重点”的结构。

不采用以下方案：

- 每种模式独立成为一份问卷：多模式企业操作过重。
- 所有企业只填统一获客漏斗：容易混淆平台流量、门店客流和项目线索。

## 3. 页面信息结构

第 3 步保持单页表单，按以下顺序展示：

1. 共同获客现状。
2. 从第 2 步继承的经营模式标签。
3. 每个已选经营模式对应的动态现状卡片。
4. 最想优先改善的一个环节。
5. 经营资料上传、官网和公众号异步内容源。

如果第 2 步未选择经营模式，只显示共同现状和提示：“返回上一步选择经营模式后，可补充更有针对性的经营现状。”用户仍可继续或跳过。

## 4. 共同获客现状

所有企业只回答三组简单问题，均非必填。

### 4.1 客户主要从哪里来

多选：

- 平台自然流量
- 老客户转介绍
- 短视频 / 内容
- 付费广告
- 主动销售
- 渠道合作 / 经销商
- 线下自然客流 / 展会
- 私域 / 社群
- 说不清楚

“说不清楚”与其他选项互斥。

### 4.2 生意稳定程度

单选：

- 基本没有稳定来源
- 有客户，但时好时坏
- 来源相对稳定
- 正在快速增长
- 暂不清楚

### 4.3 客户由谁跟进

单选：

- 老板本人
- 客服 / 导购
- 专职销售
- 渠道伙伴
- 系统自动承接
- 没有固定方式
- 暂不清楚

## 5. 按经营模式动态展示

经营模式直接继承第 2 步的多选结果，不要求用户再次选择。多个模式可同时展开；取消某个经营模式时隐藏对应卡片但保留已填内容，重新选择后恢复。

每张模式卡片遵循同一规则：

- 先回答 2–3 组文字状态题。
- 数字数据放入默认收起的“我知道经营数据，可以补充”区域。
- 数字字段只用于提升诊断依据，不参与是否可继续的判断。

### 5.1 线上零售

文字状态：

- 流量状态：流量较少 / 有流量但不稳定 / 流量比较稳定 / 正在增长 / 暂不清楚。
- 成交状态：很少有人下单 / 主要靠活动或低价 / 日常下单较稳定 / 暂不清楚。
- 复购状态：基本没有复购 / 偶尔有老客回来买 / 复购比较稳定 / 暂不清楚。

可选数字：月访客数、月订单数、月广告投入、复购率。

### 5.2 线下门店

文字状态：

- 到店来源，多选：自然路过 / 熟客推荐 / 地图或团购平台 / 短视频或内容 / 社群或朋友圈 / 说不清楚。
- 客流状态：客流较少 / 周末或活动时较多 / 日常比较稳定 / 正在增长 / 暂不清楚。
- 老客经营：没有固定维护 / 靠店员个人维护 / 有会员或社群体系 / 暂不清楚。

可选数字：月到店人数、月成交单数、新客占比、会员复购率。

### 5.3 批发 / 分销

文字状态：

- 新采购方来源，多选：老客户介绍 / 展会与市场 / 主动开发 / 电商平台 / 区域代理 / 说不清楚。
- 询价与订单状态：询价较少 / 询价多但成交不稳定 / 订单相对稳定 / 旺季明显 / 暂不清楚。
- 渠道维护：没有固定维护 / 业务员个人维护 / 有分级与返利规则 / 有渠道管理体系 / 暂不清楚。

可选数字：月新增采购方、月订单数、复购率、平均账期。

### 5.4 项目型销售

文字状态：

- 项目机会来源，多选：老客户与转介绍 / 主动销售 / 招投标 / 渠道伙伴 / 内容获客 / 行业活动 / 说不清楚。
- 商机状态：项目机会较少 / 有机会但推进慢 / 商机相对稳定 / 暂不清楚。
- 主要卡点：找不到决策人 / 需求不明确 / 方案或报价竞争 / 跟进周期长 / 验收与回款 / 暂不清楚。

可选数字：月新增商机、赢单率、平均销售周期、平均项目金额。

### 5.5 专业服务

文字状态：

- 咨询来源，多选：熟人推荐 / 内容平台 / 搜索与地图 / 付费投放 / 商务合作 / 说不清楚。
- 咨询状态：咨询较少 / 咨询量波动大 / 咨询相对稳定 / 暂不清楚。
- 成交状态：多数只咨询不购买 / 依赖低价体验 / 评估后成交较稳定 / 暂不清楚。

可选数字：月咨询数、月成交数、平均成交周期、复购或续约率。

### 5.6 订阅 / 会员

文字状态：

- 新用户来源，多选：自然注册 / 内容获客 / 付费投放 / 销售邀请 / 渠道合作 / 老客推荐 / 说不清楚。
- 首次转化：注册后很少使用 / 试用多但付费少 / 付费转化相对稳定 / 暂不清楚。
- 续费状态：续费较低 / 依赖人工提醒 / 续费相对稳定 / 暂不清楚。

可选数字：月新增注册、试用转付费率、月流失率、月经常性收入。

### 5.7 定制生产

文字状态：

- 询盘来源，多选：老客户介绍 / B2B 平台 / 主动开发 / 展会 / 设计或品牌合作 / 说不清楚。
- 打样到下单：询盘较少 / 打样多但订单少 / 订单相对稳定 / 暂不清楚。
- 交付状态：产能经常闲置 / 旺季排期紧张 / 交付相对稳定 / 交期容易延误 / 暂不清楚。

可选数字：月询盘数、打样转订单率、月订单数、平均交付周期。

## 6. 最想改善的环节

所有经营模式共用一个单选字段：

- 让更多客户看到
- 增加咨询 / 到店 / 询盘
- 提高下单或签约成交
- 增加老客复购或续费
- 降低获客成本
- 缩短跟进或成交周期
- 暂时不知道

该字段只表达当前优先级，用于初步诊断排序；不替代第 4 步的年度经营目标。

## 7. 辅助证据和异步处理

保留以下入口：

- 上传经营资料：经营报表、平台截图、销售漏斗、渠道数据等。
- 官网链接。
- 公众号单篇文章链接。
- 公众号账号 / 历史内容授权入口。

资料上传和链接采集均为异步任务。任务继续显示排队、采集中、解析中、待确认、部分成功、失败和等待授权等状态。解析结果只能形成待确认候选，不自动覆盖手动填写内容。

## 8. 交互与完成度

- 所有字段非必填，允许整步跳过。
- 共同来源和模式来源使用可多选选项；“说不清楚”与其他选项互斥。
- 文字状态使用单选卡片，避免要求用户理解“线索”“转化率”等专业指标。
- 数字区默认收起，展开与否不影响下一步。
- 完成度只统计共同字段、当前已选择模式的可见字段和改善重点；隐藏模式不进入分母。
- 第 2 步经营模式变化后，第 3 步实时同步显示内容。
- 桌面端动态卡片内部最多两栏；手机端统一单栏，选项允许换行且不得横向溢出。

## 9. 诊断数据边界

初步诊断需要区分：

- 企业手动确认的当前状态。
- 上传资料或链接提取的待确认证据。
- AI 根据上述内容形成的判断。

缺少数字数据时，AI 可以基于文字状态做低置信度初步判断，但必须标注信息缺口，不能虚构线索量、转化率、获客成本或收入数据。

## 10. 验收标准

- 选择任意一个或多个经营模式后，第 3 步只出现对应动态卡片。
- 同时选择线上零售和线下门店时，两套字段可独立填写和保存。
- 取消再恢复某个经营模式后，原填写内容仍保留。
- 未选择经营模式时仍可填写共同现状、选择改善重点并继续。
- 七种经营模式均有文字状态题和默认收起的可选数字区。
- 上传经营资料、官网和公众号异步任务仍可使用。
- 桌面端和 390 像素宽手机端无横向溢出，按钮与选项可正常操作。
- 自动测试覆盖模式继承、动态显隐、值保留、互斥选项和完成度计算。
