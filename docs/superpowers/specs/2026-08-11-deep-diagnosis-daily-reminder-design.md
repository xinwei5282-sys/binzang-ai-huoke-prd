# 深度诊断每日首次登录提醒设计

## 目标

企业已完成基础画像、但尚未完成深度诊断时，深度诊断提醒每个自然日只在首次登录时展示一次，不因当天重复登录或刷新页面反复弹出。

## 规则

1. 基础画像未完成：继续显示现有企业信息引导，不显示深度诊断提醒。
2. 基础画像已完成且深度诊断未完成：
   - 当天尚未提醒时，登录后在首页展示“基础画像已完成，继续深度诊断”。
   - 弹窗一经展示，立即记录当地自然日，无论用户选择“稍后处理”、刷新还是重新登录，当天都不再展示。
   - 进入下一个当地自然日后，首次登录可再次展示。
3. 深度诊断已完成：不再显示此提醒。
4. “继续深度诊断”的原有跳转和手动触发深度诊断逻辑保持不变。

## 状态与判定

- 新增本地状态键，只保存最后一次展示提醒的本地日期，格式为 `YYYY-MM-DD`。
- 日期以浏览器所在设备的当地时区计算，与用户看到的“今天”一致。
- 登录流程先判定画像和深度诊断状态，再判定当日是否已提醒。
- 若浏览器本地存储不可用，本原型退化为本次页面会话中只提醒一次，不影响登录与诊断入口。

## 文案

- 弹窗标题保持：“基础画像已完成，继续深度诊断”。
- 点击“稍后处理”后提示：“已留在首页；今天不再提醒，明天首次登录会再次提醒”。

## 验收

- 深度诊断未完成且当天无记录：首次登录弹出提醒。
- 同一天再次登录或刷新：不弹出。
- 本地日期变为次日：首次登录再次弹出。
- 深度诊断已完成：无论日期记录如何都不弹出。
- 基础画像未完成：只显示企业信息引导。
