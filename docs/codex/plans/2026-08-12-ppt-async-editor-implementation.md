# PPT 异步生成与画布编辑实施计划

> **状态：** 已按当前原型收口，后续开发以本计划、PPT 设计规格和当前 PRD 为准。

## 目标

将 PPT 流程固定为“一句话需求 → 大纲审核 → 后台生成 → 直接下载或独立编辑”。PPT 画布内直接编辑标题和正文，右侧只保留 AI 追问。

## 文件责任

- `prototype/index.html`
  - PPT 列表、两阶段创建、异步任务、独立编辑页、画布自动保存、AI 候选版和下载入口。
- `prototype/tests/ppt-creation-flow.test.mjs`
  - 大纲审核门、后台任务、直接下载和无成品审核。
- `prototype/tests/ppt-slide-editor.test.mjs`
  - 画布文字编辑、切页隔离、AI 候选版、采用/撤回和右侧面板边界。
- `prototype/tests/ppt-global-consistency.test.mjs`
  - 原型、设计规格、实施计划和 PRD 的全局口径检查。

## 任务 1：锁定创建与异步状态

- [x] 创建页只展示“填写需求”和“审核大纲”。
- [x] 未确认大纲时不创建完整 PPT 任务。
- [x] 确认后返回 PPT 列表，任务从 `generating` 进入 `ready | failed`。
- [x] `ready` 可直接下载 PPTX/PDF，不设成品审核门。

## 任务 2：独立预览 / 编辑页

- [x] 列表点击“预览 / 编辑”新开标签页，原列表保留。
- [x] 独立链接直接进入对应 PPT，不重复显示登录层。
- [x] 左侧显示页面缩略图，中间显示 16:9 画布，右侧显示 AI 追问。
- [x] 保留上一页、下一页、全屏播放和 PPTX/PDF 下载。

## 任务 3：画布文字编辑

- [x] 标题和正文在画布内直接编辑。
- [x] 停止输入或离开编辑区后自动保存，显示“保存中 / 已保存”。
- [x] 手动修改只更新当前页，其他页保持不变。
- [x] 右侧不放标题、正文、数据、图片、备注、版式表单，也不放编辑/预览切换。

## 任务 4：AI 追问候选版

- [x] AI 每次只读取并修改当前页。
- [x] 新结果先写入候选版，未采用前不覆盖原页。
- [x] “采用新版”只更新当前页并递增整套 PPT 版本号。
- [x] “撤回”或生成失败保留原页，不阻断现有版本下载。

## 任务 5：验收

- [x] PPT 专项 `node:test` 通过。
- [x] 列表入口新开标签页，原页保留。
- [x] 画布自动保存和切页隔离通过真实浏览器验证。
- [x] 桌面和手机宽度无横向溢出，浏览器控制台无错误。

## 本期不做

- 画布元素自由拖拽、任意坐标排版和图层编辑。
- 矢量文件编辑。
- 页面级回滚入口。
- PPT 发布、账号选择和结果回收。
- 把静态原型的定时器和下载提示当成生产服务。
