# 消保委知识库专属原型 Implementation Plan

> **For Codex execution:** This plan may be executed inline in the current session or step-by-step with explicit checkpoints. Keep checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有AI获客SaaS单页原型中增加“消保委专属租户”入口和知识库工作台，完整演示自动采集、多模态加工、知识治理、公众号同步、消费者上传材料问答及审核留痕，同时隐藏该租户无关的营销模块。

**Architecture:** 保留现有 `prototype/index.html` 单文件原型和通用知识库组件，通过租户配置对象、URL参数和 `body[data-tenant]` 切换行业蓝图。消保委租户复用知识库页面骨架，以租户数据和功能开关替换企业营销知识域、来源、待审核事项和权限说明；所有交互仍为前端原型状态，不冒充真实后端服务。

**Tech Stack:** HTML、CSS、原生JavaScript、Node.js内置测试运行器、Playwright/Chromium渲染验证（若本地依赖可用）。
